## 一、三体系并立总则

1910年世界存在多套国际法体系并存，**全球并不存在唯一国际秩序**：

1. **天下体系（北京）**——以大顺为核心；
2. **威斯特伐利亚体系（欧洲）**——以欧洲民族国家体系为核心；
3. **奥斯曼体系（伊斯兰）**——以奥斯曼为核心。

体系之间：

- **不完全承认对方法理、爵位、外交礼仪**（例如：一国在欧洲体系是主权国家，在大顺体系可能只是藩属或互市国，反之亦然）；
- 形成多个互不承认法理的文明圈，**仅通过贸易维持联系**；
- 外交竞争激烈，但科学合作反而更加频繁（见 `04-科技.md` 四）。

---

## 二、天下体系

天下体系**不是现实朝贡体系，而是现代化后的国际体系**。

### 成员/要素类型

| 类型 | 说明 |
| ---- | ---- |
| 天下宗主国 | 大顺 |
| 朝贡国 | 定期朝贡、接受礼制秩序 |
| 藩属国 | 与宗主关系更深的政治依附 |
| 保护国 | 大顺提供军事/秩序保护 |
| 互市国 | 仅通商关系 |
| 观察国 | 葡萄牙（天下—欧洲桥梁） |
| 国际互市港 | 多国共通的贸易港口（如澳门） |
| 国际运河 | 苏伊士（国际化）、巴拿马（国际共管） |
| 国际开发区 | 非洲等地列强开发权区域 |

### 特点

- **不强制吞并**；
- 重贸易、秩序、礼制；
- 可允许不同文明保留制度；
- 强调**经济控制而非殖民统治**。

### 大顺对体系的经营（原文）

- 干涉朝贡国政治、操纵其经济、控制贸易、扩大军事影响、扶植亲顺政权；
- 对本土西学严控，对朝贡体系政治控制加强；
- 19世纪推进方向：东南亚 → 印度洋 → 南亚；
- 欧洲方向：葡萄牙"买办王国"与"里斯本一口通商"（大顺对欧贸易高度集中于里斯本门户）。

### 机制化建议（待确认）

- 朝贡/藩属/保护国/互市国在游戏中的自治度与义务梯度（经济献纳、军事义务、外交自由）；
- 观察国制度：非成员国的体系内特殊地位（如葡萄牙）；
- 国际互市港、运河、开发区的共管机制；
- 体系间"法理不互认"的规则化体现。

---

## 三、威斯特伐利亚体系

强调**主权国家、平等国家、国际法、条约、国界、民族国家**。以欧洲民族国家体系为核心，是本世界与天下体系竞争的主要对象。

---

## 四、奥斯曼体系（伊斯兰）

- 以奥斯曼为核心，强调宗教、帝国边疆、地方总督；
- 北非方向自北非向撒哈拉和红海推进；
- 与威斯特伐利亚、天下体系在印度洋、中东交汇竞争。

---

## 五、国际中立区与国际共管

存在国际中立区：

- **澳门**（天下—欧洲国际自由港，葡萄牙保有）；
- **苏伊士**（国际化）；
- **巴拿马**（国际共管；哥伦比亚成为全球交通中心）；
- **亚历山大**。

相关概念：国际互市港、国际运河、国际开发区。

---

## 六、全球殖民体系

**不存在现实柏林会议式一次性瓜分**，而是**长期势力范围竞争**。非洲以《亚历山大会议》为框架：**保留本土国家主权、允许国际开发权**（形成铁路、港口、矿山、租借地、国际开发区）。

| 列强 | 殖民方式 |
| ---- | ---- |
| 英国 | 商业殖民、自治领、铁路、港口 |
| 法国 | 共和国输出、学校、行政、法语 |
| 奥斯曼 | 宗教、帝国边疆、地方总督 |
| 大顺 | 港口、华商、商会、公司、藩属、铁路贷款 |
| 德国 | 工程公司、银行、铁路、矿业资本 |

> 世界殖民更像**势力范围竞争，而不是一次性瓜分**。
