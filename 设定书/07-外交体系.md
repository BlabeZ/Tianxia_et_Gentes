## 一、三体系并立总则

1910年世界存在多套国际法体系并存，**全球并不存在唯一国际秩序**：

1. **天下体系（北京）**——以大顺为核心；
2. **威斯特伐利亚体系（欧洲）**——以欧洲民族国家体系为核心；
3. **奥斯曼体系（伊斯兰）**——以奥斯曼为核心。

体系之间：

- **不完全承认对方法理、爵位、外交礼仪**（例如：一国在欧洲体系是主权国家，在大顺体系可能只是藩属或互市国，反之亦然）；
- 形成多个互不承认法理的文明圈，**仅通过贸易维持联系**；
- 外交竞争激烈，但科学合作反而更加频繁（见 `04-科技.md` 四）。

## 二、三体系交往规则（2026-08-05 拍板）

> 原文未述，本条由用户逐项拍板确立。规则分两档：**正文**（世界观级，锁定）与**机制方向**（游戏层建议，待机制化阶段展开，不填数值）。

### 1. 使节制度

**正文**：三体系之间**不存在大使级正式互派**——"大使"身份在法理不互认下无法成立。体系间官方接触经由：
- **中转渠道**：葡萄牙（观察国，天下—欧洲桥梁）+ 国际中立区（澳门/苏伊士/亚历山大，兼作接触界面）；
- **直接接触**：以**商馆、领事、特使**为主，不涉及法理承认。

**机制方向**（待确认）：1900 年后贸易量迫使双方设立**常驻商务机构**（"通商使节/商务衙门"式）——实质常驻使节，名分降格以回避法理与礼仪冲突（如大顺驻里斯本/伦敦/巴黎设商务衙门，英法德在澳门/上海设领事）。

### 2. 条约效力

**正文**：跨体系条约采用**内国效力制**——条约（如《顺俄东北勘界条款》《顺英通商章程》）只在各自体系内法理有效；违约由**本体系内**的律例/礼制或国际法处理，无共同法理制裁；违约的代价是**事实性制裁**（禁运、断互市、撤商馆、舰队封锁），而非诉讼或仲裁。

**机制方向**（待确认）：存在唯一例外——**中立区章程**（苏伊士/巴拿马/亚历山大/澳门的共管章程）作为跨体系"**最低公约数**"：三体系在该章程范围内互相承认对方权利（航道通行、股东权益、治外豁免）。**中立区=三体系唯一的"共同法理岛"**，这是中立区价值远超普通租界的根本原因。

### 3. 争端解决

**正文**：**无超体系仲裁机构**；跨体系争端靠**事实实力**（禁运、舰队示威、扶植代理人、经济施压）与**谈判**解决；谈判地点的惯例为**中立区或里斯本**（葡萄牙观察国的居中功能）。不设非制度化的第三国调停惯例（2026-08-05 用户决定：调停不入正文与机制方向）。

### 4. 补充要点

- **礼仪回避**：使节觐见不强迫他体系使节行本体系全礼（与"不完全承认对方法理、爵位、外交礼仪"一致），以东道国惯例从简处理；
- **科学合作豁免**：科学交流是唯一**制度性合作**领域（国际科学会议、博览会、学会互访、技术图书交换），不受法理不互认限制（见 `04-科技.md` 四）。

## 三、天下体系

天下体系**不是现实朝贡体系，而是现代化后的国际体系**。

### 成员/要素类型

| 类型 | 说明 |
| ---- | ---- |
| 天下宗主国 | 大顺 |
| 朝贡国 | 定期朝贡、接受礼制秩序 |
| 藩属国 | 与宗主关系更深的政治依附 |
| 保护国 | 大顺提供军事/秩序保护 |
| 互市国 | 仅通商关系 |
| 观察国 | 葡萄牙（天下—欧洲桥梁） |
| 国际互市港 | 多国共通的贸易港口（如澳门） |
| 国际运河 | 苏伊士（国际化）、巴拿马（国际共管） |
| 国际开发区 | 非洲等地列强开发权区域 |

### 特点

- **不强制吞并**；
- 重贸易、秩序、礼制；
- 可允许不同文明保留制度；
- 强调**经济控制而非殖民统治**。

### 大顺对体系的经营（原文）

- 干涉朝贡国政治、操纵其经济、控制贸易、扩大军事影响、扶植亲顺政权；
- 对本土西学严控，对朝贡体系政治控制加强；
- 19世纪推进方向：东南亚 → 印度洋 → 南亚；
- 欧洲方向：葡萄牙"买办王国"与"里斯本一口通商"（大顺对欧贸易高度集中于里斯本门户）。

## 四、威斯特伐利亚体系

强调**主权国家、平等国家、国际法、条约、国界、民族国家**。以欧洲民族国家体系为核心，是本世界与天下体系竞争的主要对象。

## 五、奥斯曼体系（伊斯兰）

- 以奥斯曼为核心，强调宗教、帝国边疆、地方总督；
- 北非方向自北非向撒哈拉和红海推进；
- 与威斯特伐利亚、天下体系在印度洋、中东交汇竞争。

### 成员等级结构（2026-08-05 拍板）

> 四级制：直辖省 → 自治省 → 附庸邦 → 宗教影响带。与天下体系的贸易—礼制逻辑不同，奥斯曼体系是**宗教+帝国边疆+地方总督**的逻辑。

| 等级 | 成员 | 备注 |
| ---- | ---- | ---- |
| 直辖省 | 安纳托利亚、两河流域、叙利亚（奥斯曼"阿拉伯地区"内部行省） | 总督治理；行省名单待边界阶段细化 |
| 自治省 | **埃及（2026-08-05 定）**：名义奥斯曼自治省（世袭总督家族），实际受英法顺竞争影响、与苏伊士/亚历山大中立区机制深度绑定——"名义在体系内、实质多方博弈"；候选待细化：汉志（麦加谢里夫世袭家族？）、突尼斯、的黎波里塔尼亚 | 埃及为已定项；其余候选等级待主题开发确认 |
| 附庸邦 | 候选待细化：海湾诸邦（科威特/巴林/卡塔尔/特鲁西尔——名义奥斯曼、英顺竞争）、也门 | 等级容器先立，形态待细化 |
| 宗教影响带 | **制度核心**：圣地与学府（麦加/麦地那、耶路撒冷、巴格达学府、朝觐制度、乌理玛网络）；**非领土性文化成员**：逊尼派世界（中亚汗国、东非沿岸、印度洋穆斯林商人）——非奥斯曼臣属，但通过朝觐、商路、教法体系处于其宗教影响下（如中亚汗国=天下体系朝贡国+奥斯曼宗教影响，双重身份并存） | 波斯（什叶派）排除：逊尼—什叶宗派竞争，波斯为体系边缘而非成员 |

### 体系外候选（待确认）

- 内志、阿曼、摩洛哥、阿尔及利亚——独立倾向强的实体，默认体系外，形态待主题开发；
- 波斯——多方平衡（英/俄/顺/德竞争），"奥斯曼体系边缘"非成员。

## 六、国际中立区与国际共管

存在国际中立区：

- **澳门**（天下—欧洲国际自由港，葡萄牙保有）；
- **苏伊士**（国际化）；
- **巴拿马**（国际共管；哥伦比亚成为全球交通中心）；
- **亚历山大**。

相关概念：国际互市港、国际运河、国际开发区。

### 管理权归属（2026-08-05 拍板）

> 法理基础：**中立区章程**（本卷二·条约效力——三体系唯一"共同法理岛"，章程范围内互相承认航道通行、股东权益、治外豁免）。

| 中立区 | 管理模式 | 构成 |
| ---- | ---- | ---- |
| 苏伊士 + 亚历山大 | **同一家国际特许公司**（一体运营运河与港口，2026-08-05 用户决定） | 混合制：公司运营（通航/港务/工程技术）+ 列强监督委员会（安保/通行费定价/治外豁免）；资本英法主导+大顺/奥斯曼参股；委员会=英/法/顺/奥图四方；亚历山大兼为**国际谈判地惯例**（本卷二·争端解决）；均位于埃及自治省境内（本卷五） |
| 巴拿马 | 混合制：公司运营+监督委员会 | 五方竞争：英国、法国、大顺、美国、巴西（原文"共同竞争的交通节点"）；哥伦比亚为宗主国+全球交通中心 |
| 澳门 | 观察国豁免模式（非公司制） | 葡萄牙保有主权+大顺共管商港；天下—欧洲国际自由港；与使节制中转职能（本卷二）呼应 |

### 机制方向（待确认）

- 各公司股东结构、通行费定价权、董事会席位与派系事件（机制化阶段展开，不填数值）；
- 中立区内的治外豁免范围与治安责任（属地国 vs 公司 vs 委员会）。

## 七、全球殖民体系

**不存在现实柏林会议式一次性瓜分**，而是**长期势力范围竞争**。非洲以《亚历山大会议》为框架：**保留本土国家主权、允许国际开发权**（形成铁路、港口、矿山、租借地、国际开发区）。

| 列强 | 殖民方式 |
| ---- | ---- |
| 英国 | 商业殖民、自治领、铁路、港口 |
| 法国 | 共和国输出、学校、行政、法语 |
| 奥斯曼 | 宗教、帝国边疆、地方总督 |
| 大顺 | 港口、华商、商会、公司、藩属、铁路贷款 |
| 德国 | 工程公司、银行、铁路、矿业资本 |

> 世界殖民更像**势力范围竞争，而不是一次性瓜分**。
