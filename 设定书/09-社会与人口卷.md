## 一、全球社会分层框架

1910年世界不能以"发达国家/落后国家"简单划线，大体存在四种社会：

| 类型 | 典型地区 | 社会特征 |
| ---- | ---- | ---- |
| 工业城市社会 | 英国、德国、法国、英属北美、新瀛部分地区、拉普拉塔、巴西东南部 | 工人阶级已成为独立政治力量 |
| 工业—农业混合社会 | 大顺、墨西哥、奥斯曼、俄罗斯、智利、秘鲁 | 城市现代化快，农村人口仍占绝对多数 |
| 商业—农业社会 | 东南亚、波斯、加勒比、部分非洲 | 港口非常现代，腹地传统 |
| 传统共同体社会 | 中亚、非洲内陆、印第安地区、安第斯山区 | 地方共同体、宗教、部族、地主/酋长仍是社会核心 |

> 1910年的现代性呈"现代城市—现代港口—现代铁路沿线—传统腹地"的**斑块状分布**。

### 生活水平四层

1. **高度现代城市生活**：英国、德国、法国、英属北美、部分新瀛、荷兰、拉普拉塔（电灯、电车、自来水、公共卫生、报纸、电话、铁路、百货商店、现代医院；工人住宅仍拥挤）；
2. **现代化混合生活**：大顺、巴西、墨西哥、奥斯曼、俄罗斯、智利（城市中产已现代，走出城市几十公里就完全不同）；
3. **港口现代化**：东南亚、波斯、加勒比、非洲沿海、印度部分地区（港口有电报/蒸汽船/铁路/银行，内陆高度传统）；
4. **传统共同体社会**：中亚、非洲内陆、印第安地区、安第斯山区。

## 三、大顺社会志【已确立+拟定】

### 1. 社会金字塔（【已确立】）

皇族 →（理学文官集团 ↔ 良家子军事贵族）→ 士绅/地主豪强 →（工商业资本家 ↔ 商人集团）→ 城市中间阶层 → 工人/手工业者 → 小农/佃农 → 贫农/流民；另含边疆层（军事贵族/边镇 → 军屯人口 → 当地部族）与海外层（新瀛海外顺人）。

### 2. 阶层要点（【已确立】）

- **皇族**：三角平衡的最终仲裁者，政治利益是防止文官、军事贵族、商业资本任何一方获得独立国家权力；
- **理学文官集团**：1910执政阶层，控制行政、教育、科举、地方行政与国家意识形态；不反对铁路工业本身，反对"工业社会必须伴随西方式政治制度"；
- **良家子军事贵族**：爵位+军功+土地+军队影响力，被排除出文官行政，长子继承限制规模；1910利益固化，"我们不是官，但我们是国家的刀"；
- **士绅/地主**：分化出传统地主与资本化地主（土地收入投入商业、银行、铁路、工厂）；
- **商人集团**：传统陆商/海商/金融商人/工业资本家四分；工业资本家是1910最强新兴政治力量之一；
- **城市中间阶层**【拟定】：教师、医生、工程师、会计、银行/铁路/电报职员、律师、报刊从业者、企业经理——最活跃的舆论阶层；
- **工人阶级**：集中于工厂、铁路、港口、矿业；社会主义仍是成长中意识形态；
- **小农/佃农/流民**：小农经济瓦解、土地兼并、流民增加的受害者；新瀛在社会学意义上是"大顺乡村危机的海外出口"。

### 3. 社会结构总图与流动（【已确立+拟定】）

传统上升路线四条：读书（科举/官僚）、军功（良家子）、财富（商业/工业）、技术（工程/科学→技术官僚）。深层变化：**财富可以不通过官僚获得**——"谁有资格成为社会精英"成为核心问题。

### 4. 社会意识形态地图（【拟定】）

理学官僚→天下保守主义/儒家国家主义；良家子→天下保守/新军国家派；士绅→地方士绅派；海商→海洋改革/商业自由；工业资本→工商业自治/国家工业主义；工程师→实学改革/技术国家主义；城市中产→实学/改革/自由主义/社会改革；工人→社会改革/工团主义/社会主义；流民贫农→土地改革；新瀛居民→海外自治/海外顺人民族主义；激进知识分子→共和主义/民族主义/社会主义。

### 5. 大顺社会危机：八个冲突（【已确立+拟定】）

①土地危机（小农→佃农/贫农/流民）；②城市危机（农村人口→城市贫民/工人）；③阶级危机（地主/资本家↔工人）；④官僚危机（文官集团↔新兴技术官僚）；⑤文武危机（文官↔良家子军事贵族）；⑥地方危机（中央↔地方士绅/地方资本）；⑦思想危机（儒学国家主义↔西学/民族主义/共和主义/社会主义）；⑧海内外危机（北京↔新瀛）。

> 八个矛盾汇聚成一个问题：**大顺究竟还能不能用17世纪建立的社会制度，管理1910年的工业社会？**

### 6. 大顺地域社会（【已确立+拟定】）

- **京畿**：官僚帝国心脏，政治密度最高，天下保守主义最强地区之一；
- **江南**：文教与现代商业最早融合，理学官僚与工商业自治派争夺最激烈；
- **沿海**：传统农村+商业港口+工业城市三者并存，社会变化最剧烈（"沿海人看到的是世界，内陆士人看到的是天下"）；
- **华北**：农业、粮食、官僚、铁路、军事；
- **西南**：湿热多瘴，人口承载受传统技术限制，向新瀛移民的重要人口来源之一；
- **西北**：核心问题是水，依赖绿洲、河流、商路、军镇、边贸，为缓冲地带；
- **东北**：最军事化地区，军事贵族+军屯+边贸+渔猎部落，良家子地位最强。

### 7. 大顺宗教（【已确立+拟定】）

儒学承担国家伦理与政治合法性，佛教/道教/民间信仰承担日常宗教生活——"**儒学是政治文明，民间信仰是生活宗教**"。基督教具有政治敏感性（澳门耶稣会事件后的传统：实学可学、西方宗教政治思想必须防范）。

### 8. 新瀛社会（【已确立+拟定】）

社会结构：总督→巡抚→士绅→华商→工人→土著。代际身份转变："我是顺人，所以我住在新瀛"→"我是新瀛顺人"。新瀛不是"大顺海外版"，而是**大顺现代化的替代方案**（最早出现现代青年文化、商业文化、自治主义与海外民族认同的地方）。

## 四、英国社会志（定性；现实数字仅作参照）

> 本世界英国因十三州未独立、形成跨大西洋帝国（见 `01-历史.md` 三·英国帝国自治化补写线），社会结构与现实英国存在本质差异。以下为定性结构。

### 1. 社会定位

"工业帝国已经成熟，但传统等级社会仍深深嵌入工业资本主义"。现实参照：1911年英格兰与威尔士约78%人口居住在统计意义的城市地区（现实参照数字，不构成本世界观数据）。

### 2. 阶层结构

王室→世袭贵族/大地主→（上层政治精英↔大企业资本家）→中上层（专业人士/商人/中高级公务员）→下中产（职员/小商人/教师护士）→熟练工人→非熟练工人→贫民。特别群体：**家庭女佣**（现实参照：1911年英格兰威尔士约176.5万女性从事家庭服务——本世界仅作理解参考）。

### 3. 本世界英国的特殊阶层（【修订】补写线）

帝国资本家（铁路、航运、金融、殖民公司）、北美工业资产阶级（帝国最危险的新精英）、帝国官僚、自治领政治精英；伦敦与北美的矛盾本质是两个资产阶级之间的权力分配问题。工党分化为帝国工党与本土工党。

### 4. 地区差异

伦敦（金融+政府+帝国中心）、英格兰北部（煤钢机械纺织）、兰开夏（棉纺织）、约克郡（毛纺煤炭）、威尔士（煤矿钢铁港口）、苏格兰低地（造船工程）、爱尔兰（农业社会+城市工业岛屿）——"英国工人"不是一种人。

### 5. 工人社会（定性）

熟练工人（"工人贵族"，工会+较高工资）与非熟练工人（收入不稳定）分化；矿工社区（公司城镇：住宅、学校、教堂、酒吧围绕矿井）；铁路工人（稳定产业工人）；码头工人（工作不稳定但组织能力强）；女性劳动大量进入纺织、制衣、家庭服务。

### 6. 宗教、家庭、教育（定性）

宗教具强地域性（英格兰国教/威尔士非国教/苏格兰长老会/爱尔兰天主教）；"宗教信仰与教会参与逐渐分离"；家庭：中产郊区住宅+家庭女佣、工人排屋/多户住宅；教育高度阶级化（上层公学→中产文法学校→工人基础教育），同时是"阶级再生产工具与社会流动工具"。

### 7. 核心矛盾（定性）

贵族vs民主政治、资本vs劳工、熟练工vs非熟练工、城市vs农村、伦敦vs地方、帝国中心vs殖民地、男性公共领域vs女性劳动、宗教传统vs世俗现代性、传统阶级社会vs大众民主社会——最重要者为最后一项。

## 五、法国社会志（定性；现实数字仅作参照）

> 本世界法国是"第二次革命"后的革命共和国（拿破仑为革命领袖），**不是现实第三共和国**；现实1905年政教分离法等具体事件不得直接视为本世界设定（见 `00-总览` 九·原则一）。以下为定性结构。

### 1. 社会定位

"由革命、共和、工业化与农村小农化共同塑造的'公民—小农—资产阶级—工人'社会"。现实参照：1911年法国约55.8%人口生活在农村（现实参照数字）。

### 2. 四大核心人群（【拟定】）

- **Ⅰ 小农共和国**：土地+家庭+村庄+私有财产+共和国——法国人口基础。革命后形成大量小土地所有者（"有土地，但不富裕"）；小农可能同时是共和主义者与社会保守主义者（支持共和国与世俗国家，反对激进社会主义与土地集体化）；
- **Ⅱ 共和中产**：教师+公务员+医生+律师+小商人——共和国制度基础。教师是"共和国的基层传教士"，承担识字、法语、公民教育；
- **Ⅲ 资产阶级**：工业+金融+商业+地产——经济精英，家族资本明显；
- **Ⅳ 城市工人**：工厂+作坊+工会+社会主义——社会冲突最强烈的集团。法国工业集中度低于英国，手工业仍很重要（小作坊），工人高度分散；巴黎出现"垂直阶级结构"（同一栋楼上下层分属不同阶级，顶层阁楼为佣工/贫困者）。

### 3. 宗教

"国家非常世俗，社会仍然相当宗教化"——政教分离是法国革命传统的自然延伸，但具体年份与形式待本世界历史确认（不得照搬现实1905年）。

### 4. 法国与大顺/英国的差异（定性）

大顺=经济现代化追赶传统国家结构；英国=经济现代化成熟、制度正在适应；法国=政治现代化走在前面、经济与社会结构处于"农村小农社会→工业大众社会"过渡阶段。

## 六、俄罗斯社会志（【已确立+拟定】）

### 1. 定位

"一个未能建立远东—太平洋帝国、因而更加集中于欧洲俄罗斯—黑海—高加索—中亚方向的**南向大陆帝国**"；"现代化极不均衡的大陆帝国"。

### 2. 人口与土地（【拟定】）

农民仍为绝对主体；失去远东扩张方向后，人口压力集中于欧洲俄罗斯、伏尔加、黑海北岸、乌拉尔、高加索北缘、哈萨克草原边缘——**土地问题比现实更加尖锐**（农民核心问题不是抽象的社会主义，而是"有没有足够的土地"）。

### 3. 阶层结构（【拟定】）

皇室与宫廷→高级贵族（内部已分化：地主/军事/官僚/工业贵族）→官僚阶层（"国家服务者"，国家工业主义与技术官僚主义的社会基础）→城市中产→工业资本家（国家依附性明显，形成国家工业主义而非英国式自由资本主义）→城市工人（集中度高：圣彼得堡—莫斯科—乌拉尔—伏尔加—黑海工业走廊）→农民（内部：富农/中农/小农/无地农民/农业雇工）。

### 4. 六个俄罗斯（【拟定】）

宫廷俄罗斯、官僚俄罗斯、城市俄罗斯、工业俄罗斯、农村俄罗斯、边疆俄罗斯——"六个俄罗斯正在加速联系，却还没有形成共同的政治契约"。

### 5. 宗教与意识形态（【已确立+拟定】）

东正教承担国家合法性（皇帝、俄罗斯、东正教、历史传统的连续性）；教会内部三分：传统保守派、国家主义派、**东正教现代主义**（科学教育工业不与信仰冲突，是技术官僚与温和改革派的思想桥梁）。

俄罗斯1910意识形态光谱（【拟定】九派）：皇权正教保守主义、历史国家主义、泛斯拉夫主义、东正教现代主义、国家工业主义、地方自治主义、农民土地主义、社会民主主义、革命社会主义。

### 6. 核心矛盾（【拟定】）

土地（农民人口增长vs可支配土地有限）、城市工人（工业化vs保障不足）、官僚国家（需要官僚vs限制政治参与）、贵族（特权vs工业资本与技术官僚崛起）、宗教（东正教vs科学社会主义思想）、边疆（统一vs民族自治）。潜在革命危险是七股力量的合流：农民要土地、工人要权利、中产要参与、民族要自治、技术官僚要改革、贵族守旧、军队内部分化。

> 俄罗斯1910最有特色的提问：**"一个多民族大陆帝国能不能通过官僚、铁路、军队和东正教文明完成现代化？"**

## 七、德/多瑙/奥斯曼三国社会（【已确立+拟定】）

### 1. 三国总体定位

| | 德意志帝国 | 多瑙联邦 | 奥斯曼帝国 |
| ---- | ---- | ---- | ---- |
| 1910社会核心 | 工业化联邦社会 | 多民族联邦社会 | 农业—商贸帝国转型社会 |
| 现代性 | 契约现代性 | 联邦现代性 | 宗教现代性 |
| 人口主体 | 农民+城市居民并重 | 农民占主体、区域差异巨大 | 农民、牧民、小城镇居民 |
| 工业化 | 很高 | 中等且极不均衡 | 较低但战略工业增长 |
| 工人阶级 | 庞大且组织化 | 正在形成 | 少而集中 |
| 最大问题 | 工业社会如何参与联邦政治 | 民族自治如何不导致国家解体 | 帝国如何现代化而不失去统一 |

### 2. 德国（【已确立+拟定】）

统一经"关税同盟→铁路共同体→工业资本跨邦整合→联邦财政改革→有限战争→联邦统一→各邦保留政治权力→军队成为联邦机构"完成——"德国不是军国主义"是历史结果而非现实反转。最有特色的阶层是**技术—教育中产阶级**（工程师/教师/公务员/医生/律师/技术员——"工程国家"的社会基础）；工人已被纳入国家工业社会（企业住房、工厂医院、职业培训、工伤保险、福利基金）；工人政治三条路线：社会民主、工团主义、国家社会改革。

### 3. 多瑙联邦（【已确立+拟定】）

核心问题不是"民族问题导致帝国崩溃"，而是**民族差异被制度化之后如何维持共同国家**。地域差异：奥地利核心区（维也纳：帝国首都+联邦首都+金融文化中心）、波希米亚—摩拉维亚（工业核心，最现代化）、匈牙利平原（大地主+中小农+农业雇工，土地问题严重）、巴尔干联邦地区（小农+地方贵族+商人+教士）、南方新吞并区（塞尔维亚/黑山/阿尔巴尼亚/部分罗马尼亚，2026-08-05 定案；加利西亚已归俄属波兰，不在联邦内）。工人运动面临"按民族组织还是按阶级组织"问题；核心意识形态是联邦主义（"你是捷克人/匈牙利人/克罗地亚人/奥地利人，但同时也是多瑙联邦公民"）；教育采用"地方语言教育+联邦共同教育"。

### 4. 奥斯曼（【已确立+拟定】）

"以农业和地方共同体为主体，但已被铁路、港口、军队、学校和国际贸易重新组织的帝国社会"。铁路是**帝国政治项目**（没有铁路中央政府无法统治帝国）；德国—奥斯曼铁路关系制造出新社会群体（德国工程师、奥斯曼工程师、铁路工人、技术官僚、铁路商人、军事技术人员——奥斯曼现代主义的社会基础）；军队是帝国整合工具；乌理玛内部分化（传统乌理玛vs改革乌理玛——"谁有权定义伊斯兰现代化"）；伊斯兰现代主义回答"铁路、电报、现代医院、现代军队是否符合伊斯兰"——可以，而且应该。

### 5. 三国社会一句话画像（【拟定】）

德国："工厂烟囱、铁路和大学已经创造了一个现代社会，而国家正在学习如何治理它。"
多瑙联邦："帝国没有消灭民族，而是试图把民族变成联邦制度的一部分。"
奥斯曼："清真寺、集市、铁路、军营和港口共同构成一个正在寻找伊斯兰式现代国家形态的帝国。"

## 八、其他区域社会（定性）

- **东南亚**：港口—腹地二元结构（港口极现代：华商、欧洲商人、银行、航运、电报、电灯、蒸汽船；腹地仍以稻作、地主、地方贵族、宗教领袖、村社为核心）；
- **南亚**：英属城市精英/传统地主/商人/城市产业工人（纺织铁路港口矿业）/农民/宗教共同体并存；矛盾不止"印度人vs英国人"，还有"殖民现代化vs传统社会"与"宗教共同体vs新兴民族政治"；
- **葡萄牙**："里斯本属于世界，葡萄牙内陆属于旧欧洲"——商业中介、外贸代理人、金融买办、港口工人vs贫困传统内陆；
- **荷兰**：金融家和小市民社会（银行家、保险商、航运商、股票经纪人、商业律师、中小商人）；
- **波斯**：王权—宗教—商业三角社会（沙阿/乌理玛/巴扎商人/地主/知识分子/城市中产/手工业者工人/农民），巴扎既是市场金融中心又可能是政治反对力量；
- **中亚**：汗国贵族、部落首领、宗教人士、商人、农民、游牧民；现代化首先表现为新式学校、印刷、报刊、铁路、商业、教育改革（Jadid新教育派）而非大型工厂；
- **非洲**：本土王国+港口城市（华商/阿拉伯商人/印度商人/欧洲公司/航运/银行/铁路/电报）+矿业地区（公司资本/技术人员/工人/本地劳工）——现代化呈"港口化、铁路化、矿区化"；
- **英属北美**：最富裕的自治领社会；身份问题"英国人还是北美人"，年轻人/城市中产/军官更支持北美民族主义；
- **法属北美**：最政治化的北美社会（教师—律师—公务员—小资产阶级庞大，政治教育极强；天主教传统vs共和国世俗主义）；
- **美国**：被大陆包围的共和国（"我们本来应该成为大陆国家，却失败了"）——泛大陆主义、激进民主、孤立主义、工团主义；自由城、自由港、华盛顿堡、新费城等工业区形成现代工人社会（2026-08-05 补写线：纽约1781失守属英属北美）；
- **墨西哥**：北美最典型混合文明社会；无美国长期压倒，形成更强烈的墨西哥民族主义+印欧融合主义+工业发展主义；
- **印第安地区**："手里拿着马克沁机枪，社会结构却仍然是部族联盟"——酋长、部族贵族、战士集团、商人、代理人、农牧民；现代武器集中在部分部族精英手中；
- **巴西**：工业帝国社会（皇帝→议会→咖啡种植园主→工业资本→城市中产→工人→农民）；圣保罗里约最现代；
- **拉普拉塔**：南美最"欧洲化"的城市社会（技术中产+城市工人；布宜诺斯艾利斯：大学、电车、铁路、工厂、工会、剧院、报纸、咖啡馆、移民社区）；
- **智利**：矿业—港口—海军社会，矿工是重要政治阶层；
- **秘鲁**：高度分层文明社会（上层城市精英/地主/商人 vs 下层印第安共同体/矿工/山区农民）；顺学派知识阶层；
- **哥伦比亚/巴拿马**：全球最国际化区域之一（英法顺美巴哥伦比亚人、商人、水手、工程师、铁路工人、运河工人）；
- **加勒比**：早熟的跨种族、跨语言、跨宗教、跨帝国现代商业社会（海地共和主义/古巴商业金融/牙买加自治殖民/黑人平权）；
- **安第斯诸国**：少数现代矿业城市+巨大传统农村社会。

## 九、劳动与工人运动（全球）

- 工人运动到1910年已成为重要政治力量（世界性）；
- 工团主义在法国、意大利、西班牙及部分拉美国家尤其强大；
- 工业化地区必然存在强大社会主义运动（见 `05-经济.md` 四.5）；
- 德国工人已是"政治阶级"，多瑙工人正在成为"跨民族政治阶级"，奥斯曼工人仍是"港口/铁路/军工城市的新兴职业群体"（社会主义发展速度：德国＞多瑙＞奥斯曼）。
