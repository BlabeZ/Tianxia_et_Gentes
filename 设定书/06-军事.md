## 一、军事制度：良家子制度

李自成及其继承者建立的"良家子制度"是大顺军事秩序的基础（详见 `01-历史.md` 二.1）。其军事面要点：

- **耕战结合、兵农合一**：地方军事人口组织化，军队与乡村生产结合；
- **军功授田、军事贵族化**：以军功授田为核心激励，形成世袭军事贵族；
- **类似普鲁士容克的军事权贵阶层**：既是军队骨干，又是皇权的重要支持者；
- **地方军人与中央军事集团相结合**。

**皇权对军事贵族的压制（三角平衡）**：军事贵族可以拥有爵位、军功、土地、军事荣誉、军队影响力，但**原则上不得进入文官行政体系**；实行严格的**长子爵位继承制**防止其扩大。由此形成**皇权—文官集团—军事贵族**三角结构，军事贵族军事地位很高，却被刻意排除在正常行政政治之外。

**1910年的军事贵族**：良家子贵族利益固化被列为大顺盛世危机的组成部分之一（与"文武冲突"并列）。

## 二、军事史关键节点

### 1. 尼布楚战争（17世纪末—18世纪初）与军事技术觉醒

- 大顺向东北、西北重新确立帝国边疆，与西伯利亚—远东扩张中的俄罗斯冲突；
- 大顺常驻京师的禁卫军被派往东北"布武罗刹"，**在俄罗斯欧式小型要塞前遭到严重伤亡**；
- 最终在接受"通西学"的将领领导下、参考**法国沃邦式攻城法**攻克要塞，取得有限但具有重大政治意义的胜利；
- 结果：攻下俄军若干远东要塞与殖民据点、重新声明对部分远东土地及渔猎部落的宗主权，签订《顺俄东北勘界条款》（勒拿河以东、阿尔丹河以南归大顺势力范围）。

> 此战暴露大顺与西欧的军事技术差距，直接促成"器物西学"（火器、炮术、军事技术）与主动开海。

### 2. 从陆权到海权—贸易帝国（1700年前后）

尼布楚战争后，帝国战略从陆权帝国转向**海权—贸易帝国**，军事重心伴随战略转移。

### 3. 第二次法国革命战争中的大顺海军

为制衡**英属北美**（2026-08-01 修订，原文"制衡北美新瀛"为笔误），大顺**出兵支援法国殖民地**，法国成功保留北美重要殖民地。这要求大顺具备远洋投送能力（详见 `01-历史.md` 三·北美、`03-政治.md` 七）。

### 4. 大顺"黑船事件"（日本，2026-08-01 修订，2026-08-05 细化）

大顺以舰船/武力威慑发动"黑船事件"，**扶持幕府将军继续统治**，通过"名不正言不顺"的统治者迫使日本幕府依附大顺。2026-08-05 细化：**幕府仅控制京都一带**；江户（东京）及沿海多个重要港口为大顺控制的"朝贡贸易港"（驻军与贸易控制）；**藩阀割据混战**，大顺离岸平衡；游戏内表现为大顺傀儡幕府、藩阀为幕府傀儡（黑船事件本身的时间、过程、舰船规模待确认）。

## 三、海权与海军

- 开海后大顺成为海权—贸易帝国，海商、港口、商馆网络（南洋共同体、东非商站）依托海上力量维持；
- **跨太平洋航线**：18世纪初发现，18世纪中叶起支撑新瀛官方殖民（殖民船队），18世纪下半叶进入大规模殖民时代；
- 大顺海军曾远赴北美支援法国（第二次法国革命战争）；
- 天下体系的军事体现：扩大军事影响、扶植亲顺政权、保护国与藩属体系（详见 `03-政治.md`）。

## 四、1910年军备水平

依据科技卷（`04-科技.md`），本世界1910年军事技术总量与现实1910基本一致（±5年）：

- **陆军**：后膛枪、栓动步枪、马克沁机枪、速射炮、无烟火药；
- **海军**：无畏舰开始出现；钢甲舰/前无畏舰体系成熟（"无畏舰开始出现"原文明确，其余属此区间常态）；
- **空中**：飞机刚刚进入军事领域。

军事技术竞争特点：

- 技术扩散快（多体系长期贸易），但**各国军工体系不同**（例：法国炮兵体系与英国不同）；
- 各国科研组织方式不同（英偏商业、德偏工程/军工联合、法偏理论、大顺偏国家组织与工程实践，见 `04-科技.md` 七）。

## 五、各主要力量军事取向

> 标注"待确认"者均为超出原文、需后续推演的内容。

### 大顺
- 军制：良家子制度与皇权—文官—军事贵族三角平衡；
- 1910矛盾之一：**文武冲突**、良家子贵族利益固化；
- 军事方向：陆军技术追平（沃邦式攻城学起）、海权—贸易帝国、跨太平洋投送（新瀛、支援法国）。

### 英国
- 全球海权强国；海洋科技、机械制造、商业工程领先（`04-科技.md`）；殖民靠贸易、自治领、港口控制，而非全面驻军。

### 法国
- 全球军事科技中**炮兵**领域领先；革命输出常伴随军事干预（北美法属殖民地之保有依赖大顺支援）。

### 德国
- **并非军国主义国家**；科研体系为大学—国家实验室—工业企业—军工联合（`04-科技.md`）；工程与铁路为其扩张工具（向奥斯曼、中东）。

### 俄罗斯
- 陆权帝国，远东扩张失败后转向欧洲、高加索、中亚；始终试图南下。

### 奥斯曼
- 以宗教、帝国、地方总督维持边疆（北非向撒哈拉和红海推进），现代化改革中。

### 日本（2026-08-01 修订，2026-08-05 细化）
- 非列强、未统一；幕府在大顺"黑船事件"扶持下维持统治，军事上依附大顺；
- 2026-08-05：幕府仅控京都一带；江户（东京）及沿海朝贡贸易港由大顺实控驻防；藩阀割据、大顺离岸平衡；游戏内为大顺傀儡幕府、藩阀为幕府傀儡（细节待确认）。

### 北美
- **印第安地区**：无现代国家、无工业化，仅拥有列强出售或援助的**现代武器**，成为多国扶植的缓冲区（待确认：具体武器来源与规模）；
- **美国**：工业不错但被夹于英属北美与法属路易斯安那之间，军事上无大陆霸权能力；
- **新瀛**：海外顺土，海上联系依赖大顺（自身武装程度原文未述，待确认）。

### 拉美
- **智利**：太平洋主义包含**海军建设**诉求（`02-意识形态.md`）；拉美最早接受顺朝影响（贸易、造船）；
- **秘鲁**：长期接受顺朝影响（顺学派），自身军力原文未述；
- **巴西**：造船快速发展（`03-政治.md` 八），海军规模待确认。

## 六、全球军制与编制【拟定】

> 来源：`军制.md`。以下编制与人数均为**推演值**，非设定原文数字，待逐项确认。全球统一单位基准：**班（12—15人）→ 排（40—50人）→ 连（150—200人）→ 营（700—900人）→ 团（2,500—3,500人）→ 旅（5,500—8,000人）→ 师（12,000—18,000人）→ 军**。

### 1. 大顺陆军组织（【拟定】）

- 最高层：大顺皇帝 → 枢密院/军务机关 → 战区总督 → 军 → 师。
- **七大军区**：北疆军区（蒙古、俄罗斯方向、东北）、西北军区（新疆、中亚、西域）、西南军区（西藏、云南、东南亚方向）、南洋军区（南海、南洋、马六甲）、京畿军区（皇室直属战略预备队）、东海军区（日本、台湾、东海）、新瀛军区（新瀛、太平洋）。
- **四级军制**：一等中央禁卫军（直属皇室，京师防御与对地方军事贵族制衡）；二等常备野战军（现代化程度最高）；三等良家子地方军（平时军屯、战时按军籍动员）；四等预备军（退役军人+训练良家子）。
- **顺制甲等步兵师（约15,500人）**：师部500 + 第1/2步兵旅（各4,500，各含2个团） + 师属炮兵旅2,000（2个75mm野战炮营+1个105mm榴弹炮营） + 师属骑兵营500 + 工兵营700 + 通信营400 + 辎重/卫生/军械1,400。步兵团约3,000人（3营+机枪连+团属炮连+工兵/通信/辎重）；营约800人（3步兵连+1机枪连）。
- **机枪集中制**（大顺特色）：不把马克沁下放到步兵班，而集中编组——营8—12挺、师36—48挺，形成"机枪营—步兵团—炮兵群"火力骨架。
- **良家子骑兵师（8,000—9,000人）**：3骑兵旅+骑炮兵团+机枪营+工兵营+侦察+辎重；任务转型为侦察、通信、追击、包抄、铁路保护、草原快速部署（部分下马步战）。
- **良家子军籍军**：每个良家子军事户籍地区拥有预备军籍，战时"农民→军籍→集结→补充野战军"，拥有庞大潜在动员人口；问题是军队贵族化。
- **大顺海军（五舰队）**：第一舰队东海舰队（京师—上海—日本方向）、第二舰队南洋舰队（南海—马六甲—东南亚）、第三舰队印度洋舰队（印度洋—东非—波斯湾）、第四舰队新瀛舰队（太平洋）、第五舰队北美远征舰队（平时规模小，战时跨太平洋投送）。

## 八、军制/军备年鉴·逐项确认机制（2026-08-01 确定）

> 来源：`历史与军制补充.md` 第二部分。为避免"先创造漂亮型号、后才发现国家无军工能力生产"的问题，军制与军备数据按以下流程**逐项锁定（Lock-in）**；未经确认的数字一律不得伪装成原设定。

### 1. 数据四状态规则

| 标记 | 含义 |
| ---- | ---- |
| 【设定】 | 原设定已经明确，不能随意修改 |
| 【锁定】 | 推演后经用户确认，成为正式世界观 |
| 【拟定】 | 当前建议值，可以修改 |
| 【待推演】 | 缺乏足够因果基础，不应先填数字 |

> 基本原则：不能因为现实1910年某国有多少师，就直接把数字搬进来——本世界科技中心、国家制度、工业结构、人口、殖民体系和战略环境都不同（"科学趋同，工业体系不同"）。

### 2. 确认流程顺序

**第一阶段 军队规模**（总人口→和平常备军→战时动员人口→预备役→地方/殖民军→海军人员→海军陆战队→边防军/宪兵→非正规力量）→ **第二阶段 陆军编制** → **第三阶段 步兵武器** → **第四阶段 机枪** → **第五阶段 炮兵** → **第六阶段 骑兵** → **第七阶段 工程兵与铁路兵** → **第八阶段 海军吨位** → **第九阶段 逐国海军战略** → **第十阶段 空军** → **第十一阶段 航空型号**。

### 3. 陆军编制方向（【拟定】）

- **大顺**：镇/军→师→旅→团→营→连；保留**良家子地方军事组织**与**新式中央陆军**两套体系（本世界最特殊处）；
- **德国**：军团→师→旅→团→营→连，强调铁路动员+参谋体系+工程兵+火炮；
- **法国**：重点确认师级炮兵比例（炮兵强国）；
- **英国**：本土军+印度军+自治领军+殖民地军+海军陆战队构建，非德国式大规模陆军。

### 4. 步兵武器原则（【拟定】）

- 【设定】唯一直接确认项：**栓动步枪属于1910标准军事技术**；
- 型号必须体现国家工业体系（大顺应有自己的枪械设计局→制式步枪→国家标准弹药→军工厂体系，不得"毛瑟换汉字名"）；
- 机枪：**重机枪已普及，轻机枪仍处于实验/少量装备阶段**（推荐倾向，最符合时代）。

### 5. 各国炮兵哲学（【拟定】）

法国=火力集中+速射炮+理论弹道学；德国=工程化+重炮+后勤标准化；英国=海军炮术技术向陆军扩散；俄罗斯=大口径+数量+简化生产；大顺=国家标准化+工程兵+重视攻坚和铁路炮兵。注意："法国炮兵强"不等于"法国所有火炮都比别国先进"。

### 6. 骑兵与工程兵（【拟定】）

- 骑兵已完成"骑兵→侦察/机动步兵"转型（胸甲/枪/骠/龙骑兵、骑炮兵、骑乘步兵、侦察骑兵）；**俄罗斯应拥有非常强大的骑兵传统**；**大顺良家子精锐骑兵贵族**为潜在特色；
- 工程兵与铁路兵：**德国**尤其突出（铁路作为向奥斯曼/中东扩张工具）；**大顺**应有河工兵、铁路兵、堡垒工程兵、攻城炮兵（可追溯至尼布楚战争学习沃邦攻城术）。

### 7. 海军舰种状态与战略方向

舰种状态：无畏舰【设定】开始出现、前无畏舰【设定】成熟、装甲巡洋舰/防护巡洋舰/轻巡洋舰/驱逐舰/鱼雷艇/潜艇/炮舰/海岸防卫舰/水雷舰【拟定】。"无畏舰开始出现"不可写成1910年末已完成全面换装。

**无畏舰革命（2026-08-05 拍板）**：本世界**由大顺最先引爆**——现实逻辑（德国海军法挑战英国→英国 Dreadnought 回应）在本世界不成立（德国=非决战舰队的海上工业舰队，见下），挑战英国海权的是大顺（五舰队、跨太平洋航线、新瀛/新燕、印度洋扩张）。大顺**定海级**全主炮战列舰为世界首型（首舰约1906年前后），"**定海级**"成为全球海军类别名词（如同现实 Dreadnought 成为类别名——各国称"定海级标准/定海型"战列舰）；英国被迫随后回应（**King Alfred级**为本世界英国无畏舰级，首舰约1908—1910，1910开局时"开始出现"状态）；扩散至区域强国：巴西（南美竞赛）、新瀛（扶桑海级，北京主导建造）。

各国海军战略方向：

- **大顺**：天下体系的军事工具——本土海防、南洋航线、新瀛交通、东非商站、朝贡国威慑、远洋外交、海外顺土运输（开海→海商→南洋→太平洋航线→新瀛→东非→法国支援→黑船事件的因果链）；**海军历史须与法国海军史一起推演**（第二次法国革命战争中的支援关系）；
- **英国**：世界最成熟的全球舰队体系之一，但**避免"英国自动世界第一"的现实套用**——优势集中于舰队部署、海外基地、海运、商船、海军工业、海洋科技；
- **法国**：大陆军事+海外共和国双重需求（地中海、大西洋、法属北美、非洲、印度洋）；
- **德国**：**大陆强国的海上工业舰队**（北海、波罗的海、商船保护、工业运输、海外有限投送），而非"为挑战英国而建的纯决战舰队"（非军国主义国家）；
- **俄罗斯**：**黑海舰队+波罗的海舰队**优先；太平洋舰队不会像现实那样成为国家战略中心（远东扩张失败）。

### 8. 空军原则与航空型号

- 严格压住科技树：1910只有军用飞机实验、侦察机、飞行训练、少量军方航空队；**不应大量存在**专业轰炸机部队、成熟战斗机体系、战略轰炸学说、大规模航空兵；各国航空兵规模以**几十架至数百架**为限；
- 航空型号（飞鸿系列/皇家侦察/法国鸢式/德国工程航空局系列/俄罗斯伊利亚系列等）**暂不锁定名称**——须先决定发动机工业、铝材、航空研究机构、军方航空组织后再创造。

### 9. 军备年鉴国家顺序（24个军事体系，2026-08-01 确定）

- **第一组（全球军事体系）**：大顺帝国、大英帝国、法兰西共和国；
- **第二组（欧洲陆权）**：德意志帝国、俄罗斯帝国、多瑙联邦、奥斯曼联邦帝国；
