# 05 经济卷

> 来源：`Settings/Settings/Economy.md`

---

## 一、总体判断

1910年世界经济可以概括为：

> **一个"第二次工业革命已经完成、全球市场已经形成，但全球统一经济体系尚未形成"的世界。**

| 领域 | 1910年大致状况 |
| ---- | ---- |
| 工业化 | 欧洲、北美、部分东亚高度工业化 |
| 全球贸易 | 极其发达，但存在大量关税壁垒 |
| 金融 | 国际资本流动高度发达 |
| 国家干预 | 明显高于现实19世纪中叶 |
| 企业 | 大型股份公司、银行、托拉斯已经出现 |
| 工人运动 | 已经成为重要政治力量 |
| 社会福利 | 部分国家开始建立 |
| 殖民经济 | 依然重要，但形式比现实更加多样 |
| 农业 | 仍占全球人口大多数 |
| 经济理论 | 古典自由主义仍重要，但已经受到严重挑战 |

它不是"自由资本主义世界"。更准确地说：

> **资本主义已经成为全球主要生产方式，但资本主义本身已经分化成了许多不同版本。**

---

## 二、最重要的分歧：不会形成"英国式自由贸易霸权"

现实世界19世纪全球经济体系的核心链条（英国工业化 → 英国海权 → 全球殖民体系 → 金融中心伦敦 → 自由贸易 → 全球市场一体化）在本世界**无法完全形成**。

因此：

> **世界经济是全球化的，但不是自由贸易化的。**

各大经济圈之间存在：关税、配额、航运优惠、殖民贸易特权、双边贸易协定、货币壁垒、国家银行体系、战略物资管制。

> 1910年全球贸易可能比现实世界还庞大，但贸易自由度反而不一定更高。

---

## 三、多中心资本主义（Polycentric Capitalism）

世界存在几个经济核心：

### 欧洲
依然是全球最重要的工业与金融中心之一，但不是一个整体：英国体系、法国体系、德国体系、意大利体系、中东欧体系、俄国体系彼此既竞争又贸易。

### 北美
十三州及其周边国家形成强大的**大陆工业资本主义**：大规模制造业、铁路、钢铁、石油、农业机械、银行、大企业、国内统一市场。它甚至可能比现实美国更强调**保护本国工业**（因为面对真正多极化的世界）。

### 东亚
出现**国家主导型工业资本主义**，经济思想强调富国强兵、工业化、铁路、钢铁、教育、国家银行、产业政策、技术引进，天然更接近**发展主义 + 国家资本主义**而非自由放任。

---

## 四、1910年的经济理论竞争

需区分"经济学界主流"与"政府实际采用的经济政策"。

### 1. 古典自由主义经济学
仍然是非常重要正统（Smith → Ricardo → Mill 及新古典经济学），但到1910年已很难再宣称"政府完全不应该干预经济"。

### 2. 国家主义经济学 / 历史学派经济学（对政策影响最大的传统）
核心思想：**市场必须服务于国家的工业化与社会稳定。** 特别适合本世界（没有英国式霸权让所有国家放心搞自由贸易）。

### 3. 保护主义
**保护主义会非常强，甚至可能成为1910年的"正常经济政策"**。典型国家经济政策：高关税、国家铁路、国家银行、军工采购、工业补贴、技术教育、大型企业、殖民地市场——已非常接近后来所谓"**发展型国家（Developmental State）**"。

### 4. 国家资本主义
**国家资本主义 ≠ 社会主义**。私人拥有工厂/银行、股票市场、企业追求利润，同时国家控制铁路、邮政、军工、矿产，补贴钢铁、扶持航运、保护本国企业。资本主义是一个连续谱：

> **自由资本主义 ←→ 国家资本主义 ←→ 社会主义**

### 5. 社会主义（第二大思想体系，不止一种）
- **① 改良主义社会主义**：普选、工人政党、社会保险、八小时工作制、累进税、劳工保护、公共教育，但不立即废除资本主义——逐渐演变为社会民主主义；
- **② 革命社会主义**：阶级斗争、无产阶级革命、生产资料公有化、消灭资本主义；1910年尚未形成现实1917年后那种高度成熟的共产主义政治体系，更可能是"马克思主义 + 本国革命传统"；
- **③ 工团主义**：工人应通过工会直接控制生产，而非先夺取议会——工会、总罢工、工人委员会、行业组织成为重要力量，尤其在法国、意大利、西班牙及部分拉美国家。

### 6. 合作主义（Cooperativism）
农民合作社、消费合作社、信贷合作社、工人合作社——不需要国家没收资本，也不需要完全放任资本，而是让生产者和消费者自己组织经济。在农业国家尤其有吸引力。

> **自由主义、国家主义、社会主义、合作主义四方竞争。**

---

## 五、农业经济与"土地问题"

1910年全球仍不是工业社会，一个重要理论问题是**"土地应该归谁？"**，尤其涉及拉丁美洲、东欧、俄国、奥斯曼体系、亚洲、非洲殖民地。

竞争的三派：

- **地主保守主义**：土地私有、大庄园、地租、地方政治权力；
- **农民主义**：土地归耕作者、反地主、土地改革；
- **社会主义农业理论**：土地国有/集体化。

### 拉美经济问题
典型国家同时存在出口地主、城市商业资产阶级、外资企业、本国工业资本家、城市工人、小农、无地农民。政策围绕：自由贸易还是保护主义？外资还是民族资本？大庄园还是土地改革？出口农业还是工业化？铁路矿山属外国资本还是国家？因此拉美容易发展出**民族发展主义**——"资本主义没有问题，但必须是我们的资本主义"。

### 殖民地经济：帝国经济学 vs 民族经济学
殖民国家出现**帝国经济学**（殖民地提供原料/农产品/矿产/廉价劳动力/战略资源，宗主国提供工业品/资本/技术/铁路/金融/行政，殖民地应成为帝国经济体系的"互补区域"）；殖民地民族主义者则称其为经济剥削。形成**殖民主义经济学 vs 民族经济学**的冲突，成为20世纪重要思想冲突。

## 六、金融理论

1910年仍处于**金本位时代**（黄金、中央银行、银行券、汇率、国际资本流动非常重要）。但由于世界是多极体系，不存在一个像现实伦敦那样绝对压倒性的金融中心，更可能是**多个金融中心竞争**。

> **伦敦 / 巴黎 / 柏林 / 纽约 / 阿姆斯特丹 / 东京 / 上海等共同构成世界金融网络。**

> ✅ **已结案（2026-08-05）**："东京金融中心"与"日本非列强"的张力已消解——江户（东京）为大顺"朝贡贸易港"（大顺实控），金融中心地位由大顺体系支撑，与日本列岛政权联合（未统一、非列强）并存不悖。详见 `11-政权清单` 东亚节。

国际金融总体特点：**多中心 + 国家化**。

---

## 七、经济危机与国家干预

工业资本主义存在周期性经济危机（银行危机、铁路泡沫、商品价格崩溃、失业、银行挤兑）。到1910年各国已逐渐认识到"经济完全不能靠市场自己解决"，于是：

- 中央银行、银行救助、失业救济、公共工程、农业价格支持、工业补贴逐渐成为政策工具。

注意：**凯恩斯主义在本世界不应提前出现**；但会出现其前身观念：**"国家有责任维持经济稳定。"**

---

## 八、1910年经济意识形态光谱

纵向轴（经济政策）大致为：

```text
自由放任
  │
  │   古典自由主义
  │
  ├── 自由贸易主义
  ├── 社会自由主义
  ├── 国家自由主义
  ├── 国家资本主义
  ├── 社会改革主义
  ├── 社会民主主义
  ├── 工团主义
  └── 革命社会主义
```

另有横向轴：**国际主义 ←→ 民族主义**。实际上不是一条线，而是一个二维甚至三维政治空间。

**经济政策与政治意识形态不会一一对应**：政治上自由主义但经济上高度保护主义、政治上保守主义但建立完善社会保险、政治上社会主义但仍允许大量私人企业、甚至"民族主义 + 自由市场 + 福利国家"都可能共存。

---

## 九、世界经济体系正式名称

**"多元工业资本主义体系"（Plural Industrial Capitalism）**，五个核心特征：

> **资本主义是基础；工业化是目标；国家是重要参与者；国际贸易高度发达但并不自由；社会主义与民族主义正在挑战传统自由主义。**

---

## 十、为HOI4经济系统提供的逻辑

建议不简单复制现实"民主/法西斯/共产/中立"划分，而让经济体系形成另一套维度：

| 经济体系 | 英文 | 特征 |
| ---- | ---- | ---- |
| 自由市场经济 | Laissez-faire | 低税、低政府支出、高私人投资、高贸易、低工业补贴 |
| 保护主义资本主义 | Protectionist Capitalism | 高关税、国家扶持工业、本国市场优先、较强军工体系 |
| 国家资本主义 | State Capitalism | 国家银行、国有铁路、工业计划、战略产业控制 |
| 社会改革资本主义 | Social Reform Capitalism | 社会保险、工人保护、累进税、工会合法化 |
| 社会主义 | Socialism | 公有制、工人组织、计划化程度提高 |
| 工团主义 | Syndicalism | 工会控制生产、行业自治、工人合作社 |

这样可与政治意识形态体系、阶层体系、各国政治光谱真正接起来，形成：

> **自由贸易派、保护主义者、国家发展派、社会改革派、社会主义者、工团主义者、农民主义者、民族经济主义者与帝国经济主义者共同争夺"工业时代应该怎样组织经济"这一问题。**

> **1910年的世界已经进入现代经济时代，但"现代经济应该是什么样"还远没有得到答案。**
