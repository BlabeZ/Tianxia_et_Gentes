# 天下与万邦（Tianxia et Gentes）

*Tianxia and Nations* — 一款基于《钢铁雄心4（Hearts of Iron IV）》的大型架空历史模组。

## 世界观

1644年，李自成率领大顺军在山海关击败吴三桂—清军联军，清朝未能入关。大顺统一中国，并延续至20世纪——中国没有退出世界体系，而是以大顺为核心建立了另一种现代国际秩序：**天下体系**。

1910年开局，世界呈多极格局，多套国际法体系并存：

- **天下体系**（北京）——朝贡、藩属、互市、礼制
- **威斯特伐利亚体系**（欧洲）——主权国家、国际法、民族国家
- **奥斯曼体系**（伊斯兰）

核心主题不是"谁会赢得下一次世界大战"，而是：

> 天下、民族国家、帝国、共和国、殖民地、保护国与新兴工业社会，究竟哪一种秩序能够定义20世纪？

——即多种文明现代性（官僚现代性、商业现代性、公民现代性、契约现代性、宗教现代性等）之间的竞争。
