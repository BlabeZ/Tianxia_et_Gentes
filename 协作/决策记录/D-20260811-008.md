## 正式表述

Git 输出统一以 UTF-8 解码。`handoff / validation-result / test-result / complete` 将当前主调度机器脱敏快照、任务台账和本次状态产物限定在同一自动提交内，拒绝其他工作区或暂存变更。

跨机交接不隐式访问网络。主调度器先显式 fetch，然后 handoff 核对本地或 `origin` 远程跟踪任务分支；如果两个 ref 同时存在但 tip 不一致，则默认拒绝。

15 分钟新鲜度和禁止未来时间规则保持不变，跨机调度前必须保证系统时钟已同步。OpenCode 权限表先做运行时 allow/deny 冒烟验证，不在没有失败证据时盲目改规则。

## 通俗解释

每次交接、审查或完成任务时，“机器体检卡”和“任务状态”会作为一个不可拆分的提交保存，不再依赖手工 `git add --all`。另一台机器的任务分支需先明着拉取；如果本地和远程分支对不上，系统宁可停下来，也不猜哪个才是真交付。
