# D-20260811-018：快照数据边界扩展（province 列表入库）

> 状态：已确认｜确认者：用户｜时间：2026-08-11T09:52:00Z

## 通俗解释

仓库里原来每个州只存了"有几个省份"这个数字。要重划州界并自动核对"每个省份恰好属于一个州、不重不漏"，就必须把每州的省份编号清单也存进仓库。清单只有编号和校验和，没有游戏文件原文，风险可控；换来的是所有机器（CI、本地、干跑）用同一份数据做全局核对，不再靠单台机器本地猜测。

## 正式表述

1. 受控快照 schema 升级至 v2（修订 D-20260811-004）：新增 per-state `provinces` ID 数组，与 `province_count` 一致性校验；快照仍为脱敏元数据。
2. 全局唯一归属不变量由统一校验器在 CI、本地与干跑三处一致执行，作为州界重划（阶段 1）的前置基础。
3. 本体安全模型不变：仅 `snapshot-export` 只读导出，subagent 无外部访问权。

## 影响文件

- `schemas/snapshot.schema.json`：v2，新增 provinces 字段
- `scripts/workflow.py`：parse_state/snapshot 校验/摘要渲染
- `tests/test_workflow.py`：快照相关测试
