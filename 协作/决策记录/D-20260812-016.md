# D-20260812-016：国家 tag 与国家文件采用独立受控快照

> 状态：已确认｜确认者：用户｜时间：2026-08-12T06:35:00Z

## 通俗解释

国家名单单独做一份“只看目录和校验码”的清单，不塞进州快照。以后国家文件变化不会无缘无故让州和工业任务一起过期。机器 C 只写工具和测试，机器 A 才能从本体导出真实名单。

## 正式表述

1. 新增独立的 country tag 快照 schema、JSON 与 Markdown 摘要。
2. 导出范围限定为 `common/country_tags` 的注册关系、注册所指向的 `common/countries` definition，以及 `history/countries` 中与 tag 对应的历史文件元数据。
3. 仅导出相对路径、存在状态、SHA-256、数量、指纹与版本，不导出脚本正文或本机绝对路径。
4. 真实快照审查前，不推断当前 HOI4 版本中哪些项目 tag 可复用。
