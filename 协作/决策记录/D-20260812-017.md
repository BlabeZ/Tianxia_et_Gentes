# D-20260812-017：跨平台交接路径与 state 合并来源一致性修复

> 状态：已确认｜确认者：用户｜时间：2026-08-12T06:55:30Z

## 通俗解释

Windows 生成的交接路径以后统一存成正斜杠，Linux 也能直接找到；同一个州被地域清单和经济清单共同修改时，两份清单必须确实指向同一份原版州文件，不能只因为改的字段不同就把错误路径或错误校验码吞掉。

## 正式表述

1. 持久化的仓库相对交接路径统一调用 `as_posix()`，并修复 T-011 历史字段。
2. `merge_override_documents` 在字段级合并前比较 `source_relative_path` 与 `source_sha256`；不一致即抛出确定性错误。
3. 保留 D-20260812-011 已确认的“不相交字段允许合并”语义。
