# D-20260812-011：跨清单字段级合并

> 状态：已确认｜确认者：main_agent｜时间：2026-08-12T02:45:00Z

## 通俗解释

之前规定"一个州只能被一份清单改"。但经济清单（只写工厂数）和地域清单（只写归属）都想碰同一个州——它们改的字段互不重叠。规则升级为：同一个州可以被多份清单改，只要它们改的是不同方面（一个改归属、一个改工厂，可以并存）；同一个方面被两个清单都改才拒绝。

## 正式表述

1. `merge_override_documents` 支持字段级合并：同 state 字段集不相交则合并，相交则拒绝。
2. 字段集：owner/controller/cores/manpower/state_category/resources/buildings/provinces。
3. 唯一归属、来源路径、指纹校验不变。
4. T-009 与地域清单由此并存。
