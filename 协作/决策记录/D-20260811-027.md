# D-20260811-027：任务交接范围排除原子租约控制面提交

> 状态：已确认｜确认者：主 agent（修复 T-011 交接门禁发现的区间计算缺陷）｜时间：2026-08-11T15:51:00Z

## 通俗解释

领取任务时，系统会先提交一次任务台账、环境快照和任务书输入。这些是“发施工证”的记录，不是执行者交付的成果。此前交接把这次发证记录也算进成果文件，导致合规的单文件交付被误判越界。现在从租约提交之后开始统计真正的施工文件。

## 正式表述

1. `base_commit` 继续保留租约前内容基线语义。
2. 仅当首个后继提交主题严格匹配 `lease <task_id> g<generation> @ <owner>` 时，将其识别为可信原子租约提交，并从该提交至 head 计算任务产出范围。
3. 新交接使用 handoff schema v2 与租约后范围；历史 schema v1 继续按原 `base..head` 复核，既有证据无需改写。
4. v2 交接登记和交接文件静态校验复用同一范围函数；没有标准租约提交时仍回退到旧基线。
