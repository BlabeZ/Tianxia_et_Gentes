# D-20260811-004：采用 full 机受控直接转换生成完整 state 文件

> 状态：已确认｜确认者：用户｜时间：2026-08-11T02:50:26Z

## 正式表述

Git 继续只保存最小化、脱敏的本体 states 元数据快照。主 agent 在具备 `snapshot_export` 与 `mod_execution` 能力的机器上，以只读方式消费本体 state 文件，应用仓库内经过校验的声明式改写数据，并将完整结果直接写入 `mod/history/states/`。本体原文不得写入快照或交给 subagent。

机器 C 仅实现转换器核心、声明式数据 Schema、测试夹具和静态门禁；此项实现不改变机器 C 的能力判定。

按地域执行任务只写入 `协作/state-overrides/*.json`，每条改写同时绑定整体快照指纹、来源相对路径与单文件 SHA-256。所有地域任务完成后，T-028 由具备本体能力的主 agent 汇总清单，为快照中的全部 states 一次性生成完整覆盖目录；subagent 不再直接复制或编辑本体 state 正文。

## 通俗解释

机器 C 先把“州文件改造机器”造好，用项目自带的假样本证明它会正确改、遇到不明确内容会拒绝。以后由有游戏本体的机器把真实州文件送进机器，成品直接进入 mod；真实原文件不会上传到 Git，也不会交给子代理。
