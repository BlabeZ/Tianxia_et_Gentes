# D-20260812-020：OpenCode filesystem MCP 变更工具拒绝门禁

> 状态：已确认｜确认者：用户｜时间：2026-08-12T07:54:30Z

## 通俗解释

机器B已经证明，subagent 虽然不能用普通编辑工具写越界文件，却能从 filesystem MCP 绕过去。现在把这类文件工具明确列为禁止，原本允许的受限目录编辑和检查命令保持不变。

## 正式表述

1. execute、scan、verify 显式拒绝 filesystem 写入、编辑、建目录、移动、复制、删除和替换工具。
2. 通过配置解析测试及本机 `opencode debug agent` 对三类 subagent 进行验证。
3. 不修改 OpenCode 全局配置，主 agent 不受影响。
4. T-040 已在三个 subagent 配置中加入七类显式 deny，统一校验与95项测试通过；本机 OpenCode 1.18.9 解析结果作为实测证据。
5. 完整交付区间为10个受控文件，任务书文件上限与实际范围一致。
