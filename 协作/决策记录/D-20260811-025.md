# D-20260811-025：任务领取时原子解析任务书动态输入

> 状态：已确认｜确认者：主 agent（执行既定任务书门禁）｜时间：2026-08-11T15:22:33Z

## 通俗解释

任务书要求开工时写清“用的是哪一版地图快照、从哪个提交开始”，但原来的领取命令只改了任务台账，忘了把这两个值写回任务书，导致任务刚领取就会被校验器拦住。现在领取命令会把任务书和租约一起提交：要么全部成功，要么拒绝开工。

## 正式表述

1. `task assign` 对存在任务书的任务解析当前快照整体指纹与租约前 `HEAD`。
2. `snapshot_fingerprint`、`base_commit`、环境快照、任务权威台账和派生台账在同一租约提交中原子落盘。
3. 动态输入无法验证时默认拒绝领取。
4. 增加临时 Git 仓库回归测试，验证任务书属于租约提交的必要范围。
