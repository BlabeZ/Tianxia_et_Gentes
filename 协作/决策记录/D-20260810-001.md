# D-20260810-001：多机多 agent 协作框架加固方案

> 状态：已确认｜确认者：用户｜时间：2026-08-10T10:51:22Z

## 正式表述

本项目采用受控本体元数据快照、单一主调度器、Python 标准库统一门禁、结构化任务状态、48 小时带隔离令牌的租约、独立任务分支、本地与 CI 双重验证、每机脱敏环境快照，以及跨工具共享的中立决策协议。

## 通俗解释

游戏本体不再交给 agent 直接碰；每台电脑只汇报“能做什么”而不泄露路径；任务由一个主调度器发放，每次发放都有会过期的通行证；旧 agent 即使恢复也不能把过期成果混进来；所有关键规则由同一套脚本在本地和 GitHub 上检查。

完整逐项决定以同名 JSON 文件为准。
