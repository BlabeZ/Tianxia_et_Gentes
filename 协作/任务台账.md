## 领取协议（必读）

1. `git pull --ff-only`
2. 选状态=待办的任务
3. 填：负责人/分支=`<任务ID>-<机器ID>`/领取时间/状态=进行中
4. `git add 协作/任务台账.md && git commit -m "lock <任务ID> @ <机器ID>" && git push`
5. push 被拒→他人已领，不得执行，重新 pull
6. 长程执行中每子步更新"最后心跳"并 commit+push
