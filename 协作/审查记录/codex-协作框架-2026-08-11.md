# Codex 审查：多机多 agent 协作框架

> 日期：2026-08-11｜决策依据：`D-20260810-001`

## 结论

协作框架的仓库内实现已通过统一校验与单元测试。审查中发现并修复三项会影响安全或后续任务流转的实现缺口：

1. 快照原先只检查 `schema_version`，结构不完整的快照可能误授 `mod_execution`；现已改为结构、哈希、排序、唯一性与自动摘要一致性校验，无效时默认拒绝。
2. subagent 的不发布环境自检原先仍会计算游戏本体 state 指纹；现已限定只有主 agent 的 `--publish` 模式可探测外部路径。
3. `tasks.json` 的普通领取/心跳/交接变化原先会被 CI 误判为协作政策变更；现已将生命周期字段与任务定义/政策字段分开判定。
4. Git 默认转义中文路径，完整提交区间校验会因此漏识别决策记录；现已在机器可读的变更文件读取中显式禁用路径转义。

同时修正了 POSIX 与 Windows 的 Python 3 入口说明，避免 Ubuntu 没有 `python` 命令时开工流程直接失败。

## 验证证据

- `python3 -m unittest discover -s tests -v`：15 项通过。
- `python3 scripts/workflow.py validate`：通过。
- `python3 -m py_compile scripts/workflow.py`：通过。

- `git diff --check`：通过。

## 能力边界

当前 C 机为 `light`：`dialog_development=true`、`static_validation=true`，无本体快照导出、mod 执行或加载测试能力。因此本次只完成仓库内实现与静态验证，未读取或修改游戏本体。
