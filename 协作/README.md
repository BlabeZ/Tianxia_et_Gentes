# 协作层

> 三种 agent（opencode 主力+subagent、codex 辅助、claude code 少量）的共享记忆与交接层。
> **开工第一步必读**：本文件 + `AGENTS.md` + `协作/任务台账.md`，并跑 `/env-check`。
> 完整框架设计见 `docs/协作框架.md`。

## 目录结构

```
协作/
├── README.md          # 本文件
├── 任务台账.md        # 任务状态机
├── 扫描产出.md        # subagent·扫描一次性产出（38 tag↔原版state映射表）
├── 交接单/            # 每个执行 subagent 完成时写一份
├── 审查记录/          # 验证 subagent + codex + claude code 输出
└── 会话记录/          # 长程 subagent/外部 agent 会话摘要
```

## 任务状态机

状态：**待办 / 进行中 / 待验证 / 待测试 / 完成 / 阻塞**

- `待测试`：验证通过但需加载测试（仅 full 机执行；light 机在台账标"待测试"→用户手动中继到 full 机）
- 其余状态流转：待办→（领取）→进行中→（交付）→待验证→（通过）→待测试/完成→（失败）→进行中

## 任务台账字段（机器可读表格）

| 任务ID | 模块 | 状态 | 负责人(机+工具) | 分支 | 领取时间 | 最后心跳 | 交接点 | 产出文件 | 阻塞项 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |

- **分支/领取时间/最后心跳**：支撑原子领取与过期锁恢复
- **交接点**：上一任务产出文件路径 + 下一任务入口

## 原子领取协议（防多机双重领取）

领取任务时**必须**按序执行，不得跳步：

1. `git pull --ff-only`（失败→停止，远程有新提交，先解决）
2. 读台账，选状态=待办的任务
3. 台账写：负责人=本机、分支=`<任务ID>-<机器ID>`、领取时间=现在、状态=进行中
4. **立即** `git add 协作/任务台账.md && git commit -m "lock <任务ID> @ <机器ID>" && git push`
5. push **被拒**（非 fast-forward）→ 他人已领，**不得执行**；重新 `git pull --ff-only` 读最新台账
6. push 成功 → 锁定生效，开始执行

**过期锁恢复**：进行中任务若 `最后心跳` 超过 24 小时未更新 → 其他机可声明"领取超时"、重置为待办并重新领取（先 pull，改负责人，push）。

**心跳**：长程执行中每完成一个子步，更新台账"最后心跳"时间并 commit+push（让其他机可见进度、避免被误判过期）。

## 会话摘要格式（长程恢复用）

```
## 会话：[agent] - [任务] - [日期]
- 已完成：...
- 决策点：...（拍板结论）
- 遗留/阻塞：...
- 下一入口：读 协作/扫描产出.md + 设定书 XX 卷
```

## 交接协议

每个 subagent 启动第一步 = 跑 `/env-check` + 读 `协作/README.md` + `AGENTS.md` + `协作/任务台账.md`（按原子领取协议领任务）+ 对应设定卷；结束 = 写交接单/审查记录 + 更新台账 + （长程）写会话摘要。

## 验证 subagent 检查清单（4 项）

1. **可溯源**：交接单每行"设定来源"列非空且指向设定书真实卷条——空或虚假=不通过
2. **硬约束3 合规**：改动文件路径全部在 mod 目录内（不触本体）——路径比对
3. **修订记录登记**：新增设定行已在 `设定书/00-总览与索引.md` 修订记录登记——查登记
4. **无擅自补全**：待定/待确认标注保留（未被静默填实）——标注扫描

## 多机能力档（二分模型 + 默认拒绝）

- **全功能机**（有本体，`capability_mode: full`）：可长程自动化+可测试+可扫描
- **轻量机**（无本体，`capability_mode: light`）：仅逐轮对话式开发（封锁 long_running/scan/test）
- 机器特定路径（game_path）见本机 `.opencode/local.json`（gitignore，不入库）；共享模板见 `.opencode/local.example.json`
- **默认拒绝**：local.json 缺失/无效/game_path 不可达 → 一律 light，不得未经用户显式确认自动升级
- 能力判定与开工许可由 `/env-check` command 执行（所有 agent 开工前必跑）
