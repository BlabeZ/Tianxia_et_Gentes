# 06 触发器（Triggers）

> 说明：`Triggers`/`Conditions` 页为完整列表（约 700+ 条），页面过大；本笔记收录核心概念与常用触发器。完整列表可用本体自带文档：`Hearts of Iron IV/documentation/triggers_documentation.md`。待抓取补充：Triggers 页全文（见 00 索引）。

## 1. 概念

- 触发器返回严格布尔值（true/false），**不改变游戏状态**；用于国策/决策可用性、事件触发、if 的 limit。
- 支持不等号简写：`has_stability > 0.5`、`date > "1936.1.1"`（等价于 compare 完整形式）
- 块内多条件默认 AND；可用 `OR = { ... }`、`NOT = { ... }`、`AND = { ... }` 组合
- 作用域触发器（any_/all_）：`any_country = { ... }`（任一满足即真）、`all_country = { ... }`（全部满足）
- 临时变量可在触发器块内修改（常规变量不行）

## 2. 常用触发器速查

| 类别 | 触发器 |
| ---- | ---- |
| 国家存在/状态 | `exists`、`tag = X`、`original_tag`、`is_at_war`、`is_in_faction`、`has_war_with`、`is_puppet`、`is_subject_of` |
| 政治 | **`has_government = <四极>`**、`has_ideology`、`has_ruling_party`、`has_elections`、`is_ai`、`has_political_power > x` |
| 旗标/变量 | `has_country_flag`、`has_global_flag`、`has_state_flag`、`has_variable`、**`check_variable = { var = x value = y compare = ... }`** |
| 数值 | `stability > x`、`war_support > x`、`threat > x`、`manpower > x`、`has_stockpile` |
| 外交 | `has_opinion`、`opinion > x`（对某国）、`has_war_treaty_with`、`has_wargoal_against` |
| 州 | `state = <id>`、`controls_state`、`owns_state`、`is_controlled_by`、`is_core_of`、`has_state_flag` |
| 时间 | `date > "1936.1.1"`、`has_global_flag = { flag = x days > 30 }` |
| 事件/决策 | `has_country_flag`（标记事件发生）、`has_completed_focus`、`has_ideas`、`has_available_idea_with_traits` |
| 作用域成员 | `any_country`、`any_owned_state`、`any_enemy_country`、`any_neighbor_country`、`every_*`（效果侧） |
| 其他 | `has_dlc = "Man the Guns"`、`has_cosmetic_tag`、`num_of_* > x` |

## 3. 本项目使用（T-043/T-045/T-046）

- `has_government = neutrality/democratic/...`：TXG_validate_project_party_state 核对引擎四极 ✓
- `has_variable = TXG_axis_e` 等：7 变量完整性检查（fail-closed）✓
- `check_variable = { var = X value = Y compare = less_than_or_equals }` 完整形式（D-20260815-005：引擎简写仅支持 </>，`<=`/`>=` 必须用 compare 完整形式）✓
- 好感网络分派 `has_country_flag = TXG_party_state_ready` ✓
- 后续事件/国策会用 `has_government`、`has_country_flag`、`check_variable` 判型
