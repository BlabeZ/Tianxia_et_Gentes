# 02 文件结构与加载机制

> 来源：HOI4 官方 wiki `Modding` 页（2026-08-16 抓取），CC BY-SA 3.0。

## 1. 加载顺序（load order）

从低优先级到高优先级：

1. **本体**（base game）
2. **DLC**（按内部 ID/发售日期顺序）
3. **用户目录**（`Hearts of Iron IV/` 下的 nudger 输出等，优先级高于本体）
4. **Mods**（按用户 descriptor 文件名 ASCII 顺序；可用 `dependencies = { ... }` 调整）

关键规则：

- 同名同路径文件：**只读后加载者**，旧文件被忽略（只针对单个文件，不针对整个文件夹）。
- **`replace_path` 不改顺序**，但会完整卸载指定文件夹此前加载的所有文件。
- 除 replace_path 外无法"卸载"文件，只能同名覆盖。
- DLC 文件夹（modname/dlc/...）不会被加载——DLC 代码在本体里，用 `has_dlc` 检查。
- `modname/test/common/national_focus/` 这种多插一层文件夹的路径**不生效**（必须与本体目录结构对齐）。

## 2. 解释/求值阶段（interpretation/evaluation）

- 加载时文件保持纯文本，**不立即解释**；加载屏幕与本地化除外。
- 之后解释阶段读取文本创建内容（国策/国家/州等）。
- **文件名通常不影响解释方式**（除少数例外）：
  - 由所在文件夹决定类型（如 common/national_focus 下全是国策）
  - 或由其他文件直接引用（如国家历史文件里 `oob = "TAG_1936"` 加载 history/units/TAG_1936.txt）
- **同名条目重复定义的处理因文件类型而异**：有的取先创建（state：先定义者优先），有的取后（sprite：后定义者覆盖），有的报错（国策重复破坏前置线）。
- 解释顺序通常按**文件名 ASCII 排序**：`00_` 前缀放最前，`zz_` 放最后（ASCII 中大写字母在小写之前、下划线在其间）。我们 mod 用 `00_txg_*` 前缀即此惯例。
- 国家 tag 定义顺序（common/country_tags）影响：历史文件求值顺序、事件/决策/国策求值顺序、作用域多国选择顺序、附庸支持度正确性。

## 3. Checksum（校验和）

- 主菜单版本号旁的 4 位字母数字码；决定联机/成就兼容。
- 变更清单见本体 `checksum_manifest.txt`：包括整个 common/、events/、history/ 与大部分 map/（不含 map/terrain/）。
- 不触及这些文件夹的 mod 不改变 checksum。

## 4. 文件夹结构（常编辑目录）

| 目录 | 内容 |
| ---- | ---- |
| `common/` | 几乎所有数据库条目：国家、科技、国策、意识形态、scripted effects/triggers、on_actions、opinion_modifiers、defines 等 |
| `events/` | 事件定义 |
| `history/` | 开局信息：国家归属、初始政治外交、军队位置、初始建筑；`history/states/` 定义州边界（provinces 字段） |
| `map/` | 地图外观（省/地形/高度图）、战略区域、开局铁路与补给节点 |
| `localisation/` | 文本显示（按语言） |
| `gfx/` | 图片；多数需经 interface/*.gfx sprite 链接，例外：loadingscreens、flags（按意识形态/装饰 tag 加载）、equipment designer graphic_db |
| `interface/`（非 gfx/interface） | `*.gfx`（sprite/字体/文本颜色/地图箭头定义）与 `*.gui`（界面布局） |
| `music/`、`sound/`、`portraits/` | 音乐、音效、随机角色肖像 |

## 5. 用户目录（User directory）

- 由本体 `launcher-settings.json` 的 `gameDataPath` 决定。
- 用户目录 `mod/` 存 descriptor；nudger 输出（map/history/states/localisation）会被加载且**优先级高于本体**；logs/save games/screenshots/settings.txt 也在其中。
- `settings.txt` 含无法在设置菜单改的项：`save_as_binary=no`、默认文本编辑器。

## 6. 属性顺序规则（order of attributes）

- 效果与触发器：**顺序敏感**，按放置顺序执行（例：先 annex 再检查被吞国拥有某州——检查恒为假）。
- 修改器（modifiers）：顺序无关，tooltip 顺序硬编码。
- 同一条目不同属性（如国策的 reward 与 x/y 位置）：顺序无关。
- 同类数据库条目：文件内位置决定创建顺序（如决策顺序、建筑顺序、**意识形态顺序**）；装备必须先有 archetype，否则崩溃。
- 同类属性重复定义：视类型而定（事件多个 immediate 依次执行；scripted localisation 取第一个满足 trigger 的 text）。
