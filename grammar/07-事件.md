# 07 事件（Events）

> 说明：`Event_modding` 页待抓取补充（见 00 索引）；本笔记收录基础结构与本项目规划。事件文件索引见 wiki `Events` 页（events/ 文件夹清单）。

## 1. 事件结构（country_event 示例）

```pdx
country_event = {
    id = my_event.1                # 命名空间.编号（命名空间在 common/namespaces/ 或事件文件内 namespace = my_event）
    title = my_event.1.t           # 本地化 key
    desc = my_event.1.desc
    picture = GFX_event_picture    # 可选：interface/*.gfx sprite

    is_triggered_only = yes        # 只由效果触发（否则用 days/hours 定时触发）

    trigger = {                    # 触发条件（定时事件在日期检查）
        has_country_flag = my_flag
    }

    immediate = {                  # 触发时立即执行（可多个，依次执行）
        set_country_flag = my_flag_done
    }

    option = {
        name = my_event.1.a        # 选项本地化 key
        trigger = { ... }          # 选项可见条件（可选）
        ai_chance = {              # AI 选择权重（可选）
            base = 50
        }
        add_stability = 0.1        # 选项效果
    }
    option = {
        name = my_event.1.b
        ...
    }
}
```

- 触发：`country_event = { id = my_event.1 days = 10 random_days = 5 }`（效果，在任意效果块）
- 作用域：事件 ROOT=收到国；FROM=发出国（用 country_event 效果触发时=效果执行国）；`event_target:` 可传额外作用域
- 事件类型：`country_event`（国家）、`state_event`（州）、`news_event`（新闻弹窗）
- 命名空间：`namespace = my_event`（文件内定义一次，防 ID 冲突）
- 本地化：`my_event.1.t`（标题）、`my_event.1.desc`（描述）、`my_event.1.a`（选项文本）

## 2. 触发方式

| 方式 | 说明 |
| ---- | ---- |
| `country_event = { id = X days = 0 }` | 效果立即触发（days/hours 延迟、random_days 随机延迟） |
| 定时（无 is_triggered_only） | 在 trigger 满足时按 days/hours 参数自动触发 |
| `random_events = { 权重 = 事件ID }` | on_actions 内按权重随机触发一个 |
| 决策/国策完成 | complete_effect/cancel_effect 中触发 |
