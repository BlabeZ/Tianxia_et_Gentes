# 13 意识形态模组（Ideology modding）

> 来源：HOI4 官方 wiki `Ideology modding` 页（2026-08-16 抓取），CC BY-SA 3.0。

## 1. 定义格式（common/ideologies/*.txt）

```pdx
ideologies = {
    anarchist = {
        types = {
            anarcho_syndicalism = {
                can_be_randomly_selected = no
                color = { 169 42 42 }        # 可选，缺省用母极色
            }
        }
        dynamic_faction_names = { "FACTION_NAME_ANARCHIST_1" }
        color = { 169 42 42 }                # 饼图/相邻图标颜色（RGB）
        rules = {                            # yes/no
            can_declare_war_on_same_ideology
            can_force_government             # 必填：和平协议中可改政体
            can_send_volunteers              # 必填
            can_puppet                       # 必填
            can_only_justify_war_on_threat_country
            can_guarantee_other_ideologies
        }
        can_host_government_in_exile = no
        war_impact_on_world_tension = 0.2    # -1 ~ 1
        faction_impact_on_world_tension = 0.3
        modifiers = {                        # 任意国家修改器
            generate_wargoal_tension = 0.5
            join_faction_tension = 0.5
            take_states_cost_factor = 0.25
            drift_defence_factor = 0.3
        }
        can_be_boosted = no
        faction_modifiers = { faction_trade_opinion_factor = 0.50 }
        ai_<ideology> = yes                  # 绑定 AI：democratic/communism/fascism/neutral
    }
}
```

- 子意识形态类型（types）用于分配领导人；`can_be_randomly_selected = no` 阻止随机领导人使用
- AI 和平行为：`common/ai_peace/*.txt`（每个意识形态一个文件；不调整会倾向用 1_fascist.txt）

## 2. 本地化

- 意识形态 3 个 key：`my_ideology`（形容词）、`my_ideology_noun`（名词）、`my_ideology_desc`（书签选择界面一行短描述）
- 子类型：`my_subideology`、`my_subideology_desc`（悬停图标显示）；国家专属：`POL_my_subideology_desc`
- 国家意识形态国名：`TAG_my_ideology`、`TAG_my_ideology_ADJ`、`TAG_my_ideology_DEF`（the 冠词）、`TAG_my_subideology`（子类型专属名）
- 漂移本地化：`my_ideology_drift:0 "Daily Ideology Support"`（modifiers_l_english.yml）
- 未定义国家专属名时用通用 `TAG:0 "国名"`；`[GetNonIdeologyName]`/`$NONIDEOLOGY$` 引用

## 3. GFX（图标 sprite）

- `interface/*.gfx` 的 `spriteTypes = { spriteType = { name = GFX_ideology_<name>_group texturefile = ... } }`
- 子类型专属：`GFX_ideology_<name>`；国家专属：`GFX_ideology_<TAG>_<name>_group`
- sprite 重复定义：后求值者优先（zz_ 前缀文件覆盖）——**不要复制整份 .gfx 文件**（更新后缺 sprite 显示 error dog）

## 4. 国家历史接入（本项目 T-045 核心）

```pdx
set_politics = {
    ruling_party = democratic
    last_election = "1932.5.1"
    election_frequency = 48
    elections_allowed = yes
}
set_popularities = {   # ⚠ 必须加总为 100，否则意识形态显示损坏
    democratic = 69
    fascism = 1
    communism = 30
}
create_country_leader = {
    name = "Édouard Daladier"
    desc = "POLITICS_..._DESC"
    picture = "Portrait_....dds"
    expire = "1965.1.1"
    ideology = socialism
    traits = { stout_defender }
}
```

- **本项目 T-045 确认**：set_popularities 执政党极=100 其余=0 → 总和 100 ✓ 合规
- 四极壳（democratic/communism/fascism/neutrality）为引擎槽；我们的 40 子类型挂在壳内 types，`can_be_randomly_selected = no` 控制随机生成（T-043 已实现）

## 5. 政治顾问（意识形态推进者）

- `common/country_leader/*.txt` 定义 `<ideology>_booster` trait（`<ideology>_drift = 0.1`）
- 通用顾问放 `common/ideas/zzz_generic.txt`（确保后加载）；`do_effect = { NOT = { has_government = <ideology> } }`
