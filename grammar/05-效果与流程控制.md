# 05 效果（Effects）与流程控制

> 来源：HOI4 官方 wiki `Effect` 页（2026-08-16 抓取，含重定向自 Scripted effects），CC BY-SA 3.0。原文：`grammar/_sources/Effect.md`。

## 1. 效果概述

- 效果（Commands）在特定作用域内一次性改变游戏状态；持续效果用 modifiers（常经 `add_ideas` 应用）。
- 效果常用于：国策奖励（completion_reward）、事件选项（option）、决策效果、on_actions、历史文件。
- 参数可用变量：`add_manpower = var:my_var`。
- 完整清单：本体 `documentation/effects_documentation.html|md`（游戏自带离线文档）。

## 2. If 语句（条件执行）

```pdx
if = {
    limit = {
        has_political_power > 0
        stability < 0.9
    }
    add_stability = 0.1
}
```

- `limit = { ... }` 为触发条件块；满足才执行内部效果；**省略 limit 默认恒真**。
- 效果必须放在 if 块内才受条件约束（块外效果无条件执行）。
- 分支：`else_if = { ... }`（可多个，依次检查）与 `else = { ... }`。
- **两种写法：嵌套（else_if 放在 if 内部）与非嵌套（紧随其后）；重叠时非嵌套优先**。
- tooltip 只显示会执行的效果；未满足的 if/else 分支对玩家隐藏。

## 3. 随机效果

```pdx
random = {          # 80% 概率执行，20% 无事发生
    chance = 80
    add_stability = 0.4
}
random_list = {     # 权重制（不必和为 100）
    10 = { add_stability = 0.5 }
    10 = { add_manpower = 10000 }
    my_variable = { army_experience = 100 }   # 变量作权重
}
```

- random_list 选项可用 `modifier = { factor = ... }` 调整权重。
- 可重复决策默认同一次游戏内随机结果相同；加 `fixed_random_seed = no` 反转（仅决策）。

## 4. Tooltip 操作

- `hidden_effect = { ... }`：执行但不在 tooltip 显示
- `effect_tooltip = { ... }`：显示但不执行
- `custom_effect_tooltip = my_loc_key`：显示任意本地化段落（本地化 key 在 `_l_english.yml`，UTF-8-BOM）

## 5. Meta effects（元效果）

- 用变量/scripted localisation **动态构建效果**（非动态效果不接受变量）：

```pdx
meta_effect = {
    text = {
        add_equipment_to_stockpile = {
            type = [EQ_TYPE]_[EQ_LEVEL]
            amount = eq_amount
        }
    }
    EQ_LEVEL = "[?eq_level|.0]"
    EQ_TYPE = "[This.GetEquipmentName]"
}
```

- `debug = yes` 打印最终效果到 game.log。

## 6. Scripted effects（脚本化效果）

- 定义于 `common/scripted_effects/*.txt`，作为函数复用；**不会自行执行**，需被调用：

```pdx
my_scripted_effect = {
    add_stability = 0.1
}
# 调用：
my_scripted_effect = yes
```

- 控制台可直接执行：`e my_scripted_effect`
- 自定义控制台命令：名称以 `d_` 开头（控制台命令本身不含 d_）；命令行参数存入 `args` 临时数组
- **scripted effects 不支持 `$VAR$` 参数传递**（wiki 无此机制；本项目 D-20260815-004 实测一致）——需要参数时用内联展开或 meta_effect
- 本体内置有用 scripted effects：`add_ruling_to_dem`（执政党支持度并入民主极）、`store_core_states_on_game_start`、`lerp` 等
