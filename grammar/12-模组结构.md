# 12 模组结构（Mod structure / Replace path）

> 来源：HOI4 官方 wiki `Modding` 页（Mod structure / Descriptor contents / replace_path 章节，2026-08-16 抓取），CC BY-SA 3.0。

## 1. 双 descriptor 文件（.mod）

每个 mod 有两个 `.mod` 文件：

| 文件 | 位置 | 作用 |
| ---- | ---- | ---- |
| **用户专属 descriptor** | 用户目录 `mod/<name>.mod`（文件名决定加载顺序；不能含空格；如 `pdx_39436001.mod`、`ugc_1234567890.mod`） | 加载信息，**path 只在此定义**（因用户而异） |
| **mod 专属 descriptor** | mod 根目录内 `descriptor.mod` | 与用户无关的共享信息 |

- 两者内容应基本一致；launcher 只强制同步部分字段（`replace_path` 不会自动同步，**必须两边都写**）
- launcher 创建 mod：All installed mods → Upload mod → Create a mod（路径/参数受限，可手动编辑）

## 2. descriptor 字段

```pdx
name = "Average mod"                    # 唯一；dependencies 里按名字引用
path = "mod/modname"                    # 仅用户专属文件；严格正斜杠 /；只允许 ASCII 路径
picture = "thumbnail.png"               # mod 根目录内，<1MB
version = "v1"                          # 仅显示
supported_version = "1.13.*"            # 星号通配小版本；否则显示 out of date
tags = { "Gameplay" "Historical" }
remote_file_id = "1678247250"           # 绑定 Steam/Paradox 工坊
user_dir = "NewSaveFolder"              # 改存档目录（隔离存档）
dependencies = { "Major Mod" }          # 强制本 mod 在依赖之后加载（子 mod 必需）
replace_path = "history/states"         # 卸载指定文件夹此前加载的所有文件
```

## 3. 相关用户目录文件

- `dlc_load.json`：启用 mod 列表（`"mod/modname.mod"` 形式）+ 禁用 DLC；launcher 自动改写；多个 enabled_mods 定义取第一个（可做无 launcher 的播放列表）
- `launcher-v2.sqlite`：launcher 的 mod/playset 数据库；损坏时可删除重建（本地 mod 不会自动加入 playset）

## 4. replace_path 语义（重要）

- **卸载主菜单加载时指定文件夹内所有已加载文件**（只作用于该文件夹直接文件，子文件夹不动）
- **不改变加载顺序**；不保证 mod 文件被读取（低优先级 mod 的文件仍会被高优先级覆盖）
- 只卸载"索引式"文件；**直接引用式不生效**：`replace_path = "history/units"`（oob 直链）、`"gfx/flags"`（国旗按需加载）、主菜单背景（sprite 直链）
- **必须写在两个 descriptor 里**：mod 专属漏写 → launcher 会从用户专属删除；用户专属漏写 → 不生效
- **慎用**：某些文件夹不能为空（national_focus 为空崩溃；scripted triggers 有隐藏用法），replaced 文件夹内 mod 至少要有 1 个有内容的文件
- 例：`replace_path = "history/states"`（大地图 mod 接管州定义——本项目如接管全州可考虑，但当前策略是同名覆盖+新增，未用 replace_path）
