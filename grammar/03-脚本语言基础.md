# 03 脚本语言基础（语法）

> 来源：HOI4 官方 wiki `Modding`（Code structure / Indenting）、`Effect` 页（2026-08-16 抓取），CC BY-SA 3.0。

## 1. 基本结构

```pdx
<attribute> = <argument>
```

- 触发器/条件类偶用不等号：`has_stability > 0.5`
- 每个 attribute 与 argument 是**单个词**（词字符含 `[a-zA-Z0-9_.,\-/]`），空白为分隔符
- 少数情况 argument 可省略（如 add_ideas 展开式）；**省略参数/等号几乎总是错误**（`GER = { leave_faction }` 应为 `leave_faction = yes`）

## 2. 参数类型

- **字符串**：双引号 `"` 包裹；空格不打断字符串，但**直接换行打断**；无空白时引号可省略（`date > "1936.1.1"` 与 `date > 1936.1.1` 等价）
  - 转义仅两个：`\"` 与 `\\`；字符串内不能直接换行；最长 **255 字符**（不含 null）
  - 属性名也可加引号：`"TAG" = { ... }`
- **花括号块**：`random_country = { add_stability = 0.1 }`——参数为一整块代码；块内递归 `<attribute> = <argument>` 结构
  - 若属性不支持块，花括号会被当作参数本身（`transfer_state = { 123 321 }` → 试图转让 id 为 `{` 的州 → 作用域错误）
- **本地化键**：显示给玩家的文本用本地化 key（可超 255 字符、支持动态文本）；未定义 key 时引擎直接显示参数原文

## 3. 注释

- `#` 到行尾全部忽略；**无多行注释**

## 4. 空白与换行

- 注释与字符串之外，**换行等价于空格**（整文件单行也能跑）
- 缩进只为可读性；但**属性参数绝不可留空**（`icon = ` 会把下一行属性名当参数）

## 5. 缩进规范（官方推荐）

- 文件首行零缩进
- 开括号与对应闭括号在同一缩进层级
- 引入未闭合开括号的行，其内部内容右移一级
- 一行最多一种括号各一个；纯闭括号行不应有其他内容

```pdx
TAG = {
    if = {
        limit = {
            has_stability > 0.5
            has_war_support > 0.5
        }
        country_event = { id = my_event.1 hours = 1 }
    }
}
```

常见缩进错误：提前退格、闭括号层级错位、未闭合开括号后写兄弟条目、相邻行差两级缩进——都会导致括号错误破坏整个文件。

## 6. 常见参数块类型

| 类型 | 用途 | 说明 |
| ---- | ---- | ---- |
| Effects 效果 | 一次性改变游戏状态 | 国策奖励/事件选项/决策效果/on_actions/历史文件 |
| Triggers 触发器 | 条件检查 | 返回布尔，不改变状态 |
| Scopes 作用域 | 切换效果/触发器的执行对象 | 国家/州/角色/师等 |
| Modifiers 修改器 | 持续数值效果 | 如每日政治点产出；常经 ideas 应用 |

## 7. 数值与变量

- 效果参数可用变量：`add_manpower = var:my_var`（`<variable>` 标记）
- 完整效果清单见本体 `documentation/effects_documentation.html|md`（游戏自带的离线文档！）
