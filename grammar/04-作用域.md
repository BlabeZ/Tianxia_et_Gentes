# 04 作用域（Scopes）

> 来源：HOI4 官方 wiki `Effect` 页（Scopes 章节，2026-08-16 抓取），CC BY-SA 3.0。完整作用域表见原文 `grammar/_sources/Effect.md`；`Scopes` 页为权威大全（本项目仅收录常用项）。

## 1. 双作用域（Dual scopes：可作为效果或触发器作用域，也可作目标）

| 名称 | 说明 | 例 |
| ---- | ---- | ---- |
| `TAG` | 国家作用域（tag 别名见 common/country_tag_aliases） | `SOV = { country_event = my_event.1 }` |
| `<state_id>` | 州作用域 | `123 = { transfer_state_to = SCO }` |
| `<character>` | 角色作用域 | `ENG_theodore_makhno = { set_nationality = UKR }` |
| `mio:<MIO>` / `sp:<project>` | MIO / 特殊项目 | `sp:sp_land_flamethrower_tank = { ... }` |
| **ROOT** | 块根节点（国策=做国策的国家；事件=收事件国）；某些块无 ROOT（如 on_startup） | `declare_war_on = { target = ROOT }` |
| **THIS** | 当前作用域（显式引用，主要用于变量与本地化） | `set_temp_variable = { target_country = THIS }` |
| **PREV** | 上一外层作用域；可链 `PREV.PREV` | `FRA = { random_country = { GER = { declare_war_on = { target = PREV } } } }` |
| **FROM** | 块的次要硬编码作用域（事件=发事件国；定向决策=目标国）；可链 `FROM.FROM` | `FROM = { load_oob = defend_ourselves }` |
| `overlord` / `faction_leader` / `owner` / `controller` / `capital_scope` | 宗主/阵营领袖/所有者/控制者/首都州 | `owner = { add_ideas = ... }` |
| `event_target:<key>` / `var:<variable>` | 事件目标 / 变量作用域（var: 必需作作用域，作目标可省） | `event_target:my_target = { ... }` |

## 2. 效果作用域（Effect scopes：只能作效果）

- **国家**：`every_country`（满足 limit 的每国）、`random_country`（随机一国）、`every_possible_country`（含不存在国家）、`every_other_country`/`random_other_country`（除自身）、`every_neighbor_country`（邻国）、`every_occupied_country`、`every_allied_country`/`every_enemy_country`、`every_subject_country`、`every_faction_member`、`every_country_with_original_tag`（需 original_tag_to_check）
- **州**：`every_state`/`random_state`（可 prioritize）、`every_neighbor_state`、`every_owned_state`/`random_owned_state`、`every_core_state`、`every_controlled_state`、`random_owned_controlled_state`
- **其他**：`every_unit_leader`/`every_army_leader`/`every_navy_leader`、`every_operative`、`every_character`/`random_character`、`every_country_division`/`every_state_division`、`every_military_industrial_organization`、`every_scientist`、`every_collection_element`（1.17 集合）
- 作用域内常用 `limit = { ... }` 过滤；例：

```pdx
every_country = {
    limit = { has_country_flag = TXG_party_state_ready }
    TXG_opinion_network_CHI = yes
}
```

## 3. 会改变作用域的效果

- `start_civil_war` → 切换至叛乱动态国家
- `create_dynamic_country` → 切换至新建动态国家

## 4. 本项目实践（T-046/T-049 对照）

- on_actions 中 `every_country` + 标签作用域 `CHI = { has_country_flag = ... }` 判型分派 ✓
- `has_government = X` 判引擎四极；`check_variable` 判五轴 ✓
- ROOT 语义：on_ruling_party_change 中 ROOT=换党国 ✓
- 好感网络 remove/add 的 `target = <TAG>` 即双作用域作目标的用法 ✓
