# 09 本地化（Localisation）

> 来源：HOI4 官方 wiki `Localisation` 页（2026-08-16 抓取），CC BY-SA 3.0。原文：`grammar/_sources/Localisation.md`。

## 1. 文件规范（快速检查清单）

1. 扩展名 `.yml`；文件名（去扩展名）必须含语言内部名：`filename_l_english.yml`、`xx_l_simp_chinese.yml` 等（l 是小写 L）
2. **必须 UTF-8-BOM 编码**（EF BB BF 开头）；否则游戏报错
3. 首行 `l_english:`（语言数据库声明，语言名+冒号）
4. 条目格式：`localisation_key:0 "Localisation value"`
   - **key 只能**：英文字母、下划线、点、连字符、数字（其他字符破坏文件）
   - 版本号 `0` 只含数字（可省略）；引擎不读取
   - **值必须一行内**（换行用 `\n` 转义，`\"` 转义引号）；值可用几乎任何可打印字符（缺字显示 ?，换字体解决）
5. 语言在用户目录 `pdx_settings.txt` 选择；语言列表固定（含 `l_simp_chinese` 简体中文）

```yml
l_simp_chinese:
  TXG_opinion_close: "坐标相近"
```

## 2. 覆盖与替换

- key 重复：text.log 记录重叠；取值优先级不确定（倾向本体文件）
- **`localisation/english/replace/` 文件夹内文件优先**——只覆盖特定 key 无需搬运整文件（推荐做法）

## 3. 颜色代码（§ 格式）

- `§X` 开始着色、`§!` 结束（**必须成对**，否则溢色）；Windows 输入 § 用 Alt+21
- 常用：`§B`蓝 `§G`绿 `§R`红 `§Y`黄 `§W`白 `§C`青 `§O`橙 `§H`黄(标题) `§T`白(标题) `§L`灰橙 `§g`浅灰；`§0`-`§t` 为渐变阶
- 示例：`"§B蓝色§!与§R红色§!"`；新颜色可扩展 `interface/core.gfx` 的 `textcolors = { ... }`
- 常见错误：`§M`（无效色）、`§` 后跟空格、字符串以 `§` 结尾（id '0' 错误）

## 4. 变量显示（[?var|格式化]）

- `[?my_var]`（? 必须有）；作用域：`[?GER.var_name]`
- 格式化字符（`|` 后）：`0-9` 小数位（最多 5）、`%` 百分比×100、`%%` 追加 %、`+`/`-` 正负着色、`*`/`^` SI 单位（K/M）、`=` 正负号前缀、颜色字母（如 `Y` 黄）
- 示例：`[?party_popularity@democracy|%G0]`（民主支持度，绿，整数百分比）、`[?var_name|.1]`（1 位小数）
- `$LEFT$`/`$RIGHT$`：add_to_variable 等操作前后值（配 `tooltip = key` 参数）

## 5. 文本图标与嵌套

- 图标：`£icon_name`（interface/*.gfx 的 spriteType，需 `legacy_lazy_load = no` 多帧）；帧：`£icon_name|1`
- 嵌套本地化 key：`$OTHER_KEY$`；美元符本身：`$$`
- **Bindable localisation（1.15+）**：`custom_effect_tooltip = { localization_key = key NAME = "John" }` 动态绑定 $NAME$ 等
- 内部变量：`$OVERLORDADJ$`、`$NONIDEOLOGY$`（附庸国名）等

## 6. 命名空间（动态文本，[Scope.GetXxx]）

- 语法：`[ROOT.GetName]`、`[GER.GetRulingParty]`、`[123.owner.GetName]`、`[OMA.capital.GetName]`（变量链）
- 国家函数：GetName/GetNameDef/GetNameDefCap（DEF 冠词）/GetAdjective/GetTag/GetFlag/GetNameWithFlag/GetRulingParty/GetRulingPartyLong/GetRulingIdeology/GetNonIdeologyName/GetLeader/GetManpower/GetFactionName/GetLastElection/GetDateText/GetDate 等；四极政党：GetCommunistParty/GetDemocraticParty/GetFascistParty/GetNeutralParty（+GetXxxLeader）
- 州：`[123.GetName]`、`[GetID]`；角色：`[USA.USA_franklin_delano_roosevelt.GetFullName]`（先入国家）
- **可用位置有限**：国策（标题需 `dynamic = yes`）、想法/动态修改器、决策、事件、自定义效果/触发 tooltip（不支持 scripted localisation）、旗标 tooltip、操作等
- 例：`"§Y$NAME$§! 的决议"`、`"[ROOT.GetNameDefCap] 向 [THIS.GetNameDef] 宣战"`

## 7. Scripted localisation（脚本化本地化）

- 定义于 `common/scripted_localisation/*.txt`（如 `defined_text = { name = GetEquipmentName text = { trigger = {...} localization_key = "..." } }`）
- 按 trigger 选择文本；`[This.GetEquipmentName]` 调用
- 用于变量驱动的动态文本（本项目 meta_effect 示例即用此）

## 8. 本项目实践（T-043/T-045 对照）

- `mod/localisation/english|simp_chinese/txg_ideologies_l_*.yml`：UTF-8-BOM 由 T-043 修正（D-20260815-005 的 BOM 清理即本地化 yml 需 BOM 而脚本 txt 不能 BOM 的区分）
- key 命名 `TXG_opinion_close_desc` 等符合 key 字符规范；opinion 描述用了 `_desc` 后缀惯例
- 后续意识形态政党名本地化可用 `[ROOT.GetRulingParty]` 等命名空间或 `$KEY$` 嵌套
