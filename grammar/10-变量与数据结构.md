# 10 变量与数据结构（Variables / Data structures）

> 来源：HOI4 官方 wiki `Data structures` 页（Variables 重定向，2026-08-16 抓取），CC BY-SA 3.0。原文：`grammar/_sources/Data_structures.md`。

## 1. 常量（Constants）与 Defines

- **常量**：`@NAME = 值`（文件内任意位置定义、任意点使用），如 `cost = @CONSTANT_1`；字符串常量只能用于触发器与属性。
- **Defines**：`common/defines/*.lua`，Lua 代码，仅内部计算使用；不可在脚本中引用。
  - 修改单个成员：`NDefines.NGame.START_DATE = "1936.1.2.12"`（独立文件，文件名靠后如 `zz_txg_defines.lua` 以最后求值——本项目已用）
  - mod **不得**包含 `00_defines.lua`/`00_graphics.lua`（整文件复制会因缺成员而不稳/崩溃）

## 2. Flags（旗标）

- PDXScript 旗标 = 32 位有符号整数（-2147483648 ~ 2147483647）；**建议只作布尔用**（比变量优化、省内存）。
- 5 种作用域：global / country / state / character / MIO（`set_global_flag`、`has_country_flag`、`clr_state_flag`、`set_mio_flag` 等）。
- 用法：`set_country_flag = name`（=1，无 tooltip）→ `has_country_flag = name`（触发）→ `clr_country_flag = name`；has 的 tooltip 用同名本地化 key。
- 扩展形式：`set_country_flag = { flag = x days = 50 value = 3 }`（定时/定值）；`has_country_flag = { flag = x value > 2 days > 30 date < "1938.1.1" }`；`modify_country_flag = { flag = x value = 4 }`（加减，未设置时为 0 无效）。
- **定向旗标**：`my_flag_@PREV`（追加目标 tag）；仅限 @ROOT/@PREV/@FROM/@THIS 单个。
- 调试控制台：`set_country_flag`、`list_flags`、`list_vars`。
- 本项目 8 大旗标（TXG_gov_*）与状态旗标（TXG_party_state_*、TXG_opinion_refresh_required）即此机制。

## 3. Event targets（事件目标）

- 指向某作用域（国家/州/角色）的指针。
- **全局**：`save_global_event_target_as = name`（永久，需手动 `clear_global_event_target`）；用 `event_target:name` 引用。
- **普通**：`save_event_target_as = name`（仅当前效果块与随后触发的事件链内有效，自动清除）。
- 检查：`has_event_target = name`。

## 4. 变量（Variables）

- 值 = 32 位整数 + 5 位小数（精度 0.00001，溢出翻转）；未设置变量按 0 处理。
- 名字：词字符、**不能以数字开头**；建议加前缀避免与内置名冲突（如 `TXG_` 前缀——本项目规范）。
- **类型**：
  - **常规变量**（regular）：只能在效果块设置；**作用域绑定**（国家/州/角色/global 各有独立值）；永久存在
  - **临时变量**（temporary）：可在触发器块设置；无作用域（全局唯一）；仅效果/触发器块内存在（scripted effect 内定义的临时变量可能不传出块外，块外定义的传入正常）
- **作用域访问**：`var_name`（THIS）、`GER.var_name`、`global.var_name`、`PREV.var_name`、`123.var_name`；链式用 `:`（如 `ABC.capital:var_name`）；用作作用域需 `var:` 前缀（`var:my_country = { ... }`），作效果/触发器目标可省略（但 error.log 会抱怨，建议保留 var:）

### 运算符（效果/触发器）

| 名称 | 说明 | 本项目用法 |
| ---- | ---- | ---- |
| `set_variable` | 设值：`set_variable = { var = x value = 100 }` 或简写 `set_variable = { x = 100 }`；**词元：`set_variable = { var = x value = token:NAME }`** | TXG_project_party/subtype/expected_engine_pole（token）与 TXG_axis_*（数值） |
| `set_temp_variable` | 设临时变量 | — |
| `check_variable` | 比较（触发器）：`check_variable = { var = x value = 10 compare = greater_than_or_equals }` 或简写 `check_variable = { x > 10 }`（简写**严格**：> 不含等于） | TXG 判型（D-20260815-005 用完整 compare 形式） |
| `has_variable` | 检查已设置（0 也算设置） | TXG_validate_project_party_state 的 7 变量检查 |
| `add_to_variable` / `subtract_from_variable` / `multiply_variable` / `divide_variable` / `modulo_variable` | 算术 | — |
| `clamp_variable` / `round_variable` / `set_variable_to_random` | 钳制/取整/随机 | — |

### 本地化中显示变量

- `[?var_name]`（? 必须）；格式化：`[?var|.1]`（小数位）、`[?var|%]`（百分比）、`[?var|+G]`（颜色）、`[?var|K]`（SI 单位）等；`$LEFT$`/`$RIGHT$` 表示操作前后值。

### 定向变量

- `var_name_@GER`、`var_name_@PREV`、`var_name_@var:target`（比 meta effect 更优）。

## 5. Arrays（数组）

- 5 种作用域同 flags；`create_array`/`clear_array`/`push_to_array`/`remove_from_array`/`get_array_size`/`for_each_array`（触发器 `is_in_array` 等）。
- `for_each_scope_loop = { array = args ... }`（scripted effect 控制台参数遍历）。
