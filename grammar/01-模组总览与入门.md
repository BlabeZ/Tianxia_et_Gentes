# 01 模组总览与入门

> 来源：HOI4 官方 wiki `Modding` 页（2026-08-16 抓取），CC BY-SA 3.0。原文：`grammar/_sources/Modding.md`。

## 1. 核心准则（Guidelines）

1. **绝不修改游戏本体文件**——任何改动都通过 mod 实现；本体改动会被更新覆盖且无警告。
2. **最小化覆盖本体文件**——尽量新增独立文件（mod 内文件可与本体文件同名同路径覆盖；也可用不同文件名追加）。文件名选择他人不会使用的命名（如 mod 名前缀），例 `coolmod_countries`。
3. 用合并工具（如 WinMerge）跟进本体补丁更新。
4. 备份/版本管理：推荐 Git + GitHub/GitLab。
5. **编码**：
   - 脚本 txt：**UTF-8 无 BOM**（"UTF-8 without BOM"）
   - 本地化 yml：**UTF-8 带 BOM**
6. 注释用 `#`：`#` 之后到行尾被完全忽略；**无多行注释**。
7. **debug 模式**：启动参数加 `-debug`（Steam 启动选项或 hoi4.exe 快捷方式追加）。

## 2. 编辑器建议

- VS Code + CWTools 扩展（语法高亮/校验/触发器效果提示；校验规则不完整，gui/localisation 会误报）
- Notepad++（设 Perl 高亮）、Sublime Text（+Sublime Tools）
- 必备能力：括号匹配高亮（缺失括号标红）、多文件搜索（Ctrl+Shift+F，可用 `*.txt` 过滤）、行号（error.log 按行号定位）
- **Windows 资源管理器不是好的搜索工具**（只搜 txt、极慢）

## 3. Debug 模式

- 启动参数 `-debug`；主菜单显示控制台快捷键。
- **日志**（用户目录 `Documents\Paradox Interactive\Hearts of Iron IV\logs\`）：
  - `error.log`：错误（含语法/作用域错误，带行号）
  - `game.log`：`log = "..."` 效果输出 + 常规日志
  - `system.log`：加载过程、mod 激活信息
  - 启动后日志**每次会话从零开始**（`system.log` 清空重写属预期轮转）

## 4. Mod 结构（descriptor）

- 模组定义：用户目录 `mod/` 下的 `.mod` 文件（如 `yourmod.mod`），内容：

```
name = "Your Mod Name"
path = "mod/yourmod"
tags = { Gameplay Graphics }
supported_version = "1.19.*"
replace_path = "map/strategicregions"   # 可选，整目录接管
```

- 用户目录：`C:\Users\<用户名>\Documents\Paradox Interactive\Hearts of Iron IV\`
  - `mod/`：用户级 descriptor（pdx_*.mod 或自定义名 .mod；本地模组注册用 `pdx_39436001.mod` 风格命名，见项目 T-048 基线）
  - `logs/`、`save games/`、`screenshots/`、`settings.txt`
- **路径不得含非 ASCII 字符**（否则 error.log 打不开、mod 加载异常）——注意项目路径 `D:\projects\Tianxia et Gentes` 合规。
- 同名 mod 冲突：仅按用户 descriptor 文件名顺序第一个生效。
- launcher 可创建本地 mod（"All installed mods"→"Upload mod"→"Create a mod"），但路径/结构受限，可手动编辑 descriptor。

## 6. 常见错误（Common mistakes）

- 缺少成对括号（最常见）
- 属性后留空参数（`icon = ` 会把下一行属性名当作参数）
- 编码错误（带 BOM 的脚本文件 / 无 BOM 的本地化文件）
- 路径含非 ASCII 字符
- 修改本体文件（更新即丢失）
