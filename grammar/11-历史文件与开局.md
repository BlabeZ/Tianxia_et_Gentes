# 11 历史文件与开局（History / Country creation）

> 来源：HOI4 官方 wiki `Modding`（Folder structure）、`Ideology modding`（国家历史接入）等（2026-08-16 抓取）；`History` 与 `Country_creation` 页待抓取补充。

## 1. history/ 目录结构

| 子目录 | 内容 |
| ---- | ---- |
| `history/countries/` | 国家历史文件（T-045 已生成 17 国） |
| `history/states/` | 州定义（provinces 边界、owner、初始建筑）——**州边界在此定义，不在 map/** |
| `history/units/` | 军队初始部署（被 `oob = "TAG_1936"` 直链引用） |
| `history/diplomacy/` | 初始外交关系 |
| `history/wars/` | 初始战争 |
| `history/ideologies/` | 初始意识形态状态（如政党领袖历史） |

## 2. 国家历史文件（history/countries/<TAG>.txt）

典型结构（T-045 已实践）：

```pdx
capital = 371                         # 首都州 ID
set_convoys = 10
set_politics = {                      # 开局政治状态
    ruling_party = democratic         # 只能四极（T-045 约束）
    last_election = "1932.5.1"
    election_frequency = 48
    elections_allowed = yes
}
set_popularities = {                  # ⚠ 四极必须加总 100
    democratic = 100
    communism = 0
    fascism = 0
    neutrality = 0
}
create_country_leader = {             # 领导人
    name = "..."
    desc = "..."
    picture = "..."
    ideology = <子类型>
    traits = { ... }
}
oob = "TAG_1936"                      # 引用 history/units/TAG_1936.txt
research = { ... }                    # 初始科技
add_ideas = { ... }                   # 初始国策/精神
```

- **日期块**：`1936.1.1 = { ... }` 形式为定时历史事件（开局时只执行 ≤ 开局日期的块）
- **on_action 不在开局历史执行**：set_politics 等不会触发 on_government_change/on_ruling_party_change（wiki 明确）——本项目 T-049 的 on_startup 校验不受影响

## 3. 州历史文件（history/states/<ID>-<Name>.txt）

```pdx
state = {
    id = 361
    name = "STATE_361"                # 本地化 key
    provinces = { 1 2 3 4 5 }         # 省份列表（州界声明，T-041 任务范围）
    manpower = 100000
    state_category = town             # 建筑槽位类别
    owner = CAN
    buildings = { ... }
    victory_points = { 1 10 }         # 胜利点（省份 值）
    resources = { oil = 5 }           # 资源
}
```

- 同名州重复定义：先创建者优先（本体优先于 mod）
- 开局铁路/补给节点在 map/ 定义（非 history/）
