# 声明层 → 落地层 流水线规范（D-20260812-064）

> 本文件是"修改意图如何变成游戏实际加载文件"的唯一权威地图。
> 总则：**声明层**（JSON/设定书，可校验、可审核、可重放）与**落地层**（`mod/**`，引擎实际加载）职责分离；跨层必须经由受控命令（state-build 等）或明确登记的手写清单，禁止任何 agent 直接复制/编辑本体 state 正文后塞进 mod。

## 四、最小可运行状态（MVP，D-20260812-064）

**定义**：当前批次任务书（T-028/T-034/T-041/T-042/T-043/T-045/T-046）全部完成后，mod 必须达到：

| # | 门槛 | 覆盖任务 | 验收方式 |
| ---- | ---- | ---- | ---- |
| 1 | 游戏可启动并加载 mod，无 state/ideology/country/scripted 解析错误 | T-028/T-043/T-045 load_test | 机器 A 实机 error.log 无 fatal |
| 2 | replace_path 缺口补齐：states 全量覆盖 + 已声明政党国家历史文件齐备 | T-028/T-045 | state-build 全量 + validate |
| 3 | 1910 开局可进入主地图 | T-042 | game-test map-load 闭环 |
| 4 | 坐标驱动机制运行无脚本报错（on_startup 政体旗标 + 好感网） | T-046 | 开局好感验证 |

**规定**：
1. 任何单任务 done 不得牺牲上述 MVP 目标；
2. 批次全部 done 后，主 agent 必须执行一次**最小可运行验收**（T-042 执行器 process-smoke/menu-debug/map-load 各 3 轮稳定）；
3. 验收未通过：按 fail_semantics 将相关任务退回重开，不得以"任务书已 done"掩盖不可运行；
4. MVP 范围外（明确豁免）：其余 38 国国家文件与政党、国旗 gfx 缺省、HOI4 leader 文件、国策树、事件内容——属后续主题阶段。
