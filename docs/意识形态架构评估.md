# 意识形态架构评估（T-008 前置）

> 状态：评估落盘，架构未拍板（D-20260812-024）｜待用户最终选择
> 引用：设定书/02-意识形态.md（8 大意识形态）；docs/mod_examples/02-意识形态与政治系统.md（KR/EAW/TNO 三范式）

## 一、背景与需求

- 设定书 02 卷定义 **8 大意识形态**：保守主义 / 自由主义 / 共和主义 / 国家发展主义 / 社会主义 / 文明主义 / 帝国主义 / 宗教现代主义，每大 5 个子意识形态（共约 40 个），并已列出各国政治力量归属。
- 用户提出**二维政治光谱愿景**（经济轴×政治轴坐标平面，替代单纯饼图），本评估确认其可行性并给出分层架构，坐标预存为既定设计原则（避免未来重构）。
- T-008（意识形态分布）需先定游戏内总意识形态架构，再产出各国分布。

## 二、方案 A：KR 式 8 极

**实现**：删原版四极，`common/ideologies/00_ideologies.txt` 定义 8 个顶层（保守/自由/共和/发展/社义/文明/帝国/宗教现代），每极 5 子类型；外交规则全脚本（KR 先例：10 极规则全相同+脚本差异）；`set_government_flags` 聚合旗标 + `has_xxx_government` 触发器判型。

**优点**：世界观表达最直接——饼图直接 8 色，UI 即设定。

**代价**：
1. 🔴 成就系统禁用（KR 先例：修改顶层 ideology 后成就不可用）；
2. 🔴 `history/countries/*.txt` 的 `set_politics` 引用原版 ideology 名，**38+ 国历史文件需全量覆盖改写**（最大工作量）；
3. 🟡 引擎硬编码四极处需脚本补丁（选举判定/意识形态好感模板/部分事件国策）；
4. 🟡 8 极+40 子类型完整本地化、图标、和平会议 cost_modifiers。

## 三、方案 B：EAW 式四极壳（推荐基线）

**实现**：保留引擎四极（democratic/communism/fascism/neutrality），8 大意识形态作 40 个子类型（`can_be_randomly_selected = no`）；顶层保留原版 rules/faction_modifiers 兼容引擎 UI 与成就；判型用聚合旗标（`has_developmentalist_government` 等触发器，docs/mod_examples/02:79 已验证）；世界观玩法差异下沉法律系统（TNO 式理念）。

**优点**：
- ✅ 成就保留、引擎机制原样可用；
- ✅ 国家历史文件/国策/事件无需全量改写；
- ✅ 工作量小（约 KR 式 1/2—1/3）；
- ✅ 长程自动化风险低。

**代价**：8 大意识形态藏于子类型层，饼图顶层仍四色；世界观表达需脚本触发器（`has_xxx_government`）呈现，不如 KR 直观。

## 四、方案 C：TNO 式标签化

**实现**：意识形态完全标签化（零修饰、无 rules/modifiers、`can_be_boosted = no`），真正差异全部下沉法律系统与 GUI（docs/mod_examples/02:190-192）。

**优点**：最灵活，意识形态纯作"政治路线名"载体。
**代价**：工程量大（法律系统+GUI 全新建），与 02 卷 8×5 子类型结构叠加复杂度高；本期不适用。

## 六、工作量与风险

| 维度 | KR 8 极 | EAW 四极壳 |
|---|---|---|
| 相对工作量 | 大（约 2—3 倍） | 小—中 |
| 主要增量 | 国家文件全量改写、引擎补丁、全量本地化 | 子类型配置、聚合旗标脚本 |
| 长程自动化风险 | 高（大工程跨多任务） | 低 |
| 世界观直接性 | 高 | 中（脚本触发器呈现） |

## 七、二维光谱衔接（既定设计原则）

三层架构（与架构选择无关，均为共识）：

| 层 | 内容 | 迁移成本 |
|---|---|---|
| 引擎层 | ideology 槽（无论 8 极或四极壳） | 不变 |
| 数据层 | 每政党 `x_axis/y_axis` 坐标字段（经济轴=02 卷纵向光谱，政治轴=横向轴） | **本期预存，未来零迁移** |
| 显示层 | 原生饼图 + scripted_gui 二维坐标图（EAW 议会 GUI 先例，可共存切换） | 后置增强 |

**结论**：无论选 A 或 B，政党数据必须预存二维坐标；后续二维光谱仅新增显示层，政治系统无需推倒。

## 八、建议

**EAW 式四极壳 + 40 子类型 + 聚合旗标判型**为推荐基线：兼容成就与引擎、工作量可控、长程自动化风险低；8 大意识形态经脚本触发器完整表达，二维光谱坐标预存保证未来零迁移。
