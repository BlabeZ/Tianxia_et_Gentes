## 二、坐标→四极映射表（五轴组合判据，D-20260812-056）

> 双轨一致性（D-20260812-026）：坐标政体供自定义脚本（好感/事件/国策），引擎机制按四极静态字段；二者经本判据保持一致。2+1 模型已由五轴模型取代（D-20260812-056）。

| 引擎四极 | 五轴组合判据（依次特判，命中即停） | 8 大旗标 |
| ---- | ---- | ---- |
| communism | L ≤ -50 且 E ≥ +50 且 O ≤ -40（激进左翼：左+计划+革命） | 社会主义主判型 |
| fascism | L ≥ +60 且 F ≥ +60 且 P ≥ +40（右翼激进民族主义；1910 无政权落入，预留） | —（1910 无对应） |
| democratic | P ≤ -30（分权政体，且未命中前两条） | 自由/共和主判型 + 温和左/立宪细分 |
| neutrality | 其余（P > -30 且未命中前两条） | 保守/发展/文明/帝国/宗教现代主判型 |

政体标签（P 轴，T-046 政体判定脚本化）：
- 分权政体：P ≤ -30；威权政体：P ≥ +40；混合政体：-30 < P < +40。

双轨一致性规则：
1. 政党 key 命名 = `TXG_<TAG>_<party>`（D-20260812-025 已定），政党文件子类型必须取自 40 key 之一；
2. 国家坐标（T-044 坐标 JSON，五轴）经本判据映射出的四极，必须与 set_politics 中执政党所在四极一致（validate 校验，T-045）；
3. 8 大旗标按执政党子类型所属大类打标（T-045 初始化、T-046 变更钩子）。
