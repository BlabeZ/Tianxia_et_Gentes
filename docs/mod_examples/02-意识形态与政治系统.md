# 02-意识形态与政治系统

> 适用：意识形态体系、政党、选举、议会、联合政府、政治派系。
> 参考样本：KR（10 大意识形态 + 联合政府 + 德国国会席位）、EAW（四极 + 65 子类型 + 议会 GUI）。

## 一、意识形态文件的位置与两种路线

文件：`common/ideologies/00_ideologies.txt`（同名覆盖原版）。

| | KR | EAW |
|---|---|---|
| 大意识形态 | **10 个**（删原版四极）：totalist/syndicalist/radical_socialist + social_democrat/social_liberal/market_liberal/social_conservative + authoritarian_democrat/paternal_autocrat/national_populist | **保留原版四极**（democratic/communism/fascism/neutrality） |
| 子类型 | 每大意识形态仅 1 个 generic 子类型 | **65 个子类型（52 个自创）**，如 alicornrule、magocracy、undead_horde、socialist_monarchism、theocracy_subideology |
| faction_modifiers | 删除 | **保留**（`faction_trade_opinion_factor = 0.50`） |
| 随机保护 | 无 can_be_randomly_selected | 自创子类型全部 `can_be_randomly_selected = no` |
| 外交规则 | 10 者完全相同（禁傀儡/禁建阵营/可志愿军）——**外交限制全靠脚本** | 按极定制（民主保留同意识形态禁战、`can_force_government = no`） |

## 二、政府快速判型：flag 聚合（KR）

KR 在 `common/scripted_effects/00_government_scripted_effects.txt` 定义 `set_government_flags`，把 10 意识形态映射为 12 个布尔旗标，所有聚合触发器查旗标：
```pdx
has_socialist_government = {
	custom_override_tooltip = { ... }
	has_country_flag = KR_is_socialist
}
```
政体变化时 `on_ruling_party_change_immediate` 调用 `set_government_flags = yes` 重建旗标。

**启示**：本 mod 的 8 大意识形态（保守/自由/共和/发展主义/社会主义/文明主义/帝国主义/宗教现代主义）可以既保留原版四极外壳（兼容引擎机制），又用聚合旗标（`has_developmentalist_government` 等）做脚本判型——EAW 路线比 KR 路线兼容性更好。

## 三、意识形态好感网（KR 动态 opinion）

`00_on_actions_global.txt` 的 on_startup 对每对国家按执政意识形态亲疏打 5 档 opinion：
```pdx
KR_same_ideology = { value = 40 }
KR_similar_ideology_close = { value = 30 }
KR_similar_ideology = { value = 20 }
KR_similar_ideology_distant = { value = 10 }
KR_different_ideology_close = { value = -10 }
KR_different_ideology = { value = -30 }
```
`on_ruling_party_change` 时先全部 remove 再重算（文件 `00 Generic_Opinion_Modifiers.txt` + `00_on_actions_global.txt` 1075-1137 行）。

## 四、政党支持度与 PP 挂钩（KR 通用效果）

文件：`common/scripted_effects/00_party_popularity_effects.txt`、`common/dynamic_modifiers/00 Generic dynamic_modifiers.txt`：
```pdx
party_popularity_dynamic_modifier = { political_power_gain = party_popularity@ruling_party }
party_popularity_dynamic_modifier_coalition = { political_power_gain = coalition_pp_gain }
```
即：执政党支持度越高 PP 产出越多——用变量 + 动态修正实现，无需新引擎。

## 五、联合政府（KR 核心政治系统）

**实现**：`coalitions_array` 长度为 10 的**国家变量数组**（索引 0-9 对应 10 意识形态），存 `constant:party_pop.party.ruling_party` / `coalition_partner` / `none`。
```pdx
add_to_coalition = {
	create_coalitions_array_if_missing = yes
	convert_coalition_partner_var_into_index = yes
	if = {
		limit = { check_variable = { coalitions_array^coalition_partner_var < constant:party_pop.party.coalition_partner } ... }
		set_variable = { coalitions_array^coalition_partner_var = constant:party_pop.party.coalition_partner }
		add_to_variable = { coalition_pp_gain = { ... } }
		add_dynamic_modifier = { modifier = party_popularity_dynamic_modifier_coalition }
	}
}
```
配套：`add_to_coalition`/`remove_from_coalition`/`end_coalition` 三个 effect；`is_in_coalition_with_<意识形态>` 触发器（`check_variable` 判数组）；`is_part_of_government_*` = `has_government` OR 联盟成员。德国开局即建三党联盟（on_actions_Germany.txt）。

**启示**：本 mod 大顺"皇权-文官-军事贵族"三角或晚清"君宪/咨政院"政治可用此模板：各政治集团 = 联盟成员，支持度 = 政党人气，PP 收益随支持度变化。

## 六、国会/议会席位系统

### KR 德国国会（seats 变量法）
初始化在 `history/countries/GER - Germany.txt`（总 445 席）：
```pdx
set_variable = { GER_SPD_seats = 125 }
set_variable = { GER_LVP_seats = 59 }
...
```
运行逻辑在 `GER effects (Germany).txt`：
- 黑周一冲击席位：`subtract_from_variable = { GER_LVP_seats = 3 }`、`add_to_variable = { var = GER_SPD_seats value = 10 }`——经济危机通过席位再分配改变国会格局；
- 联盟聚合：党团按 `_l/_c/_r` 左右翼拆分归入 `GER_democratic_union_seats` / `GER_swr_coalition_seats`，223 席多数线判定（`GER_democratic_union_seats > 223`）；
- 拉拢/保护：`GER_is_possible_reichstag_target` + `is_in_array = { GER.protected_factions_array = 3.id }`；
- 政治路径：`GER_is_schleicher_path/swr_path/du_path` 用 2IC 角色职位（`is_second_in_command`）+ flag 判定。

### EAW 议会（数组+帧数组驱动 GUI）
- **WNG**（`EAW_WNG_parliament_effect.txt`）：535 席 15 党，`setup_WNG_parliament` 用 `resize_array` 建 `parliament_parties`/`parliament_parties_colors` 数组，`update_WNG_frame_array` 把席位按党色写入 535 元素帧数组，配合 `common/scripted_guis/eaw_wng_parliament.txt` 画出半圆议会座位图；多数线 `check_variable = { WNG.WNG_parliament_seats > 267 }`。
- **JER**（`common/scripted_guis/eaw_jer_parliament.txt`）：`context_type = decision_category` 的议会 UI，400 个 `pb_N = { frame = parliament_frame_array^N }` 属性逐座绑定颜色。
- **ABY**：席位存数组 + 选举日 `next_election_date_temp = global.date + 0.26280`（年）滚动计算。

**启示**：大顺廷议/咨政院/议会可以用"席位变量 + 联盟聚合 + GUI 座位图"完整复刻；KR 的变量法适合做机制，EAW 的帧数组法适合做可视化。

## 七、选举与政体公投（EAW 示例）

- `EquestriaDemocratic.txt` 事件 `equestriadem.4`：妥协后四选项（重申公主制/等级会议 Diet/联邦 Commonwealth/共和国），各设旗标 + `set_cosmetic_tag = EQS_DEM1` 换国号，`is_historical_focus_on` 控制 AI 走历史线。
- BRZ 选举按核心州人口计票：`total_votes = state_population_k`，`BRZ_national_party_support^0..6` 七党支持率数组，直接写原版选举数据（`elections_allowed = yes`、`election_frequency = 60`）。
- ZES 选举 GUI（`common/scripted_guis/zes_election_scripted_gui.txt`）：四候选人选择窗口。

## 八、派系斗争：power/loyalty 双变量（EAW CTH）

`EAW_CTH_effect.txt`（1849 行）：五派系各带 **power（0-5）与 loyalty（0-100）双变量**，忠诚度以 50 为阈值，跨过阈值翻转动态修正正负号：
```pdx
CTH_add_10_scientifid_loyalty = {
	custom_effect_tooltip = CTH_add_10_scientifid_loyalty_tt
	if = {
		limit = { check_variable = { CTH_scientifid_loyalty < 50 } }
		add_to_variable = { var = CTH_scientifid_loyalty value = 10 }
		if = {
			limit = { check_variable = { CTH_scientifid_loyalty > 49 } }
			multiply_variable = { var = CTH_science_production_factory_efficiency_factor_var value = -1 }
		}
	}
	else = { add_to_variable = { var = CTH_scientifid_loyalty value = 10 } }
	force_update_dynamic_modifier = yes
	CTH_clamp_variables = yes
}
```
（FBK 军队忠诚用 idea 阶梯：low→medium→high→extreme 四级。）

## 九、制作本模块时的检查清单

1. `common/ideologies/00_ideologies.txt`：决定"四极+子类型"（EAW 式）还是"自创大意识形态"（KR 式）——**建议 EAW 式**，兼容引擎 UI 与成就；
2. 每个新子类型必须同步：`common/scripted_localisation/` 显示文件（EAW 文件头注明此约定）、`common/peace_conference/cost_modifiers`、各国 `set_popularities`；
3. 政体判型：建 `set_government_flags` 式聚合旗标效果 + `has_xxx_government` 触发器；
4. 政治机制（联合政府/议会/派系）：先写变量/数组初始化效果，再写读写触发器，最后接 UI（scripted_gui）；
5. `on_ruling_party_change` / `on_ruling_party_change_immediate` 钩子：重建旗标、重算好感网、清理旧联盟。

## 十、KX 扩展视角：超大规模子意识形态（966 个）

KX 在 KR 基础上把子类型扩到 **966 个**（totalist 98 / syndicalist 80 / radsoc 106 / socdem 104 / soclib 79 / marlib 64 / soccon 76 / authdem 97 / pataut 109 / natpop 153），顶层配置与 KR 完全一致。要点：

- 命名呈"派别×主义"嵌套（`socdem_crime_syndicate`、`marlib_christian_democracy`、`cowboy_communalism` 跨极变体）；23 个带自定义 `color`；全部 `can_be_randomly_selected = no`；
- **新增子类型 4 件套**（文件头注释点名）：① `common/scripted_localisation/_useful_scripted_localisation.txt` 加 1 条 trigger 链（`GetRulingIdeologySubtype` 共 967 条）；② `interface/countrypoliticsview.gfx` 加 `GFX_ideology_<subtype>` 精灵；③ `gfx/interface/ideologies/subideologies/` 放图标 png；④ 本地化文件加 `X_subtype` 名与 `X_subtype_desc` 长描述；
- 显示开关：`common/scripted_guis/syndicalist_soc_dem_notice.txt` 仅当领袖意识形态非 generic 子类型时显示名称；
- **本项目建议**：采用 EAW 式"四极+子类型"与 KX 式 4 件套显示，但子类型控制在每极 5-15 个（按《意识形态与全球政治设定 Ver.2》的 8 大意识形态 × 5 个子类型 ≈ 40 个）；顶层保留原版 rules/faction_modifiers 以兼容引擎。

详细见 [10-KX扩展内容参考.md](10-KX扩展内容参考.md) 第二节。

## 十一、TNO 扩展视角：标签化意识形态（11 大 × 152 子类型）

TNO 提供第三种范式（详见 [12-TNO冷战经济与GUI参考.md](12-TNO冷战经济与GUI参考.md) 第四节）：**意识形态完全标签化**——11 大意识形态 × 152 子类型 + `_1~_4` 编号渐变变体，但**全部零修饰**（无 rules/modifiers/faction_modifiers、`can_be_boosted = no`、`ai_neutral = yes`），意识形态不再承载任何玩法数值，只作"政治路线名"载体；真正差异全部下沉到法律系统、GUI 面板与 scripted 系统。政体判型靠聚合触发器（`has_elected_government`/`has_authoritarian_government`/`has_dictatorship_government` 按 11 意识形态分组）。

**三范式对比（供本项目决策）**：
| | KR | EAW | TNO |
|---|---|---|---|
| 大意识形态 | 10（删四极） | 4（保留原版） | 11（原创） |
| 子类型 | 每极 1 个 | 65 | 152 |
| 顶层配置 | 完整 rules/modifiers | 完整 + faction_modifiers | **零修饰纯标签** |
| 玩法承载 | 意识形态本身 | 意识形态本身 | 法律/GUI/脚本系统 |

《天下与万邦》建议：意识形态承载世界观识别（EAW/KR 式配置），而"文明现代性"的具体玩法差异用 TNO 式的法律系统 + 修正承载。
