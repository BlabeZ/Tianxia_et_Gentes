# 14-KR阵营页面与按钮机制（帝国公约专题）

> 适用：阵营（faction）UI 页面定制、页面按钮效果、阵营加入提醒弹窗、阵营模板/manifest/goals 数据定义。
> 参考样本：Kaiserreich（KR，`E:\Steam\steamapps\workshop\content\394360\1521695605`）的"帝国公约"（Reichspakt）阵营页面。
> **阅读前提**：先读 [06-外交阵营与自治度.md](06-外交阵营与自治度.md)（阵营模板/规则/manifest 机制）与本专题配合。
> 本专题为 KR 阵营界面的**代码级精读**：页面窗口、全部按钮、提醒弹窗的完整实现链路。

## 一、总体架构：阵营页面的三层机制

帝国公约（Reichspakt）页面由三层组成，各层职责不同：

```
① 数据层（common/factions/）：阵营模板/规则/宣言/目标 —— 决定"阵营是什么"
② 窗口层（interface/factions/countryfactionview.gui）：页面布局与按钮外观 —— 决定"页面长什么样"
③ 逻辑层（common/scripted_guis + on_actions + scripted_effects）：按钮点击逻辑与弹窗 —— 决定"点了发生什么"
```

- 页面窗口 = 引擎**原版阵营视图的整体重写**（KR 版本 3100 行，含大量 `#KR:` 注释标记改动）；
- 按钮效果分两类：**引擎硬编码按钮**（按钮 name 由引擎识别，点击触发引擎逻辑，mod 只控制外观/可见性/tooltip）与 **scripted_gui 按钮**（effects 完全由脚本编写）。

## 二、数据层：帝国公约阵营定义

### 1. 模板（`common/factions/templates/reichspakt.txt`）
```pdx
faction_template_reichspakt = {
	name = faction_reichspakt
	icon = GFX_faction_icon_reichspakt
	manifest = faction_manifest_global_hegemony

	default_rules = {
		#manpower_contribution_high #Consider readding if manpower contributions are ever revised to be functional
		joining_rule_non_socialist
		dismissal_rule_ideology_socialist
		change_leader_rule_never
	}
}
```
- 开局创建：GER 历史文件 `create_faction_from_template = faction_template_reichspakt` + `scope:faction = { set_variable = { faction_template_reichspakt_var = 1 } }`；
- 图标：`GFX_faction_icon_reichspakt`（大图）与 `_miniature`（小图）注册于 `interface/kaiserreich/factions.gfx`。

### 2. 宣言（manifest，`common/factions/goals/reichspakt.txt`）
```pdx
faction_manifest_global_hegemony = {
	name = faction_manifest_global_hegemony_name
	description = faction_manifest_global_hegemony_desc
	is_manifest = yes
	ratio_progress = {
		total_amount_collection = collection:non_american_countries
		completed_amount_collection = collection:allied_non_american_countries
		scale = {
			army_core_defence_factor = 0.20
			production_factory_max_efficiency_factor = 0.10
			war_support_factor = 0.10
			conscription_factor = 0.10
		}
		progress_sections = {
			manifest_fulfilled = {
				min = 0.75
				modifier = {
					extra_trade_to_overlord_factor = 0.20
					stability_factor = 0.10
					political_power_factor = 0.10
				}
			}
		}
	}
}
```
即：**全球霸权宣言**——非美国国家中盟友占比 ≥75% 时触发满额奖励（`ratio_progress` + `progress_sections`），页面头部的 `manifest_progress` 进度条直接读此数据。另有通用宣言（`00 generic_manifests.txt`：区域霸权/民主堡垒等）与其他阵营专属宣言。

### 3. 目标（goals）
`common/factions/goals/` 按阵营分文件（reichspakt.txt/internationale.txt/entente.txt 等）+ 通用目标（`01 generic_short/medium/long_term_goals.txt`）。目标有短/中/长三档槽位，页面 goals 页签展示。

## 四、按钮效果机制（两类）

### 1. 引擎硬编码按钮（mod 侧控制外观与可用性）
页面上的多数按钮由**引擎识别 name 并触发内置逻辑**，mod 无法改点击逻辑，只能控制：

| 按钮 name | 引擎效果 | KR/mod 侧控制 |
|---|---|---|
| `close_button` | 关闭页面（shortcut ESCAPE，clicksound click_close） | 仅外观 |
| `leave_faction_button` | 解散/退出阵营 | **`hide = yes #KR: hidden to avoid disbanding factions`**——KR 直接隐藏，防止玩家解散帝国公约 |
| `member_countries` | 打开成员列表 | `frame = 2`（按钮贴图帧）、本地化 FACTION_MEMBERS_LIST_BUTTON |
| `become_leader` | 发起领袖权争夺 | 本地化 FACTION_BECOME_LEADER_BUTTON |
| 5 个 `*_tab_button` | 切换页签 | frame 控制选中态（1/2 帧）、pdx_tooltip 本地化、`lock_icon_*` 叠加锁定图标 |
| `rules_button` / `edit_button` | 打开 change_rule_window | 引擎内置弹窗 |
| `open_research_tab` / `open_scientist_roster` | 跳转科技/科学家面板 | 引擎内置 |
| `send_button`/`cancel_button`（弹窗内） | 确认/取消（shortcut RETURN/ESCAPE，clicksound click_send/click_close） | 仅外观 |
| `unlock_button`（学说/情报） | 解锁对应功能 | 引擎按 `has_faction_*_unlocked` 状态控制显示 |

**关键规律**：引擎按钮的可用性由引擎内部状态（阵营规则、解锁 flag、领袖身份）控制；mod 通过 `hide`、`frame`（贴图帧=状态帧）、`pdx_tooltip`、`clicksound` 做外观层定制。**KR 对原版页面最主要的改动就是把"离开阵营"按钮隐藏**（保护阵营完整性）。

### 2. scripted_gui 按钮（效果完全脚本化）
`common/scripted_guis/` 中的 GUI 按钮带完整 `effects`（点击时执行脚本）。以阵营相关最典型的 **kaiserreich_alerts（阵营加入提醒弹窗）** 为例：

**文件**：`common/scripted_guis/00_alerts.txt`
```pdx
scripted_gui = {
	kaiserreich_alerts = {
		context_type = player_context
		window_name = "kaiserreich_alerts_window"
		dirty = global.kaiserreich_alerts_dirty
		ai_enabled = { always = no }

		dynamic_lists = {
			faction_joining_alerts_grid = {
				array = global.faction_joining_alerts    # 数组驱动列表
				change_scope = yes
				country_scope_entry_container = faction_joining_alert
			}
			...
		}

		effects = {   # ← 按钮点击效果全部脚本化
			faction_joining_bg_right_click = {
				clear_faction_joining_alert = yes
			}
			incoming_war_ok_button_click = {
				clear_variable = ROOT.alert_war_target_@THIS
				remove_from_array = { ROOT.incoming_war_alerts = THIS }
				set_variable_to_random = global.kaiserreich_alerts_dirty
			}
			...
		}

		properties = {   # ← 动态贴图
			faction_joining_sender_flag = { image = "[THIS.GetFlag]" }
			faction_joining_receiver_flag = { image = "[?faction_leader.GetFlag]" }
			faction_joining_alert_progressbar = { x = faction_joining_progressbar_value }
			...
		}
	}
}
```

**阵营加入提醒的完整数据流**（三层联动的教科书示例）：
```
on_offer_join_faction（common/on_actions/00_on_actions_global.txt 2094 行）
  └─ FROM（被邀请国）：
       set_variable = { faction_joining_alert_timer = 0 }
       add_to_array = { global.faction_joining_alerts = THIS }   ← 入数组
       sound_effect = diplomatic_notification
       set_variable_to_random = global.kaiserreich_alerts_dirty   ← 触发 GUI 重绘
       country_event = { id = generic_events.25 hours = 1 }      ← 通知事件
  → scripted_gui 的 dynamic_lists 遍历数组渲染弹窗条目
  → properties 动态显示双方国旗 + 进度条
  → 玩家点按钮 → effects：clear_faction_joining_alert
     （00_alert_scripted_effects.txt：clear_variable + remove_from_array + set dirty）
  → on_annex（875 行）清理：吞并国退出数组时 clear_faction_joining_alert
```

**进度条实现**（`common/scripted_effects/00_alert_scripted_effects.txt`）：
```pdx
update_faction_joining_progressbar = {
	set_variable = {
		faction_joining_progressbar_value = {
			value = faction_joining_alert_timer
			divide = @alert_timer
			multiply = @progressbar_divisor
			subtract = @progressbar_divisor
			round = yes
			clamp = { min = @progressbar_min_value max = @progressbar_max_value }
		}
	}
}
```
（定时器变量 → 归一化 → 乘除常量 → 进度条像素偏移，`properties = { x = faction_joining_progressbar_value }` 直接驱动进度条横坐标。）

### 3. 阵营属性保存/恢复（`common/scripted_effects/00_faction_scripted_effects.txt`）
```pdx
@num_faction_attributes = 7
save_former_faction_attributes = {
	resize_array = { former_faction_attributes = @num_faction_attributes }
	# 0=faction_research 1=faction_military 2=spymaster 3-6=四类设施
	if = { limit = { has_faction_research_unlocked = yes } set_variable = { former_faction_attributes^0 = 1 } }
	...
}
add_to_faction_tech_sharing_group = { ... }   # 按 can_join_* 触发器加入科技共享组
set_as_temporary_faction = { ... }            # 临时阵营（短/中/长目标槽 -1）
```
即：国家退阵/被踢后再入阵营时，**研究/军事/情报/设施四类阵营属性通过数组保存恢复**——阵营成员的"升级成果"不因退阵丢失。

## 六、对本项目的借鉴清单

| KR 机制 | 本 mod 对应需求 | 移植要点 |
|---|---|---|
| 阵营页面整体重写（countryfactionview.gui） | 天下体系/威斯特伐利亚体系阵营页面 | 直接复制 KR 版文件为基础改（它已适配 NSB 阵营系统）；隐藏不想要的按钮用 `hide = yes #注释` |
| 引擎按钮外观定制 | 阵营页按钮 | frame 状态帧 + pdx_tooltip + clicksound；**按钮逻辑引擎硬编码，mod 只做外观层** |
| 阵营加入提醒弹窗（kaiserreich_alerts） | 朝贡国加入/体系邀请提醒 | 数组（global.faction_joining_alerts）+ dirty 变量 + dynamic_lists + effects + properties 五件套 |
| 进度条变量驱动 | 任何倒计时/进度 UI | 定时器变量→归一化→像素偏移→`properties = { x = var }` |
| 宣言进度（manifest） | 体系目标达成度 | ratio_progress + collection + progress_sections |
| 属性保存/恢复（save_former_faction_attributes） | 退体系再入不丢成果 | 7 元素数组存档/恢复 |
| 世界紧张度不对称 | 体系加入的威胁度 | on_offer_join_faction 中按阵营阵营 flag 计算（保守 -75%） |
| 科技共享组联动 | 体系科技圈 | add_to_faction_tech_sharing_group + can_join_* 触发器 |
