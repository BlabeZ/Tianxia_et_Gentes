# 11-RT56追加式开发参考（Road to 56）

> 适用：**与原版共存的追加式开发**（不接管 common 目录）、科技树扩展、通用国策树、formable nations、动态国策树切换、AI 剧本化。
> 参考样本：Road to 56（RT56，`E:\Steam\steamapps\workshop\content\394360\2129897125`，本机为 CN 中文版，supported 1.19.*）。
> **前提**：RT56 是与 KR/EAW/KX 完全不同的开发范式——**追加式（additive）**：descriptor 仅 3 条 replace_path，保留原版 1936 世界观与全部原版内容，靠"新文件追加 + 同名覆盖 + 引擎替代"三管齐下扩展。文件规模：404 国家、1143 州（255 新增）、212 国策文件（134 新增）、182 决策文件、166 个 ai_strategy_plans、296 人物文件、20 科技文件。

## 一、追加式加载策略（核心方法论）

### 1.1 三条 replace_path 及原因
```
replace_path="history/states"        # 1143 州全量重写（含 255 新州）
replace_path="map/strategicregions"  # 298 战略区全量重划
replace_path="gfx/fonts"             # 中文字体替换
```
**规律**：这三类资源引擎无法增量合并（州/战略区按 id 合并会冲突、字体需整体替换），必须 replace_path；其余一切系统都用增量方式。

### 1.2 三管齐下的文件策略（RT56 核心方法论）
1. **追加**（占多数）：新国家/事件/国策/人物/决策一律用**新文件名**（`r56_` 前缀、新 TAG、新主题名），与原版 100% 不冲突——实测新增：国策 131、决策 54、人物 119、事件 131、scripted_effects 29；
2. **同名覆盖**（仅当必须改原版系统）：generic.txt、00_ideologies.txt、00_game_rules.txt、大国国策树、国家历史/事件/人物文件——**覆盖版保留原版 ID 与 namespace**（事件 `add_namespace = china` 保留、原版事件 id 保留，新事件从高号段追加如 china.101）；
3. **引擎替代**（不碰原版文件）：defines 用新文件 `r56_defines.lua`（原版 defines 零改动）；本地化用 `localisation/simp_chinese/replace/` 子目录（引擎内置覆盖机制，无需 replace_path）；国策树用 game_rule + `load_focus_tree` 动态切换。

### 1.3 兼容性工程细节
- **国家 tag 管理**（`common/country_tags/r56_countries.txt`）：新 tag 全 3 字母唯一，文件中**注释保留与原版冲突的候选 tag 及原因**：
```
#GRL = "countries/Greenland.txt" #Replaced by vanilla
#SWK = "countries/Sarawak.txt"   #Now SAR to match vanilla
```
- **意识形态防御性兼容**：保留原版 `japan_militarism_ideology` key（注释 `#R56_TODO: Do not remove to not have issues with future vanilla content`），新子类型全部 `can_be_randomly_selected = no`；
- **DLC 共存**：新内容带 `NOT = { has_dlc = "Gotterdammerung" }` 条件让位（MIO）、`has_global_flag = XXX_dlc_focus_tree` 让位（AI 计划）、废弃文件整体注释（`# technologies = {`）。

**启示**：若《天下与万邦》选择"基于原版地图与机制、不做全替换"的轻量路线，RT56 是本项目的**第一参考**；若做全替换则参考 KR/EAW。

## 四、三层科技扩展体系

### 1. 常规树延伸（_2/_a 后缀，外科手术式插入）
12 个原版科技文件被覆盖（体积 1.1-1.8x），覆盖版 = 原版内容 + `# R56` 注释标记的插入：
- 装甲延伸到 **1955**（`main_battle_tank_a #E-60` 1947 → `_e` 1955）；
- 支援连延伸到 **1954**（tech_engineers4 → tech_engineers_a/b/c 1948/1951/1954）；
- **重定义原版科技**：`motorised_infantry` 从 infantry.txt 移到 r56_vechicles.txt，新增 1920 年代卡车根科技 `tech_trucks`，`sub_technologies` 改为显式 `path`；
- 在原版科技定义内插 `path = { leads_to_tech = main_battle_tank_a } # R56`、改 folder 位置腾空间。

### 2. 特殊研究部门树（SRD，`r56e_etax.txt`，38 科技）
整棵新树独立 folder（`etax_folder`），根 `etax_doctrine`（1918）→ 三军分支 + 经济两路（1936）→ 互斥首级（1938，`xor`）→ 次级（1941）→ 终局（1943：`etax_the_bomb` 原子向 / `etax_super_soldiers` / **`etax_moonshot` 登月** / `etax_seashot`）；根科技带 `allow_branch = { NOT = { has_global_flag = disable_r56_techs } }` 全局开关。

### 3. 国家专属科技（`r56_country_techs.txt` 等）
统一模式：`research_cost = 1` + `allow = { always = no }`（仅国策/事件 `set_technology` 授予），如 BRA `selva_tech`（丛林攻防）、POL 河上舰队、USA 侧车油箱。

### 4. 特殊工程链（`r56_land_projects.txt` 等）
"坦克光学测距仪"父子项目链：完成项目 → `set_technology = r56_improved_optics_tech_1`（解锁隐藏科技）→ `enable_equipment_modules`（解锁装备模块）——与 `r56_special_projects_techs.txt` 的隐藏科技一一对应。

## 五、国策树策略（RT56 最值得学的部分）

### 1. generic.txt：2541 行 → 48 行聚合器
原版通用树被压成 48 行的 `shared_focus` 引用列表（82 个共享 focus 定义在 `r56_gen_shared.txt`，6053 行）：
```pdx
focus_tree = {
	id = generic_focus
	country = { factor = 1 }
	default = yes
	reset_on_civilwar = no
	shared_focus = GEN_Aviation_Effort
	shared_focus = GEN_begin_industrial_buildup
	shared_focus = AFR_african_unification
	shared_focus = USC_UNIFIED_central_american_unification
	...
}
```
每个 shared_focus 用 **`offset + trigger` 为不同国家定制树内位置**（如 `offset = { x = 23 y = 0 trigger = { has_focus_tree = albania_focus } }`）——**一套通用国策，多国复用且位置各异**，这是全小国通用树的最优解。

### 2. 23 国国策树动态切换（与原版 DLC 树共存）
`game_rules` 定义 `XX_focus_tree_selection` 规则（默认 R56_TREE 或 STANDARD_TREE，`allow_achievements = yes`）→ `r56_focus_tree_selection_on_actions.txt`（2604 行）的 on_startup 按规则 + has_dlc 二选一：
```pdx
if = { limit = {
		has_game_rule = { rule = AFG_focus_tree_selection option = STANDARD_TREE }
		has_dlc = "Graveyard of Empires" }
	set_global_flag = afg_dlc_focus_tree
	AFG = { load_focus_tree = afghanistan_tree
		remove_power_balance = { id = AFG_power_balance }
		remove_ideas = { AFG_decentralized_economy ... }
		... } }
```
（选 DLC 树时彻底清理 RT56 专属内容，选 RT56 树时反向清理 DLC 角色。）

### 3. 大国树两种扩展模式
- **原位追加**（italy.txt 25012 行 372 focus）：保留原版 95% focus id，新 focus 用 `prerequisite`/`relative_position_id` 挂原版节点旁（如 `ITA_ally_yugoslavia` 挂在 `ITA_foreign_affairs` 旁）；
- **重构式扩展**（france.txt 236 focus）：大量新命名 focus 重组。

### 4. 新国家树
`focus_tree { id = albania_focus, country = { factor = 0 modifier = { add = 30 tag = ALB } }, default = no }` + 复用 6 个 shared_focus + 自研 focus（命名 `TAG_xxx`）。

## 六、独特机制

### 1. 印度省级三党选举（`r56_indian_provincial_elections.txt` 1277 行）
三党（INC 国大党/UP 统一党/IFB 独立工党）→ 州级 `INC_Majority` 州 flag → `raj_calculate_election` 按州数算得票率%（`inc_control/upa_control/ifb_control` 变量）→ 玩家用决策增减各党州级支持 → 365 天倒计时选举事件 → `declare_independence_political` 按胜利旗标落地换政府（安贝德卡尔共产/尼赫鲁民主/Sikander 中立），失败方 PP 清零 + 稳定 -10%。

### 2. 国民党双 BOP（`common/bop/china_bop.txt`）
- `KMT_main_bop`：**党务官僚 vs 蒋介石**（各 4 档），极端档（±0.9 外）`on_activate` 触发 `add_power_balance_value` 回推（未完成对应国策时被拉回）——**BOP 与国策树深度联动**；
- `KMT_ycp_bop`：地主商人 vs 教师（青年党内部路线）。
配套 `decision_category`（KMT_the_internal_party_shenanigans）让玩家花 PP 移动指针。

### 3. faction influence 军阀整合（`r56_china_decisions.txt`）
`KMT_integrate_the_cliques_decision`：`custom_cost_trigger` 同时消耗影响力比例（>14.9%）+ PP（>99）；AI 权重按工厂数/阵营角色；完成事件将军阀并入（`autonomy_state = autonomy_integrated_puppet`）。

### 4. Formable Nations（成立国家，40+ 决策 + 13 个统一类 shared_focus）
`r56_formable_nations_decisions.txt`（3919 行）统一模板：
```pdx
unite_korea = {
	available = { is_subject = no
		custom_trigger_tooltip = { tooltip = ...  controls_state = 525 controls_state = 919 ... } }
	complete_effect = {
		set_cosmetic_tag = KOR_unified
		hidden_effect = { every_state = { limit = { OR = { is_core_of = KOR is_core_of = NKR } } add_core_of = ROOT }
			set_global_flag = unite_joseon_flag
			every_country = { every_operative = { ... add_nationality = ROOT } } }  # 间谍国籍合并
		add_ideas = generic_recent_political_unification
		add_ideas = generic_recent_army_unification
		add_ideas = generic_recent_economic_unification
		news_event = { id = r56.news_event.34 } }
}
```
（18 类别：大叙利亚/统一朝鲜/俄罗斯重建/普鲁士/加勒比/阿拉伯/西班牙美洲/马穆鲁克/大德州/西非联盟等；通用树另有 AFR/USC/GCO/PLA/SYR/PER/MONGOL 等 13 个统一类 shared_focus。）

### 5. 流亡政府专属法律（`r56_generic.txt`）
```pdx
influx_of_exiles_r56_law = {  # 已投降/流亡国可用
	available = { has_war = yes has_capitulated = yes }
	modifier = { weekly_manpower = 400 conscription = 0.015 non_core_manpower = 0.2 ... } }

	on_add = { add_offsite_building = { type = industrial_complex level = 2 } ... } }  # 白送厂位
```

### 6. 州类别升级链（发展殖民地）
`r56_state_category_level_up`：`wasteland → pastoral → rural → developed_rural → town → ... → megalopolis` 逐级升级；配套新增州类别 `developed_rural`（3 槽，替换原版 large_island）。

### 7. 殖民核心化决策
`ARG_core_conquered_state`：`target_trigger` 抵抗 <15 且顺从 >45 → 花 75PP 等 35 天 → `add_core_of = ROOT`。
