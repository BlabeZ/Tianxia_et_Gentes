# 模组参考文档库（mod_examples）

> 本目录存放对钢铁雄心4知名大型模组（Kaiserreich、Equestria at War）的代码级分析总结。
> **用途**：制作《天下与万邦》的某个模块时，先查阅对应主题文档，参考其他模组相同/相近模块与机制的实现方法，再结合实际读取原模组代码进行开发。
> 所有分析均来自实际读取原模组代码文件，非二手资料。

> **KX 说明**：本机安装的 2142407679 是"KX 本体 + 汉化"整合包（`common/` 为 KX 英文原码，`localisation/` 为简体中文；另有 `localisation/replace/` 覆盖原版字符串）。KX 是 KR 的扩展，继承 KR 全部基础内容，独有内容见 [10-KX扩展内容参考](10-KX扩展内容参考.md)。
>
> **RT56 说明**：RT56 是**追加式**（additive）模组——descriptor 仅 3 条 replace_path（history/states、map/strategicregions、gfx/fonts），与原版共存而非接管。其"新文件追加 + 同名覆盖保留原版 ID + 引擎替代"的开发方法论见 [11-RT56追加式开发参考](11-RT56追加式开发参考.md)。
>
> **TNO 说明**：TNO 是 1962 年开局的三极冷战 mod（紧张度全系清零、战争事件驱动），以**变量模拟经济系统**与 **133 个 scripted_guis** 著称，详见 [12-TNO冷战经济与GUI参考](12-TNO冷战经济与GUI参考.md)。
>
> **TFR 说明**：TFR 是 2020 年开局的现代战争 mod，核心是**宏观账本经济**（TNO 的简化取舍版）、**国际组织自建系统**（NATO/EU/BRICS 不用原版阵营）、**多实体分裂内战**与 **27K 行巨型分支和平系统**，详见 [13-TFR现代战争与宏观账本参考](13-TFR现代战争与宏观账本参考.md)。

**注意**：文档中引用的代码片段以分析时的版本为准；游戏与模组更新后字段可能有变化，制作时务必回到上述路径核对原文。引用时一般省略根路径，只写相对路径（如 `common/ideologies/00_ideologies.txt`）。

## 三、使用方法（制作模块时的标准流程）

1. 确定要制作的模块（如"意识形态体系"），查阅 [09-世界观映射对照表](09-世界观映射对照表.md) 找到可参考的机制；
2. 阅读对应主题文档（如 [02-意识形态与政治系统.md](02-意识形态与政治系统.md)），了解 KR/EAW 的实现思路与关键代码；
3. 回到原模组路径，用编辑器实际打开文档中引用的文件，核对并深入研读（文档引用可能因版本更新略有出入）；
4. 结合《Settings/》世界观设定与 AGENTS.md 规则，在 mod 工程中实现该模块。

## 四、总体结论速览

- **KR**：全替换式（replace_path 整目录接管），意识形态激进（10 大意识形态删四极），政治机制用"变量+数组+动态修正"实现（联合政府、国会席位、黑周一卡牌），军事上"一战科技嫁接"原版树，AI 深度定制（事件旗标驱动策略）。
- **EAW**：全替换式（直接重写原版同名文件），意识形态保守（四极+65 子类型），灵魂是**魔法系统**——以"标签+类别+专精"三位一体横向渗透所有子系统；变量经济系统（爱情/魔法平衡/邪恶计量器）用每日 on_actions 结算；多国策树按剧情切换；脚本边界极限利用（手写 arctan、while 防溢出）。
- 两者共同点：on_startup 集中做全局初始化（大陆数组、全局事件目标、外交网络）；game_rules 提供国家路径/剧本选项；scripted_effect/trigger 按国家拆分文件复用；开局国家文件是"总装清单"（政治+科技+外交+事件预排+角色全在一个文件）。

- 现实历史素材仅可作参照说明，不得混入《天下与万邦》世界观（见 AGENTS.md 硬约束 2）。
