# 04-军事与科技系统

> 适用：科技树、学说、装备/兵种、MIO、AI 军事配置、人物/指挥官。
> 参考样本：KR（一战科技嫁接、学说重写、MIO 国策联动、AI 事件驱动）、EAW（魔法科技渗透、龙装备、种族特战学说、魔法 MIO）。

## 一、科技树：两种覆盖方式

| | KR | EAW |
|---|---|---|
| 覆盖 | `replace_path="common/technologies"` + 内部"原版科技 + 前插自创" | 直接重写原版同名文件（`infantry.txt` 等，`#EAW modified` 注释） |
| 自创科技 | `gw_artillery`/`gwtank`/`gwtank_chassis`/`early_fighter`/`gw_armored_car_equipment` | 种族科技 16 文件 + `magical_weapons` 线 + `EAW_unique_tech.txt`（4408 行） |
| 接入方式 | 两者相同：`path = { leads_to_tech = 原版科技 research_cost_coeff = 1 }` 嫁接 |

### KR 一战科技"嫁接"示例（`common/technologies/NSB_armor.txt`）
```pdx
gwtank_chassis = { #Leichttraktor
	show_equipment_icon = yes
	enable_equipments = { light_tank_chassis_0 medium_tank_chassis_0 heavy_tank_chassis_0 ... }
	enable_equipment_modules = { tank_torsion_bar_suspension tank_riveted_armor ... }
	enable_subunits = { light_armor medium_armor heavy_armor }
	path = { leads_to_tech = basic_light_tank_chassis ... }  # 3 条分叉
	research_cost = 2
	start_year = 1918
	folder = { name = nsb_armour_folder position = { x = 2 y = 0 } }
	ai_will_do = { base = 0 modifier = { add = 500 is_eligible_for_armor_production = yes } }
	categories = { armor mio_cat_tech_all_armor_and_modules cat_light_armor }
	special_project_specialization = { specialization_land }
}
```
- KR 特色：`ai_will_do = { base = 0 add = 500 }` 模式（只有有装甲生产能力的国家才研究）；`basic_light_tank` 直接 `ai_will_do = { base = 0 } # KR production changes - only mediums`（AI 只产中型）。
- **DLC 双轨 folder**：`armour_folder`（`available = { has_dlc_nsb = no }`）与 `nsb_armour_folder` 并存；空军同理（BBA 双轨）。

### EAW 魔法科技示例（`common/technologies/pony_tech.txt`）
```pdx
tech_unicorn = {
	dependencies = { pony_race = 1 tech_support = 1 }
	enable_subunits = { unicorn_company }
	enable_subunits = { limit = { has_dlc = "Thunder at Our Gates" } hq_support_unicorn_teleporters }
	path = { leads_to_tech = tech_unicorn_ms research_cost_coeff = 1 }
	path = { leads_to_tech = tech_unicorn_th research_cost_coeff = 1 }
	categories = { magical_tech unicorn_tech race_tech }
	special_project_specialization = { specialization_magical }
	ai_will_do = { factor = 6 modifier = { factor = 4 interested_in_magic = yes } }
}
```
- **事件授予型科技**：`allow = { always = no }` 不可研究，由国策/事件给（如 `WIT_healing_magic_tech`、`dragons_light`）。
- **互斥科技**：`tech_pony_magical_infantry = { xor = { tech_pony_unicorns } }` 二选一。
- **科技 folder**：EAW 自创 16 个种族文件夹（`pony_folder` 等），全部 `ledger = civilian` + 种族科技旗标门控（`available = { has_pony_race_tech = yes }`），避免切换标签页 bug；无 magic_folder——魔法科技散在种族树与步兵树。

## 二、科技标签（technology_tags）

- `common/technology_tags/00_technology.txt`：原版标签 + folder 定义。
- KR/EAW 均大量使用 `mio_cat_*` 标签（如 `mio_cat_tech_all_armor_and_modules`）把科技归属到 MIO 研究类别。
- EAW `eaw_technology.txt`：39 个自定义分类，核心 `magical_tech`，另有 `race_tech`/`unicorn_tech`/`pegasi_tech`/`kirin_*`/`airship_tech` 等——AI 研究权重（`ai_research_weights = { magical_tech = 1.0 }`）靠这些标签。

## 三、学说体系（doctrines）

### 原版结构（v1.19.2，AAT 体系）
```
common/doctrines/
├── grand_doctrines/     # 大学说（land/air/sea，每学说含 tracks + milestones）
├── subdoctrines/        # 子学说（land/air/sea/special_forces，xp_cost + rewards + mastery）
└── tracks/              # 轨道定义（land: infantry/combat_support/armor/operations）
```

### KR（15 文件）
- 大学说完整重写，`mass_assault` 的 AI 权重为中国军阀加码（`OR = { tag = QIE tag = CHI ... } factor = 100`）；
- 自创子学说 `great_war_infantry`（xp 50，`rewards = { traverse_digging ... redoubt_networks }`）；
- `mounted_infantry` AI 权重给蒙古系国家（MON/XSM ×200）；
- NCNS 子学说用 `visible = { has_dlc_ncns = yes }` 门控。

### EAW（42 文件）
- 自创**特种部队大学说**（`special_forces_grand_doctrines.txt`）：`special_forces_quantity`（cap+0.04）vs `special_forces_quality`（组织度+10）；
- 自创**种族特战子学说** `racial_specforces`（556 行文件）：专精 `category_racial_special_forces`，4 级奖励，且对龙/蠕虫**反向修正防超模**：
```pdx
racial_specforces = {
	track = { special_forces_first special_forces_second special_forces_third }
	xp_cost = 60
	mastery = { multiplier = 6 categories = { category_racial_special_forces } }
	category_racial_special_forces = { soft_attack = 0.025 max_organisation = 2.5 }
	rewards = {
		reward_2 = {
			category_racial_special_forces = { air_attack = 500 soft_attack = 0.1 }
			heavy_dragons = { air_attack = -499 }   # 龙不受空袭加成，防重复叠加
		}
	}
}
```
- 魔改原版精通倍率（`#EAW modified was 1.0`）平衡魔法兵种经验通胀。

## 四、装备与兵种（units）

```

├── equipment/           # 装备定义（archetype 原型 + 具体型号 parent 链）
```

```pdx
	maximum_speed = 9
```

### EAW 龙装备（`equipment/dragon_eq.txt`）——装备自带攻防数值的范式
```pdx
dragon_equipment = {
	is_archetype = yes
	type = infantry
	active = yes
	reliability = 0.5 maximum_speed = 12
	defense = 40 breakthrough = 30
	hardness = 0.8 armor_value = 10
	soft_attack = 30 hard_attack = 8 ap_attack = 30 air_attack = 25
```

```pdx
GER_erich_von_manstein = {
```

## 九、制作本模块时的检查清单

1. 科技树：按 `path = { leads_to_tech }` 嫁接自创科技（1910 年代的 gw 系列直接参考 KR）；folder 用 DLC 双轨；`start_year` 与开局日期匹配；
2. 新概念渗透（本 mod 的"现代性/实学/西学"）：建立 标签（technology_tags）+ 类别（unit_tags）+ 专精（specialization）三位一体，参考 EAW magical_tech 模式；
3. 学说：AAT 体系下自创子学说时注意 `mastery` 倍率与反向修正（防叠加超模）；
4. MIO：include 通用组织 + `available = { has_completed_focus = ... }` 国策门控特质；`equipment_type`/`research_categories` 限定专精范围；
5. AI：先做 `ai_templates`（blocked_for 定制）+ `ai_strategy`（role_ratio + 事件旗标），大国补 `ai_strategy_plans` 剧本计划；
6. 人物：每国一文件、ID 规范、随机池禁用、legacy_id 唯一、顾问配套 idea_token。

## 十一、RT56 扩展视角：三层科技扩展体系

RT56 在"保留原版科技树"前提下的扩展方案（详见 [11-RT56追加式开发参考.md](11-RT56追加式开发参考.md) 第四节）：

1. **常规树外科手术式延伸**：覆盖原版同名科技文件（12 个），在保留原版科技定义的前提下插入新分支——`path = { leads_to_tech = main_battle_tank_a } # R56`、改 folder 位置腾空间、`sub_technologies` 改显式 `path`；新科技用 `_2/_a/_b` 后缀（main_battle_tank_a 1947 → _e 1955、tech_engineers_a/b/c 1948/1951/1954）；
2. **独立整树（SRD）**：`r56e_etax.txt` 38 科技独立 folder（etax_folder），根 1918 → 终局 1943（含登月科技），根科技 `allow_branch = { NOT = { has_global_flag = disable_r56_techs } }` 全局开关；
3. **国家专属 + 特殊工程隐藏科技**：`research_cost = 1` + `allow = { always = no }`（国策/事件授予）；特殊工程完成 → `set_technology` 解锁隐藏科技 → `enable_equipment_modules`（"光学测距仪"父子项目链范式）。

配套：新 folder 在 `common/technology_tags/r56e_technology.txt` 注册；新兵种 12 个（自行车/猎兵/丛林/沙漠/突击队系列/惩戒营/假情报单位）+ 空中单位 6 种（战斗轰炸机/水上飞机/舰载喷气）；特种部队学说同步跟进（`shocktroops_1/2` 子学说 + `r56_guerilla_warfare` 游击战大学说，`ai_will_do = { factor = 0 is_major = yes }` 大国不点）。
