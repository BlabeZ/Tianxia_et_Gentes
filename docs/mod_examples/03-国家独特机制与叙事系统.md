# 03-国家独特机制与叙事系统

> 适用：各国专属玩法（内战、危机、资源型经济、路线切换）、事件链调度、叙事机制。
> 参考样本：KR（美国内战、黑周一、中国 alignment、西班牙狂热、俄国派系）、EAW（爱情经济、亡灵转化、魔法平衡、邪恶计量器、多树切换、大君之死）。

## 一、大型内战：KR 美国第二内战（ACW2）

文件：`common/scripted_effects/01_American Civil War effects.txt`（4721 行）、`common/scripted_triggers/USA triggers (United States).txt`、`common/scripted_localisation/01 - American_Civil_War_scripted_localisation.txt`

**实现技术**：释放国家 + cosmetic tag + 全局 flag + collection 数组 + 针对性决策 + 变量（实力系数）。

**开战总控** `USA_civil_war_begins`：
```pdx
if = {
	limit = { NOT = { has_global_flag = USA_civil_war_begun_flag } }
	set_global_flag = USA_civil_war_begun_flag
	#declarations of war
	if = { limit = { country_exists = WCA } WCA = { declare_war_on = { target = USA type = civil_war } } }
	if = { limit = { country_exists = APG } APG = { declare_war_on = { target = USA type = civil_war } } }
	# remove USA cores in uncontrolled territory
	every_state = {
		limit = { is_core_of = USA }
		if = {
			limit = { OR = { is_controlled_by = WCA is_controlled_by = APG is_controlled_by = ACC } }
			remove_core_of = USA
			add_claim_by = USA
		}
	}
	#hidden looping event for ACW desertions
	USA = { country_event = { id = american_civil_war_events.803 days = 1185 random_days = 100 } }
	...
}
```

**释放一方** `USA_release_WCA`（一次性完成 9 件事）：
```pdx
WCA = {
	add_state_core = 261 #Ohio
	...
	set_cosmetic_tag = WCA_ACW          # 换国号
	transfer_technology_without_doctrines = yes   # 科技转移
	send_equipment_fraction = { target = WCA value = 0.4 }  # 分装备
	add_civil_war_target = USA
	set_temp_variable = { coalition_partner_var = token:totalist }
	add_to_coalition = yes               # 开局即建联合政府
	load_oob = ACW_WCA_air_bba           # 空军编制按 DLC 分支
	add_ideas = WCA_red_guard_militias_1
	...
}
```
配套：`collection:all_mainland_american_states` 激活各州征兵定向决策；`ACW_strength_factor` 变量计算双方初始军力；战后 `USA_civil_war_ends` 复原 cosmetic tag、挂战后国家精神、工厂重建。

## 二、回合制危机卡牌：KR 德国黑周一

文件：`GER effects (Germany).txt`（5799 行）、`01_Black Monday effects.txt`、`GER decisions (Germany).txt`、`common/scripted_guis/germany_black_monday.txt`

**四件套**：角色对象（卡牌）+ 数组（卡池）+ 定向决策（出牌）+ scripted_gui（界面）。
- 卡牌注册：25 张经济卡以角色对象形式 `add_to_array = { GER.GER_cardgame_object_array = THIS }`（国家历史文件中初始化，含 `card_id`/`card_investment_value` 等变量）；
- 发卡：`GER_bm_card_add` 将卡加入 `GER_bm_cardgame_cards_array` 并计数；国策完成给卡池发卡（`activate_targeted_decision`）；
- 回合计时：`GER_set_bm_turn_timer` = 15 天 + 每级经济健康 +15 天；
- 危机等级：`GER_black_monday_2~10` 九级精神用 `swap_ideas` 逐级恶化，`GER_increase_black_monday` 升级；
- 全球蔓延：`fire_black_monday_events` 向 50+ 国派发各自的经济崩溃事件（`MAF = { country_event = mittelafrika_events.200 }`、`USA = { country_event = united_states_events.2 }`）；
- 收尾：`GER_bm_game_end` 清空数组 + `remove_targeted_decision`。

**启示**：《天下与万邦》大顺"盛世危机"（黑天鹅事件开局）可完全复刻此结构：财政危机卡牌游戏 + 全球连锁经济事件。

## 三、资源型经济机制（EAW 三例）

### 1. 幻形灵爱情经济（CHN）
`common/on_actions/eaw_on_daily_on_actions.txt` 每日结算：
```pdx
### State Total (S) : [ directly-controlled non-core states + (indirectly-controlled states / 2) ]
set_temp_variable = { CHN_weekly_love_gain_state_var_TEMP = { value = CHN.num_of_controlled_states subtract = CHN.num_core_states } }
set_temp_variable = { CHN_amount_of_allowed_battalions_TEMP = { value = CHN_weekly_love_gain_state_var add = 10 multiply = 10 } }
# 超编消耗：CHN_excess_battalions × 0.001 erots/营/日
add_to_variable = { CHN_excess_battalions_cost = { value = CHN_excess_battalions multiply = 0.001 } }
# 赤字惩罚
if = {
	limit = { check_variable = { CHN_love_variable < 0 } }
	set_variable = { CHN_penalty_from_love_deficit_var = { value = CHN_love_variable divide = 4 clamp = { min = -1.50 max = 0 } } }
	add_dynamic_modifier = { modifier = CHN_love_deficit_dynamic_modifier }
}
# 占领区收割（抵抗度降低收益）
CHN_continuous_love_harvesting_LOVE_var_TEMP = { value = CHN_weekly_love_gain_state_var divide = 2000 multiply = { value = 100 subtract = CHN_average_resistance_level_of_states_under_occupation_var divide = 100 } }
```
公式链：免费营上限 = (10 + S) × 10 → 超编耗爱情 → 赤字惩罚 → 占领收割。国策解锁增幅（`CHN_love_refineries` +25%）。

### 2. 亡灵人口转化（DED）
`common/scripted_effects/EAW_necromancy_effect.txt`：
```pdx
decrease_population_necromancy = {
	if = { limit = { state_population > 999999 }
		set_temp_variable = { pop_to_kill = state_population_k }
		set_state_flag = state_population_thousands
	}
	else = { set_temp_variable = { pop_to_kill = state_population } }
	multiply_temp_variable = { pop_to_kill = 0.1 } #10%
	if = {
		limit = { has_state_flag = state_population_thousands }
		while_loop_effect = { #avoid overflows
			limit = { check_variable = { pop_to_kill > 999 } }
			subtract_from_temp_variable = { pop_to_kill = 1000 }
			ROOT = { add_manpower = 1000000 }
			add_manpower = -1000000
		}
	}
}
```
要点：战时用 `every_controlled_state`、平时用 `every_owned_state`；while_loop 分块防溢出；零和转移。

### 3. 魔法平衡（EQC/ED）
`common/scripted_effects/EAW_EQC_ED_effect.txt`：`arctan((EQC magic - EQS magic)/5000)`——游戏无 arctan，**手写泰勒级数九阶**（`ED_calculate_arctan`：`x - x³/3 + x⁵/5 - x⁷/7 + x⁹/9`）；结果写入 `current_magic_balance`，换算成法师组织度/指挥点/攻防修正；每周自然衰减向零回归（"优势随占领衰减"）。

### 4. Equestria 邪恶计量器
`celestia_evil_meter` 旗标值（0-100）：决策与国策双向博弈（妥协 <33 走民主路线、>46+法西斯>30%+开战 → 堕落为 Daybreaker）；开局 `manpower_laws_blocked`/`economic_laws_blocked` 旗标锁兵役/经济法，需决策触发事件解锁；`harmonic_stagnation` 三级国家精神（开局 -35% 科研 +70% 消费品）战争压力下逐级解除。

**启示**：以上四个都是"每日/每周 on_actions 结算的变量 + 动态修正"模式。大顺的财政、朝贡收支、改革支持度可直接套用。

## 四、多国策树路线切换（EAW KIR/HIP/GRI）

- **KIR**：14 棵 focus_tree（`KIR_early_game` → `KIR_middle_late_game`/`_civil_war` → `KIR_post_civil_war` → `KIR_council`/`KIR_republic`/`KIR_council_empire_focus_tree`），用 `has_focus_tree` 触发、`load_focus_tree` 替换。
- **GRI**：3 棵树（imperial_focus / imperial_army_focus / imperial_grover_focus，不同时期）。
- **EQS**：1 棵树但 110 个国策全用 `shared_focus` 形式，供 EQS/NLR/SOL 各分支国家共享；`bypass = { hidden_trigger = { is_EQS_SOL = yes } }` 按路线自动跳过。
- 分支解锁的通用手段：`available = { always = no }` 隐藏国策 + 事件 `complete_national_focus` 强制完成解锁新分支 + `allow_branch`（旗标出现前整个分支不可见）+ `dynamic = yes`（战况变化即失效）。

**启示**：大顺"理学守成 / 实学改革 / 君主立宪 / 革命"四路线可用多树切换或单树分支两种方案。

## 五、事件链调度（叙事标准写法）

### EAW 格里芬大君之死（`events/GriffonianEmpire Events.txt` imperial.3）
```pdx
option = {
	name = imperial.3.a
	GRI_emperor_grover_v = { retire = yes }
	add_country_leader_role = { character = GRI_regency_council country_leader = { ... } promote_leader = yes }
	add_political_power = -50
	add_stability = -0.35
	set_country_flag = GRI_emperor_dead
	set_global_flag = GRI_emperor_dead          # 全局旗标通知所有诸侯
	add_ideas = GRI_grover_vi
	hidden_effect = {
		news_event = { id = imperial_news.3 hours = 6 }
		MNC = { country_event = { id = mountain.1 days = 3 random = 48 } }
		BRZ = { country_event = { id = bronzehill.1 hours = 3 } }
		...
		complete_national_focus = GRI_emperor_passed   # 强制完成隐藏国策解锁新分支
	}
}
```
**调度链模式**：on_startup 排 `imperial.1`（+100PP）→ 40 天后 `imperial.2` → 20 天后 `imperial.3`（驾崩）；`set_global_flag` + 向 8 位诸侯错峰派发（4-39 天）反应事件。

### KR 全球事件链（黑周一蔓延 / 二战开幕）
- `ai_events.200`（二战开幕式）：`set_global_flag = second_weltkrieg_has_started` + `add_named_threat` + 各国开战事件；
- 德国意外灭亡兜底：`on_annex` 检测 `FROM = { tag = GER }` 且未开战 → 强制触发。

### 通用事件结构规范
- 文件首行 `add_namespace = xxx`（唯一前缀防 id 冲突），事件 id `xxx.数字`；
- `immediate = { log = "[GetDateText]: [Root.GetName]: event xxx" }` 调试埋点；
- `fire_only_once` / `is_triggered_only` / `trigger` 条件 / `option = { ai_chance = {...} }`；
- 事件目标传参：`save_event_target_as = xxx` + `event_target:xxx` 跨国家引用；
- MTTH 轮询事件：`mean_time_to_happen = { days = 15 }`。

## 六、KR 中国 alignment 系统（角色变量承载政治归属）

`common/scripted_effects/01_China effects.txt`：
```pdx
china_set_character_alignment_northern_zhili = {
	event_target:system = { china_alignment_northern_zhili = { set_variable = { PREV.PREV.china_alignment = THIS } } }
}
```
10 种归属（北直系/南直系/满清/奉天/北洋/联邦派/左右KMT/南方共和/大亚细亚）存在**国家领导角色身上的变量**；`china_character_is_left_kuomintang` 触发器经 `event_target:system` 读变量判型；全国政府机制 `set_potential_national_government` 建全球事件目标 + 州数组宣称；`CHI_phase_*_begins_flag` 四阶段划分；军阀军民平衡用变量（KUM_military_influence vs KUM_chinese_influence）或 BOP（SHX 阎锡山 vs 冯玉祥）。

## 七、KR 西班牙狂热系统（surrender_progress 推导）

```pdx
SPA_calculate_fervor_effects = {
	set_variable = { fervor_level = THIS.surrender_progress }
	multiply_variable = { fervor_level = -1 }
	add_to_variable = { fervor_level = 1 }   # fervor = 1 - surrender_progress
	set_variable = { fervor_org_modifier = fervor_level }
	multiply_variable = { fervor_org_modifier = 0.4 }
	add_to_variable = { fervor_org_modifier = -0.2 }  # org lerp +20% 到 -20%
	force_update_dynamic_modifier = yes
}
```
`on_state_control_changed` 每次州易手重算双方狂热并概率触发恐怖事件；`random_list 8/92` 权重分支。

## 八、制作本模块时的检查清单

1. **先定机制载体**：flag（简单开关）/ 变量（可数值化状态）/ 数组（多成员）/ 角色（带 UI 的对象）/ BOP（双向条）/ 多国策树（阶段叙事）；
2. 数值型机制统一放 on_actions（on_daily/on_weekly/on_monthly）结算，配合 `force_update_dynamic_modifier` 刷新；
3. 大型内战照抄 KR 模板：释放国家 → cosmetic tag → 去核心化 → 分装备分科技 → 宣战 type=civil_war → 战后复原；
4. 卡牌/危机系统照抄黑周一四件套：角色对象+数组+定向决策+scripted_gui；
5. 事件链统一规范：namespace 前缀、log 埋点、fire_only_once、错峰 days/random_days 调度、全局旗标连锁、complete_national_focus 解锁分支；
6. 每个机制配套 scripted_trigger（判型）与 scripted_effect（执行），按国家/主题拆分文件。

## 九、TNO 扩展视角：变量矩阵型政治与阶段式叙事

TNO 补充的两种高价值模式（详见 [12-TNO冷战经济与GUI参考.md](12-TNO冷战经济与GUI参考.md) 第七节）：

1. **变量矩阵型选举**（美国）：**7 群体 × 6 政党 affiliation 变量矩阵**（`black_com_affiliation` 等 42 个变量），每周 `USA_political_weekly_tick` 让极端派衰减、转入主流派；国会法案每法案定义各党初始支持率 + `flip_cost` 拉票成本——政治完全数值化，GUI 实时可视化；
2. **卡牌/仪表盘式政治斗争**：鲍曼卡牌屋（三大派系 × 12 个特殊利益集团数组，各带 Power 与 Loyalty，`BOR_Control_Update` 算可控百分比）、施佩尔 Speerdometer（`SGR_Alignment` 五档仪表盘）——复杂政治 = 变量数组 + scripted_gui 渲染；
3. **阶段式多树叙事**（广东）：8 棵 focus_tree 按剧情阶段切换（suzuki→yasuda_crisis→silicon_years→oil_crisis→riots→ending），状态变量切换 dummy idea；
4. **国策树"空心化"**：focus_tree 壳 + shared_focus 实体（UI）+ 实际逻辑全在 tooltip 背后（GUI/事件/决策）；`allow_branch` 限定元首（希特勒在位才进开局树）；德国开局树仅 1 个 focus 的"fakeout"序章设计（登月序幕后事件切到真正四政权树）；
5. **计分制内战判定**（德国 GCW）：兵力/装备/投降进度各 1 分 + 元首遗嘱 flag 加权 2 分，`GER_GCW_select_victor` 判胜负——比纯事件判定更可控。

**本项目适用**：大顺"皇权-文官-军事贵族"三方角力可用卡牌屋式 SIG 数组；改革路线用阶段式多树；朝贡体系更替用计分制。
