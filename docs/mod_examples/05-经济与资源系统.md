# 05-经济与资源系统

> 适用：经济法、贸易法、资源、建筑、动态修正、禁运、经济圈/共同市场。
> 参考样本：KR（禁运系统、经济圈 Mitteleuropa、闭关经济法、动态修正）、EAW（crystals 资源、叙事经济法、核反应堆水晶循环、魔法工业）。

## 一、经济法的位置与结构

**注意**：v1.19.2 **没有** `common/economy_laws/` 目录！经济法位于 `common/ideas/_economic.txt`（贸易法同文件），兵役法在 `_manpower.txt`。结构：
```pdx
ideas = {
	economy = {
		law = yes
		use_list_view = yes
		civilian_economy = {
			cost = 150
			removal_cost = -1
			default = yes
			available = { ... }
			modifier = {
				consumer_goods_expected_value = 0.35
				production_speed_industrial_complex_factor = -0.3
				...
			}
			on_add = { ... }
			ai_will_do = { factor = 2 ... }
		}
	}
}
```
- 法律统一 `cost = 150`（PP）；稳定度/战争支持度代价需自己在 `on_add` 里用 `add_stability` 等实现；
- `allowed = { always = no }` 的法律只能通过事件/国策加入（`add_ideas`）；
- 常用修饰键：`consumer_goods_expected_value`、`production_speed_*_factor`、`conversion_cost_*`、`min_export`、`max_fuel_factor`、`fuel_gain_factor`、`factory_energy_consumption`、`trade_opinion_factor`。

## 四、KR 禁运系统（意识形态隔离的经济武器）

### defines（`common/defines/KR_embargo_defines.lua`，全文 3 行）
```lua
NDefines.NDiplomacy.EMBARGO_COST = 50 -- Vanilla is 100
NDefines.NDiplomacy.EMBARGO_THREAT_THRESHOLD = -1 -- Vanilla is 30
NDefines.NAI.EMBARGO_WORLD_TENSION_THREAT_DIVISOR = 0 -- Vanilla is 2.5
```
（成本减半；紧张度阈值 -1 使 AI 永不禁运；紧张度联动关闭。）

### 实现（`common/scripted_effects/00_useful_scripted_effects.txt` 1002-1214 行）
自建"变量 + opinion/外交关系"双层标记：
```pdx
#requires a temp variable target
embargo_TARGET = {
	if = {
		limit = {
			var:target = {
				NOT = { has_variable = embargoed_@PREV }
				is_in_same_economic_sphere_as_PREV = no   # 经济圈内禁止互禁
				NOT = { tag = PREV }
			}
		}
		hidden_effect = {
			var:target = {
				add_to_temp_array = { embargo_target_and_subjects = THIS }
				every_subject_country = { add_to_temp_array = { embargo_target_and_subjects = THIS } }
			}
			add_to_temp_array = { embargo_target_and_subjects_reverse = THIS }
			every_subject_country = { add_to_temp_array = { embargo_target_and_subjects_reverse = THIS } }
			for_each_scope_loop = {
				array = embargo_target_and_subjects
				for_each_scope_loop = {
					array = embargo_target_and_subjects_reverse
					set_variable = { embargoed_@PREV = 1 }       # 双向变量标记
					PREV = { set_variable = { embargoed_@PREV = 1 } }
					if = {
						limit = { has_dlc_bba = yes }
						diplomatic_relation = { country = PREV relation = embargo }   # BBA 硬外交
						...
					}
					else = {
						add_opinion_modifier = { modifier = embargo target = PREV }
						reverse_add_opinion_modifier = { modifier = embargo target = PREV }
					}
				}
			}
		}
	}
}
```
- 连带附庸：两个临时数组做矩阵式双向禁运；
- 双轨：有 BBA 用 `diplomatic_relation`，无则 opinion（`embargo = { trade = yes value = -400 }`）；
- 解除 `clear_embargo_TARGET`：清变量 + 外交关系 active=no + remove_opinion_modifier；
- 便捷包装：`embargo_ROOT/PREV/FROM`。

### 触发（`common/on_actions/00_on_actions_global.txt` 496-517 行）
```pdx
every_possible_country = {
	limit = { has_socialist_government = yes is_dynamic_country = no }
	for_each_scope_loop = { array = ENT.faction_members embargo_PREV = yes }
	for_each_scope_loop = { array = GER.faction_members embargo_PREV = yes }
	RAJ = { embargo_PREV = yes } SRD = { embargo_PREV = yes } ...
}
```
动态维护：`on_ruling_party_change` 附庸政变后重新施禁；`on_annex`/`on_war`/`on_offer_join_faction` 自动清理；经济圈加入时圈内互清。

## 五、KR 经济圈（economic spheres）——天下体系的现成方案

**实现**：用 **character 当容器**的变量数组系统（`common/scripted_effects/00_economic_sphere_scripted_effects.txt`）：
- `create_economic_sphere`：`generate_character = { token_base = economic_sphere }` 生成"圈"角色，存 `members` 数组 + 随机 RGB 颜色（供专属地图模式着色）；
- `add_to_economic_sphere`：加入时自动清除圈内互禁运 + AAT 市场准入（`diplomatic_relation = { relation = market_access_rights }`）；
- `leave_economic_sphere` / `dismantle_economic_sphere` / `set_economic_sphere_leader`（leader = members 数组索引 0）；
- 触发器：`is_in_economic_sphere`（`check_variable = { economic_sphere = 0 }`）、`is_economic_sphere_leader`（`tag = var:economic_sphere:members^0`）、`is_in_same_economic_sphere_as_ROOT`；
- 地图模式：`common/map_modes/economic_spheres.txt` 按圈颜色着色，未入圈灰色。

德国 Mitteleuropa 经济圈加成（`MIT dynamic_modifiers (Mitteleuropa).txt`）：
```pdx
MIT_mitteleuropa_modifier = {
	min_export = MIT_min_export
	trade_opinion_factor = MIT_trade_opinion_factor
	consumer_goods_factor = MIT_consumer_goods_factor
	industrial_capacity_factory = MIT_industrial_capacity_factory
	research_speed_factor = MIT_research_speed_factor
	...
}
```
全部数值来自国家变量（`MIT_min_export` 等），随中欧议程投资动态变化；`GER_is_in_mitteleuropa = { has_dynamic_modifier = { modifier = MIT_mitteleuropa_modifier } }` 是唯一判定标准。

**启示**：本 mod 的"天下体系/威斯特伐利亚体系"经济隔离 = KR 禁运系统 + 经济圈组合拳；"朝贡贸易"= 经济圈 + 贸易法 min_export 调节。

## 七、动态修正（dynamic_modifiers）通用模式

文件：`common/dynamic_modifiers/`（KR 64、EAW 56）。核心模式：**变量驱动 + 条件移除**。
```pdx
# EAW 战争州修正
WAR_tobuck_resistance = {
	remove_trigger = { OR = { BAT = { exists = no } WAR = { exists = no } } }
	state_resources_factor = -0.5
	recruitable_population_factor = -0.5
	disable_strategic_redeployment = yes
}
# KR 政党支持度
party_popularity_dynamic_modifier = { political_power_gain = party_popularity@ruling_party }
# KR 鲁尔斗争（变量驱动）
GER_Ruhrkampf = { local_manpower = GER.GER_ruhrkampf_manpower_factor ... }
```
使用：`add_dynamic_modifier = { modifier = X scope = GER days = 14 }`；`force_update_dynamic_modifier = yes` 强制刷新。

## 九、制作本模块时的检查清单

1. 经济法 = `common/ideas/_economic.txt` 追加（注意 v1.19.2 无 economy_laws 目录）；世界观经济制度（闭关/朝贡贸易/保护主义）新增法律 + `min_export`/`consumer_goods` 调节；
2. 体系隔离 = KR 禁运系统（变量标记 + 附庸连带 + 双轨外交关系）；
3. 经济联盟 = 经济圈（character 容器 + 地图模式着色），可做"天下经济圈/威斯特伐利亚经济圈"；
4. 独特资源（如需）按 EAW crystals 模式：resources 追加 + 建筑产资源 + 消耗循环；
5. 一切数值型经济状态用"变量 + 动态修正 + on_daily 结算"三件套；
6. 贸易法 `rule = { can_access_market = no }` 可做体系间市场隔离。

## 十、KX 扩展视角：法律化贸易条约（产能转移）

KX 对经济法系统的独特创新：**把不平等条约做成强制贸易法**（`common/ideas/China_ideas.txt`、`Turkestan_ideas.txt`）：

```pdx
trade_laws = {
	law = yes
	use_list_view = yes
	unequal_treaties = {
		allowed = { always = no }            # 不可移除
		cancel = { 743 = { owner = { is_chinese_tag = yes NOT = { tag = LEC } } } }  # 收回上海州才取消
		modifier = { min_export = 0.6 civilian_intel_to_others = 40.0 }
		targeted_modifier = { tag = LEC cic_to_target_factor = 0.3 }   # 30% 民用工厂产能定向输送
	}
}
```

要点：`targeted_modifier` 的 `cic_to_target_factor` / `mic_to_target_factor` 把产能按比例输送给宗主/列强；`cancel` 块做自动解除条件（收回领土/旗标）；`on_add`/`on_remove` 可附带军通/事件（突厥斯坦铁路开局自动给俄国军通 + 15% 产能转移）；法律还与科技共享组跨机制联动（`russian_research` 的 available 检查 `has_idea = TRK_russian_railways`）。

**本项目适用**：大顺的朝贡岁币、华商铁路贷款、国际开发区收益分成均可按此模式——"法律化条约 + 产能转移 + 解除条件"。

详细见 [10-KX扩展内容参考.md](10-KX扩展内容参考.md) 第三节。

## 十一、TNO 扩展视角：变量模拟经济（全模拟闭环）

TNO 提供最深度的经济方案（详见 [12-TNO冷战经济与GUI参考.md](12-TNO冷战经济与GUI参考.md) 第二节）：**完全替代原版工厂经济的变量模拟**——

```
开局变量（GDP/税率/债务/贫困/信贷评级 200+ 国）
  → 月度脉冲单入口（econ_calculations_ON_MONTHLY，AI/玩家分叉）
  → 结算链（投资→贫困→贸易→经济圈→预算→收支→赤字→评级→央行→通胀→增长）
  → 引擎桥接三件套：
      modifier_definitions（注册 40+ 经济键）
      → dynamic_modifiers（变量映射进原版 modifier 槽）
      → offsite buildings（PU 数字转为原版工厂条）
  → 显示层（scripted_gui：GDP 州显示/信贷阶梯/经济圈/电力开关）
  → AI（auto_set_ai_pus/自动央行/自动预算）
  → 冷战得分（GDP 直接进 Score_Economy）
  → 地图模式（GDP 人均着色）
```

要点：GDP 自底向上（州 `state_value` 累加）；生产单位 PU 分配三类（民用/军用/消费品）转 offsite buildings；信贷阶梯 1-10 级影响利率/债务上限/稳定度；经济圈 `ECON_SPHERE_LEADER` 变量 + 月度重建成员数组 + 圈占世界 GDP 百分比。

**本项目取舍**：TNO 式全模拟工作量巨大（176 effects + 15000 行）。建议初期做**简化三件套**（GDP 变量 + 财政收支 + 朝贡贸易额），用"modifier_definitions → dynamic_modifiers → offsite buildings"接线层保持与引擎兼容，后续再逐步深化。

## 十二、TFR 扩展视角：宏观账本（TNO 的取舍版）

TFR 提供经济模拟的**中等粒度方案**（详见 [13-TFR现代战争与宏观账本参考.md](13-TFR现代战争与宏观账本参考.md) 第二节）：月度 `add_GDP` 一次结算，公式为"民厂×商业价值 + 人力×个人价值 + 资源出口 + 杂项收入 − 军费 − 债务本息"，年化 ×12，通胀变量累积，实际 GDP 用 1+通胀折算；**现实数据锚定**（开局写入美国 23.7 万亿债务等真实数字）+ 各国 `gdp_fix` hidden idea 校正模拟值贴近现实；`gdp_debt_dynamic`/`inflation_dynamic` 动态修正按债务/GDP 比传导惩罚；玩家干预 = 4 个经济行动（印钞/紧缩/战争税/开发州）+ 税率法；经济账本 GUI 用评分器做全球排名。

**三方案对比（本项目决策用）**：
| | 原版 | TFR 宏观账本 | TNO 全模拟 |
|---|---|---|---|
| 复杂度 | 0 | ~1000 行 | 15000 行 |
| 表现力 | 无经济概念 | 债务/通胀/GDP 排名 | 完整经济循环 |
| 适合 | 快速原型 | **1910 开局推荐起点** | 深度模拟后期扩展 |

另：TFR 的**开发州**（state_category 13 级升级链 wasteland→megalopolis，含 suburb/conurbation）与 RT56 的州类别升级可互为补充。
