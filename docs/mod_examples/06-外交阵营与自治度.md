# 06-外交阵营与自治度

> 适用：阵营（factions）、外交 opinion、傀儡/附庸/朝贡等级（autonomous_states）、科技共享组、战争触发。
> 参考样本：KR（阵营模板+意识形态硬绑定、15 个自定义自治等级、意识形态好感网、二战全局闸门）、EAW（101 阵营文件、大陆结盟规则、40 科技共享组）。

## 一、阵营系统：模板式（现代写法，v1.19.2）

**不用**旧式 `factions = { ... }`，用 **faction_template + 规则文件**。目录：
```
common/factions/
├── templates/     # 阵营模板（KR 15、EAW 64）
├── rules/         # 规则（joining/dismissal/war_declaration/call_to_war/change_leader + groups）
├── goals/         # manifest（阵营宣言/目标）+ 各阵营战略目标
├── upgrades/ member_upgrades/ icons/
```

### KR 主要阵营模板
```pdx
faction_template_reichspakt = {
	name = faction_reichspakt
	icon = GFX_faction_icon_reichspakt
	manifest = faction_manifest_global_hegemony
	default_rules = {
		joining_rule_non_socialist
		dismissal_rule_ideology_socialist
		change_leader_rule_never
	}
}
faction_template_internationale = {
	name = faction_third_internationale
	manifest = faction_manifest_world_revolution
	goals = { faction_goal_industrial_domination }
	default_rules = {
		joining_rule_socialist_only
		dismissal_rule_ideology_not_socialist
		change_leader_rule_manpower
	}
}
```
创建：`create_faction_from_template = faction_template_xxx`。

### 意识形态绑定规则（`rules/joining_rules.txt`）
```pdx
joining_rule_socialist_only = {
	type = joining_rules
	visible = { has_socialist_government = yes }
	trigger = { has_socialist_government = yes }
	can_remove = { always = no }
}
```
**政体变更自动踢出**（`00_on_actions_global.txt` 1394-1415 行）：
```pdx
if = {
	limit = {
		is_in_faction_but_not_leader = yes
		NOT = { has_country_flag = non_ideological_faction_member }
		faction_leader = {
			both_socialist_or_both_not_socialist = no
			scope:faction = { NOT = { has_variable = non_ideological_faction } }
		}
	}
	if = { limit = { is_subject = yes } overlord = { set_autonomy = {...} } }
	leave_faction = yes
	peace_out_non_neighbours_after_leaving_faction = yes
}
```

### EAW 附加规则（`rules/joining_rules.txt` 末尾 `### EAW ADDED ###`）
```pdx
joining_rule_fascist_non_aligned = {   # 法西斯+中立可入

joining_rule_puppets_only = { ... subjects_autonomy_gain = -0.05 }
```

### 阵营 manifest（进度化加成）
```pdx
faction_manifest_global_hegemony = {   # KR 全球霸权宣言
	is_manifest = yes
	ratio_progress = {
		total_amount_collection = collection:non_american_countries
		completed_amount_collection = collection:allied_non_american_countries
		scale = { army_core_defence_factor = 0.20 production_factory_max_efficiency_factor = 0.10 war_support_factor = 0.10 }
		progress_sections = {
			manifest_fulfilled = {
				min = 0.75
				modifier = { extra_trade_to_overlord_factor = 0.20 stability_factor = 0.10 political_power_factor = 0.10 }
			}
		}
	}

```
战略目标库：`faction_goal_control_suez_canal`、`faction_goal_control_ploiesti_oil_fields`、`rule_the_waves` 等（KR）；`faction_goal_a_puppet`（EAW 短程目标）。

## 二、opinion_modifiers

- KR：55 文件（按国 + `00 Generic_Opinion_Modifiers.txt`），结构 `opinion_modifiers = { 名称 = { value、months/years、decay、trade、target } }`。意识形态好感网见 [02-意识形态与政治系统](02-意识形态与政治系统.md) 第三节（6 档动态好感，政变时重算）。
- EAW：单文件 570 行 200+ 条目（`CHN_Embargo = { trade = yes value = -300 }`、`TBK_fake_money = { value = -150 decay = -1 }` 假钞随时间恶化、`ZZZ_day_override_opinion_1..10` 永昼/永夜剧情双向 opinion）。

## 三、自治度等级（autonomous_states）

文件：`common/autonomous_states/`（原版 20 级；KR 23、EAW 32）。**v1.19.2 每等级一个文件**。结构：
```pdx
autonomy_state = {
	id = autonomy_puppet
	default = yes
	is_puppet = yes
	min_freedom_level = 0.4          # 自由分数下限（0=完全吞并，1=完全自由），总分数轴 5000
	manpower_influence = 0.9         # 宗主国对该国征兵影响
	rule = {
		desc = "RULE_DESC_IS_A_SUBJECT"
		can_not_declare_war = yes
		can_decline_call_to_war = no
		can_be_spymaster = no
		contributes_operatives = no
	}
	modifier = {
		autonomy_manpower_share = 0.9
		extra_trade_to_overlord_factor = 1.0
		overlord_trade_cost_factor = -0.9
		peace_score_ratio_transferred_to_overlord = 0.1
		lend_lease_tension_with_overlord = -0.40
		research_sharing_per_country_bonus_factor = -0.5
	}
	use_for_peace_conference_weight = { base = 0 modifier = { add = 10 ... } }
	ai_subject_wants_higher = { factor = 1.0 }
	ai_overlord_wants_lower = { factor = 1.0 }
	allowed = { has_dlc = "Together for Victory" ... }
	can_take_level = { }
	can_lose_level = { }
}
```

### KR 新增 15 个特色等级（与本项目关联最大的）

| 等级 | 用途 | 关键数值 |
|---|---|---|
| `chinese_suzerainty` | **中国朝贡体制（宗主权）** | 直接可改编为本 mod 朝贡国 |
| `KR_mitteleuropa_integrated_member` | 中欧一体化成员 | `min_freedom_level = 0`、禁手动升降 |
| `oststaat` | 德国东部邦国 | `min_freedom_level = 0.4`、`can_decline_call_to_war = no`（强制参战） |
| `governorates` | 奥斯曼行省 | — |
| `union_republic` | 联盟共和国（苏联式） | — |
| `crownland` | 奥匈王室领地 | — |
| `federated_colony/dominion/state` | 英联邦体系 | — |
| `french_colonial_government` | 法兰西殖民政府 | — |

`KR_mitteleuropa_integrated_member` 示例：
```pdx
autonomy_state = {
	id = kr_mitteleuropa_integrated_member
	is_puppet = yes
	min_freedom_level = 0.0
	manpower_influence = 1.0
	rule = { can_not_declare_war = yes can_decline_call_to_war = yes ... }
	modifier = {
		extra_trade_to_overlord_factor = 0.25
		overlord_trade_cost_factor = -0.25
		research_sharing_per_country_bonus_factor = -0.5
		peace_score_ratio_transferred_to_overlord = 0.05
	}
	allowed = {
		overlord = { tag = GER has_completed_focus = GER_officialise_cession_of_sovereignty }
		GER_is_in_mitteleuropa = yes
	}
	allowed_levels_filter = { kr_mitteleuropa_integrated_member }
	can_take_level = { always = no }   # 禁止手动升降，只能剧本/事件授予
	can_lose_level = { always = no }
}
```

### EAW 特色等级
- `imperial_mandate`（帝国委任统治）：`min_freedom_level = 0.5`、`cic_to_overlord_factor = 0.2`、`mic_to_overlord_factor = 0.4`、`peace_score_ratio_transferred_to_overlord = 1`；
- `friendship_associate`（友谊伙伴）：剥削更轻，`extra_trade_to_overlord_factor = 0.15`；
- 均 `can_take_level = { always = no }` 事件锁定。

**启示**：《天下与万邦》建议新增等级：朝贡国（参考 chinese_suzerainty/KR_mitteleuropa）、藩属国（参考 dominion/oststaat）、保护国（参考 supervised_state）、互市国（低自治但贸易高自由，用 `extra_trade_to_overlord_factor` 负数/贸易规则表达）、国际共管区（不适用自治度，用 state 级特殊处理）。

## 四、科技共享组（technology_sharing）

```pdx
technology_sharing_group = {
	id = phalanstere_research          # KR：法共研究圈
	name = phalanstere_research_name
	research_sharing_per_country_bonus = 0.1
	available = {
		has_socialist_government = yes
		INT = {
			is_leader_of_economic_sphere_of_ROOT = yes
			NOT = { has_war_with = ROOT }
		}
	}
}
```
- KR 18 个组（phalanstere/entente_research/german_research/russian_research/us_research/japan_research 等，全部绑定阵营/经济圈领袖）；
- EAW 约 40 个组（`equestrian_research` 条件 `is_in_faction_with = EQS OR is_subject_of = EQS OR original_tag = EQS`；`CRY_SOL_magic_tech_share` 限 `categories = { race_tech magical_tech nuclear }`——**科技共享组可以限定科技类别**）；
- 加入时机：`on_offer_join_faction`、`on_ruling_party_change` 调用 `add_to_faction_tech_sharing_group`；
- `NDefines.NTechnology.MAX_TECH_SHARING_BONUS = 0.5` 封顶。

## 五、战争触发：全局闸门模式（KR 二战）

```pdx
# common/scripted_triggers/_war_scripted_triggers.txt
second_weltkrieg_can_start = {
	if = {
		limit = { second_weltkrieg_has_begun = no }
		OR = { threat > 0.75 date > 1940.8.1 }
	}
}
```
`on_war_relation_added`（00_on_actions_global.txt 2687-2838 行）检测德俄/德法开战（双方须为阵营领袖防误触发）→ `ai_events.200` 正式开幕（`set_global_flag = second_weltkrieg_has_started` + `add_named_threat = 20` + 全球新闻）；`on_annex` 兜底（德国意外灭亡强制触发）。所有国策/决策用 `second_weltkrieg_can_start = yes` 做统一时间轴闸门。

**启示**：本 mod 的"天下大战"触发可用同一模式：`great_war_can_start`（紧张度/日期双条件）+ on_war_relation_added 检测"天下宗主 vs 体系大国"开战。

## 六、外交动态维护（on_actions 中的外交钩子）

- `on_ruling_party_change`：重算意识形态好感网、召回志愿军、踢出非法阵营、附庸重施加禁运；
- `on_annex`：清理禁运、解散经济圈、动态国家区域数组清理；
- `on_offer_join_faction`：加入前清除与盟友的禁运/互不侵犯、加入科技共享组、世界紧张度不对称（保守阵营 -75%）；KR 用 flag 防刷（每国只计一次）；
- `on_war`：开战即清禁运；
- `on_peaceconference_started/ended`：维护 pc_winners/losers 数组、不可通行州转移、和会后 drop_cosmetic_tag 复原。

## 七、制作本模块时的检查清单

1. 阵营 = 模板 + 规则文件（意识形态绑定规则实现"体系内/体系外"结盟限制）；
2. 政体变更自动踢出阵营的 on_ruling_party_change 逻辑必写；
3. 自治等级：每等级一个文件，`min_freedom_level` 决定分数轴位置；等级间分数差 ≤10 才可变动；需要剧本锁定时 `can_take_level = { always = no }`；
4. 新自治等级需本地化（id、AUTONOMY_LEVEL_*、RULE_DESC_*）；
5. 科技共享组 = 阵营/经济圈的配套（限类别可实现"体系内科技圈"）；
6. 全局战争闸门：统一 trigger + on_war_relation_added 判定 + 开幕事件 + 兜底。

## 八、KX 扩展视角：自治度增量与体系化傀儡

KX 在 KR 的 23 个等级上新增 12 个（`common/autonomous_states/`，35 个），全部**宗主专属 + 禁止自治度变化**：

- **`KX_YUN_tributary.txt`（云南朝贡国）**：`min_freedom_level = 0.8`（最高自由度）、`can_be_spymaster = yes`、`allowed = { overlord = { tag = YUN } }`、剥削最轻（`extra_trade_to_overlord_factor = 0.25`）——**本 mod 朝贡国等级的最直接参考**；
- `BOTDE_Imperial_Constituent/Satellite`（奥匈构成邦/卫星国）：`mic_to_overlord_factor = 0.25`、`cic_to_overlord_factor = 0.25` 产能上交（与 05 文档的产能转移呼应）；
- `KX_MAF_*` 五件套（法德共管区/自由邦/军事保护领/保护领/三方共管）：中非碎片化专用，`can_lose_level = { always = no }`；
- `KX_colored_puppet`：上色傀儡（`use_overlord_color`）。

**制作多等级附庸体系时**：先列等级谱（完全吞并 → 直辖殖民地 → 保护国 → 朝贡国 → 藩属 → 自治领 → 完全独立），每个等级定 `min_freedom_level` 分数轴位置与 `rule`/`modifier` 组合，再按 KX 方式绑定宗主与锁定条件。

详细见 [10-KX扩展内容参考.md](10-KX扩展内容参考.md) 第十一节。
