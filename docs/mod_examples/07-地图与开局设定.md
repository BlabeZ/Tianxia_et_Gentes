# 07-地图与开局设定

> 适用：地图（省份/州/战略区/大陆）、开局日期、书签、国家历史文件、州文件。
> 参考样本：KR（275 战略区、202 国 1125 州）、EAW（20308 省份、329 战略区、1209 州、三大陆映射、单补给区）。

## 一、地图文件管线（v1.19.2 要点）

```
map/
├── default.map           # 引擎加载清单（definitions/provinces/terrain/rivers/heightmap/trees/continent/adjacency_rules/adjacencies/ambient_object/seasons/tree 索引）
├── definition.csv        # 每行: 省份ID;R;G;B;类型(land/sea/lake);沿海/可通航;名字;战略区域ID
├── provinces.bmp         # 省份像素图（RGB 对应 definition.csv）
├── terrain.bmp           # 地形索引色（对应 common/terrain/00_terrain.txt 的 terrain 块）
├── rivers.bmp heightmap.bmp trees.bmp cities.bmp
├── positions.txt         # 【v1.19.2 为空文件】位置由引擎自动计算
├── unitstacks.txt        # 自动生成（部队显示位置）
├── railways.txt          # 铁路：`等级 省份数 起点 中间... 终点`
├── adjacencies.csv       # 海峡/运河：From;To;sea;Through;坐标;规则名
├── adjacency_rules.txt   # 海峡通行规则（enemy/friend/neutral/contested × army/navy/submarine/trade + is_disabled + icon）
├── colors.txt            # 战略区显示色
├── continent.txt         # 大陆名列表
├── strategicregions/     # 战略区（id/name/provinces/weather 12 个 period + static_modifiers）
├── supplyareas/          # 【v1.19.2 仅剩 1 号文件】其余由引擎按州自动生成
└── terrain/              # dds 贴图（colormap/atlas/normal/border 等）
```

### 海峡示例（KR/EAW 与本体相同格式）


## 二、大陆定义与映射（EAW 的"不改引擎"方案）

`map/continent.txt` 只有原版三大陆键（EAW 的 38 字节版本：`europe / africa / asia`），on_startup 注释直接写明映射：
- **europe = Equus（小马大陆）、asia = Griffonia（狮鹫大陆）、africa = Zebrica（斑马大陆）**

大陆判定性能优化：tag 白名单触发器 + 启动时缓存旗标（`common/scripted_triggers/EAW_triggers.txt`）：
```pdx
is_griffon_continent_country_tag = { OR = { original_tag = MIT original_tag = LUS ... } }  # 80+ tag
```
`EAW_misc_effect.txt` 的 `set_continent_flags_on_every_possible_country` 在 on_startup 统一写入 `griffon_continent_country`/`zebrican_continent_country`/`riverlands_country`/`underdeveloped_country`/`feudal_vassal_country` 等 9 类旗标。

**启示**：《天下与万邦》可设"天下圈/欧洲圈/伊斯兰圈/南洋圈"等概念：`is_tianxia_country` = tag 白名单 + 启动缓存旗标（而非运行时地理判定）。

## 三、州文件（history/states/）

```pdx
state = {
	id = 46
	name = "STATE_46"
	manpower = 3971400
	resources = { oil = 44 }
	state_category = city          # 13 类：megalopolis(12槽)…wasteland(0槽)
	history = {
		owner = ROM
		add_core_of = ROM
		victory_points = { 9617 20 }
		buildings = { infrastructure = 3 arms_factory = 3 ... 3838 = { naval_base = 3 } }
		start_resistance = yes set_resistance = 75 set_compliance = 2   # 抵抗/服从
	}
	provinces = { 660 674 818 ... }
	local_supplies = 0.0
}
```
全部可用键：顶层 `id/name/manpower/resources/state_category/provinces/local_supplies/impassable/impassable_ignored_links/buildings_max_level_factor/modifier/strategic_state_location`；history 内 `owner/add_core_of/remove_core_of/add_claim_by/controller/victory_points/buildings/start_resistance/set_resistance/set_compliance/set_demilitarized_zone/transfer_state/set_variable/add_dynamic_modifier` 等。

EAW 州特点：
- 无内嵌种族人口（26 种族 idea 启动分配）；水晶资源集中水晶帝国（`resources = { crystals = 60 }`）；
- `eaw_on_startup_states_on_actions.txt` 为特定州注入修正（coltvan_unrest 等）与"密集乡村基建"逻辑（town/rural 且人口>1000 且无现代工业 → `dense_rural_infrastructure`）。

## 四、开局日期与 defines（三件套）

```lua
NDefines.NGame.START_DATE = "1910.1.1.12"
NDefines.NGame.END_DATE = "1950.1.1.1"
NDefines.NDiplomacy.TENSION_TIME_SCALE_START_DATE = "1916.1.1.12"
```
参考实装：EAW `"1007.1.1.12"`→`"1030.1.1.1"`（缩放起点 1012）；KR 保留 1936 开局只改 `END_DATE = "1959.1.1.1"` + 紧张度全系清零。
**注意**：`SAVE_VERSION`、`CHECKSUM_SALT` 应改防串档；书签 `common/bookmarks/` 需新增 1910 书签并 `default = yes`。

## 五、国家历史文件（总装清单写法）

`history/countries/TAG - 国家名.txt` 固定顺序（KR GER 1366 行 / EAW EQS 360 行为模板）：
1. `capital`、`oob = "GER"`、`set_naval_oob`、`set_research_slots = 4`、`set_convoys`、`set_stability`、`set_war_support`
2. `set_technology`（按 DLC 分支 if/else 两套：BBA 空军、NSB 坦克、LaR 侦察）
3. `complete_special_project` / `add_breakthrough_progress`（特种工程与突破专精）
4. `set_politics` + `set_popularities`（意识形态分布）
5. 外交：`create_faction_from_template = faction_template_xxx`、`set_autonomy = { target = CRY autonomous_state = ... }`、`add_opinion_modifier`、`give_guarantee`
6. 机制变量初始化（KR：`set_variable = { GER_SPD_seats = 125 }`；EAW：`set_country_flag = { flag = celestia_evil_meter value = 0 }`）
7. `country_event = { id = xxx days = N random_days = M }` 预排剧情时间轴
8. `recruit_character` 批量角色（`retire = yes` 管理不可用、`set_character_as_monarch`、`activate_advisor`）
9. `add_ideas` 开局国家精神（KR：victors_of_wwi/imperial_pride/pre_black_monday；EAW：harmonic_stagnation/alicorn_sisters）

日期块：`1936.1.1 = { ... }`、`1939.1.1 = { ... }`（多书签分档，按开局日执行）；EAW 的 `actually_fix_weapon_techs = yes` 类修复效果在每个历史文件主 set_technology 后调用（文件头注释要求）。

## 六、OOB 与编制（history/units/）

```pdx
division_template = {
	name = "Jalkaväkidivisioona"
	division_names_group = FIN_INF_01
	regiments = { infantry = { x = 0 y = 0 } ... }
	support = { engineer = { x = 0 y = 0 } }
}
units = { division = { division_name = { is_name_ordered = yes name_order = 6 } ... } }
```
- `set_oob = "TAG_1936"` 引用 `history/units/TAG_1936.txt`（**该目录对 replace_path 无效，靠文件名直接链接**）；
- 空军按 BBA 分支双 OOB（`GER_air_bba` vs `GER_air_legacy`）；
- KR 对 11 国 `country_lock_all_division_template = yes` 开局锁编制。

## 七、历史/开局全局文件（history/general/）

v1.19.2 仅 4 个文件（`china_shared_advisors.txt`、`generic_advisors.txt`、`spain_shared_advisors.txt`、`taog_hq_template.txt`）——旧版 00_autonomy.txt 等已迁移到 `common/autonomous_states/` 与 `common/generation/`。全局开局设置（意识形态好感、禁运、数组）一律在 `on_startup` 做（见 [08-脚本技术技巧库](08-脚本技术技巧库.md)）。

## 八、制作本模块时的检查清单

1. 1910 开局：defines 三件套 + 书签 + `common/technologies` 各科技 `start_year` 检查 + 所有 `date > 1936` 脚本日期审查；
2. 地图规模决策：继承原版地图（只改省份归属/州划分）还是全新地图（需 provinces.bmp/definition.csv 全套 + railways/adjacencies 重做）——前期建议继承原版 + replace_path strategicregions；
3. 大陆/文明圈概念：tag 白名单 + on_startup 缓存旗标；
4. 州：先定核心州与资源分布（大顺核心区、新瀛、朝贡国），`add_core_of` 与 `add_claim_by` 分开管理；
5. 国家历史文件按总装清单 9 步写；一个国家的全部内容集中在单文件，用 `#` 注释分节；
6. 开局状态（外交网络、禁运、意识形态好感）统一放 on_startup，国家文件保持纯粹。
