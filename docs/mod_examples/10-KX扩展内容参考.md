## 三、法律化贸易条约（KX 独特经济机制）

**核心创新**：把"不平等条约"做成**强制贸易法**（`law = yes` + `allowed = { always = no }` + `targeted_modifier` 产能转移）。

### 中国不平等条约（`common/ideas/China_ideas.txt`）
```pdx
trade_laws = {
	law = yes
	use_list_view = yes
	unequal_treaties = {
		allowed = { always = no }
		cancel = {
			743 = {   # 上海州
				owner = { is_chinese_tag = yes NOT = { tag = LEC } }
			}
		}
		modifier = {
			min_export = 0.6
			civilian_intel_to_others = 40.0
		}
		targeted_modifier = {
			tag = LEC      # 租界获得中国 30% 民用工厂
			cic_to_target_factor = 0.3
		}
	}
	unequal_treaties_japan = {
		cancel = { NOT = { has_idea = FNG_mantetsu_influence_idea ... } }
		targeted_modifier = { tag = JAP cic_to_target_factor = 0.4 }
	}
}
```
要点：中国政权无法移除（`allowed = always no`）；强制 60% 最低出口 + 40 点民用情报泄露；**15-40% 民用工厂产能定向输送给租界/日本**（`cic_to_target_factor`）；收回上海（州 743）或满铁影响力消失才自动取消（`cancel` 块）。

### 突厥斯坦俄国铁路（`common/ideas/Turkestan_ideas.txt`）
```pdx
TRK_russian_railways = {
	on_add = { give_military_access = RUS }
	on_remove = { ... RUS = { country_event = turkestan_railway_crisis.19 } ... }
	modifier = { min_export = 0.6 civilian_intel_to_others = 40.0 }
	targeted_modifier = { tag = RUS cic_to_target_factor = 0.15 }
	cancel = { has_country_flag = central_asia_restored_control_of_railways }
}
```
开局自动给俄国军通 + 15% 产能转移；中亚政权须通过"恢复铁路控制权"旗标取消。**该法律还联动科技共享**（`russian_research` 的 available 里有 `has_idea = TRK_russian_railways`）。

**启示**：本 mod 的"朝贡/不平等条约/铁路贷款"体系可完全照此实现——法律化条约 + `cic_to_target_factor` 产能转移 + `cancel` 条件 + 跨机制联动。

- `on_actions_economic_spheres.txt`：`on_offer_join_faction` 时若领袖是碎邦派系自动给受邀国 `USA_sphere_member`；
- `common/map_modes/economic_map_modes.txt`：`economic_zone_map_mode` 按 22 种经济圈着色（IEDC/Phalanstere/Mitteleuropa/日本圈/穆斯林协会/Mizhmoria/KCN 中华圈/BRG/阿盟/Profintern/大陆体系/Rostorg/犯罪集团/贝尔格莱德委员会/维也纳圈/民生伙伴/OSAEC/美国圈/chud axis 等）；
- 国联地图模式 `leauge_of_nations.txt`：按 `global.LON_voters`/`LON_security_council` 数组着色；投票模式按 `lon_yes/no/abstain_votes` 数组红绿黄。

## 十三、on_actions 增量（43 文件）

- `KX_on_actions.txt`（679 行）：临时科学家生成（四专精分支 + 排除名单）+ meme 规则旗标 + 四内战 strengthen 分配 + 换旗规则；
- `on_actions_annexations.txt`：`global.annexation_relevant_states` 州数组 + `set_variable = { 712.release_event = 395 }` 州→释放事件映射，`on_annex`/`on_peaceconference_ended` 触发 `annex.1` 附庸候选事件；
- `BOTDE_on_actions_set_variables.txt`：奥匈解体变量初始化（`AUS.subject_revolt_progress = 0.52`、各族 unrest 变量）；
- `on_actions_spooky.txt`：on_monthly 对全球执行 `spooky_portraits`。
