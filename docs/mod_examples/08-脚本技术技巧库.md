### 全局初始化模式（KR `00_on_actions_arrays.txt` / EAW `eaw_on_startup_general_on_actions.txt`）
on_startup 集中建立：
- **区域 TAG 数组**：`global.european_tags_array`（90+ tag）、`global.china_tags_array`（13 军阀）、各洲数组 + `for_each_scope_loop` 合成 `global.american_tags_array`；
- **大陆州数组**：`global.europe_states`/`asia_states`/`africa_states`（EAW 按 `is_on_continent` 分配）；
- **不可通行州配对**：`set_variable = { 262.paired_impassable = 397.id }`（和会移交用）；
- **殖民地宣称数组**：`global.british_colonial_claims`（附 `set_state_flag`）；
- **地区旗标**：`set_country_flag = is_in_europe` 等（区域判定性能优化）；
- **全局事件目标**：`save_global_event_target_as = equestria` 每日动态维护锚点（EAW：SOL 法西斯时指向日蚀帝国等）；
- **版本旗标**：`set_global_flag = KR_CURRENT_VERSION_1.6.4`。

### 每日结算模式（EAW `eaw_on_daily_on_actions.txt`）
on_daily 是"变量经济"的主战场：爱情收割、魔法平衡衰减、水晶短缺检测、关系清理（`has_military_access_to` → 移除）、`adjust_research_modifier`。使用 `on_daily_TAG` 变体可只对特定国家结算。

## 二、变量系统要点

- 作用域：国家/州/角色/舰队变量；跨作用域 `THIS.X`、`PREV.X`、`ROOT.X`；国家间 `GER.GER_var`；
- **数组**：`add_to_array`/`remove_from_array`/`is_in_array`/`clear_array`/`resize_array`、`array^索引`、`for_each_scope_loop = { array = X }`；全局数组 `global.xxx`；
- **@变量拼接**：`embargoed_@PREV`、`defender_state_vs_@FROM`——变量名内嵌 tag，每对国家一个标记（KR 禁运核心）；
- **token 常量**：`constant:party_pop.party.coalition_partner`、`token:totalist`（脚本常量定义于 `common/script_constants/`）；
- **临时变量传参**：`set_temp_variable` + 跨脚本约定（如 `embargo_TARGET` 要求先 `set_temp_variable = { target = X }`）；
- 坑：`set_power_balance` 的 `set_value` **不接受变量**（KR UPC 注释明言，手写 10 个 if 分支把变量映射为 ±0.9）。

## 三、scripted_trigger / scripted_effect 规范

文件：`common/scripted_triggers/`、`common/scripted_effects/`（按国家/主题拆分文件，如 `GER triggers (Germany).txt`）。
```pdx
# trigger 示例（00_scripted_triggers.txt）
can_ROOT_get_wargoal_on_THIS = {
	exists = yes
	NOT = { is_in_faction_with = ROOT }
	NOT = { is_subject_of = ROOT }
}
# effect 示例（00_scripted_effects.txt）
replace_civ_with_arms_factories = {
	random_owned_controlled_state = { limit = { is_fully_controlled_by = ROOT industrial_complex > 0 }
		remove_building = { type = industrial_complex level = 1 }
		add_building_construction = { type = arms_factory level = 1 instant_build = yes } }
}
```
调用：`trigger = { example_trigger = yes }`、`effect = { example_effect = yes }`。
**命名规范**：KR/EAW 均按国家前缀（`GER_`、`EQS_`）+ 语义名；通用机制用主题前缀（`USA_civil_war_begins`、`ED_calculate_magic_balance`）。
**工具提示**：`custom_trigger_tooltip = { tooltip = loc_key ... }`、`custom_effect_tooltip = loc_key`、`custom_override_tooltip`。

## 四、scripted_localisation（动态文本）

```pdx
defined_text = {
	name = GetHermannGoringWerkeName
	text = { trigger = { original_tag = GER has_government = communism } localization_key = GER_HERMANN_GORING_WERKE_NAME_COMMIE }
	text = { localization_key = GER_HERMANN_GORING_WERKE_NAME }   # 最后一个无 trigger = 默认
}
```
用法：本地化文件写 `$GetHermannGoringWerkeName$`。
- 递归上限 `NDefines.NGame.MAX_SCRIPTED_LOC_RECURSION = 30`；
- EAW 子意识形态显示系统（移植自 TNO）：先按政府类型分派、再按领袖意识形态取键；
- EAW 种族姓名生成器（`EAW_race_scripted_localisation.txt` 5000+ 行：`GetPonyMaleName` 86 条等）支撑随机将领/特工命名；
- KR 世界新闻动态文案（`01 - World_News_scripted_localisation.txt`）：同一新闻按 tag/阵营/意识形态返回 16 种措辞；
- EAW 州 lore 地图图标（`eaw_state_lore_gui.txt` + `mapicon_targets = { target_array = global.states_with_lore }`）。

## 五、scripted_gui（自定义 UI）

文件：`common/scripted_guis/`（KR 20、EAW 48）。语法核心：
```pdx
window_name = "..."
context_type = decision_category / player_context / state_mapicon ...
dirty = z_xxx_dirty_var          # 需要刷新时置 1
ai_enabled = { always = no }
properties = {
	pb_0 = { frame = parliament_frame_array^0 }   # 帧数组驱动视觉
}
```
EAW 用法示例：议会座位图（WNG 535 座/JER 400 座）、选举窗口（zes）、偏执系统、昼夜切换、神器面板、炼金超级工程面板、欢迎界面。KR 用法：黑周一卡牌界面（`germany_black_monday.txt` + `dynamic_lists`）、政党界面（`00_political_parties.txt` 的 `coalition_indicator` 把 coalitions_array 映射为 UI frame）。

## 六、BOP（力量平衡）用法与坑

文件：`common/bop/`（KR 12、EAW 19）。结构：
```pdx
xxx_power_balance = {
	initial_value = 0.20
	left_side = CHI_PAC_winning_side
	right_side = CHI_RCA_winning_side
	decision_category = CHI_balance_of_power_category   # 决策移动指针
	side = {
		id = CHI_PAC_winning_side
		icon = GFX_bop_CHI_pac_side
		range = {
			id = CHI_bop_PAC_dominant
			min = -1.00 max = -0.60
			modifier = { stability_factor = -0.20 ... }
			on_activate = { country_event = { id = CHI.midgame.038 days = 3 } set_power_balance_gfx = { ... } }
			on_deactivate = { ... }
		}
	}
}
```
- 读取：`is_power_balance_in_range = { id = X range > CHI_bop_PAC_tilt }`、`has_any_power_balance = no`；
- 写入：`set_power_balance = { id = X set_value = 小数 }`（**不接受变量**，需 if 分级）；`set_power_balance_gfx` 换图标；
- KR 把 on_activate 当"事件触发器"用（进入主导档触发党内事件）；EAW GRF 用 BOP 控制内战民兵数量（on_activate 里 set_temp_variable）；
- BOP 无文件的国家也可用变量系统替代（KR 德国国会、美国内战均不用 BOP）。

## 七、脚本边界技巧（KR/EAW 极限利用）

1. **手写 arctan**（EAW）：`x - x³/3 + x⁵/5 - x⁷/7 + x⁹/9` 泰勒级数九阶；
2. **while_loop 防溢出**（EAW 亡灵）：人口转化按 100 万人力分块循环；
3. **replace_unit_leader_trait 探测**（EAW on_unit_leader_created）：用夜战测试特质探测将领是否带夜战特质（对损坏原版效果的反向利用）；
4. **角色对象当数据容器**（EAW 经济圈、KR 黑周一卡牌）：`generate_character` 生成"圈/卡牌"角色，成员存数组——对象可挂变量、可被 UI 引用；
5. **框架变量防刷**：`set_global_flag = on_startup_completed` 后置检查（EAW 市场准入只在开局后生效）；
6. **`modifier@键名` 读取现有修正值**（EAW 日夜覆盖系统：读取 land_night_attack 等现有修正差值施加惩罚）；
7. **`count_triggers amount = N`** 统计满足条件的子触发数量（KR 宪法改革大礼包、FRA 达摩克利斯计划）；
8. **collection 集合**（`common/collections/`）：`collection:all_mainland_american_states` 等供 every/limit 批量操作与 manifest 进度计算；
9. **`check_expr`**：`check_expr = { value = resource_produced@crystals add = resource_imported@crystals less_than = 0 }`（EAW 水晶短缺）；
10. **`forced_update_dynamic_modifier`** 刷新变量驱动的动态修正。

## 八、DLC 双轨分支（版本兼容惯例）

```pdx
	limit = { has_dlc_bba = yes }
	set_air_oob = "GER_air_bba"

	else = {
		set_air_oob = "GER_air_legacy"

```
触发/效果内：`has_dlc_nsb = yes`、`has_dlc_aat = yes`、`has_dlc_ncns = yes`、`has_dlc = "Thunder at Our Gates"`。MIO/学说等新系统功能全部用 DLC 条件包裹，避免无 DLC 玩家报错。

## 九、动态国家与 cosmetic tag

- **cosmetic tag**：`set_cosmetic_tag = WCA_ACW` 换国号/旗帜（不换 tag）；`drop_cosmetic_tag` 复原；判定 `has_cosmetic_tag = X`；KR 美国内战各方、EAW 政体公投（`set_cosmetic_tag = EQS_DEM1`）都用它；
- **动态国家**：`create_dynamic_country`/`reserve_dynamic_country`；`original_tag` 判定本源国家（`original_tag = EQS`）；
- 动态国家区域数组维护：`on_state_control_changed` 中 `is_in_array = { global.american_tags_array = original_tag }` → 继承数组/旗标（KR）；
- `country_tag_aliases/`：KR 特色别名系统（一 tag 多别名）。

## 十、game_rules 与开局联动

## 十一、调试与排错

- `-debug` 启动项：mod 热加载、MAP_ERROR 记录、主菜单 nudge、GUI 元素悬停（Ctrl+Alt+右键跳转 GUI 文件）、错误日志自动打开；

## 十二、KX 扩展视角：彩蛋开关与超事件

KX 补充的三种高价值通用模式（详见 [10-KX扩展内容参考.md](10-KX扩展内容参考.md)）：

1. **Meme 规则三阶段开关**：`game_rules` 定义规则（如 `polar_bear_invasion`）→ `KX_on_actions.txt` 的 on_startup 用 `if/limit/has_game_rule` 转 `set_global_flag = POLAR_BEARS_ON` → 各国事件/国策/决策/scripted_effect 用 `has_global_flag` 消费。**本项目"历史/架空/联动"开关的最简洁实现**；
2. **超事件三件套**：hidden 事件设旗标+音效（`scoped_sound_effect`）→ scripted_gui 窗口 `visible = { has_global_flag = Super_Event_Visible }` + 114 个图片触发块 → scripted_localisation 按旗标返回图名；玩家可用 `KX_superevent_total_off`/`KX_superevent_sounds_off` 开关；
3. **`change_tag_from` 玩家变身**：北极熊入侵事件 `JMN = { change_tag_from = ROOT }` 让玩家直接接管新国家——流亡/变身剧情的隐藏接口。

另注意：KX 用 `on_state_control_changed` 做 50+ 大城市沦陷新闻（`news_event`），判定范式 `FROM.FROM = { state = 126 } ROOT = { controls_province = 6103 }`；`set_variable = { 州id.release_event = 事件id }` 建立"州→释放事件"映射（on_actions_annexations.txt）。

## 十三、RT56 扩展视角：追加式开发的技巧补充

RT56 为"与原版共存"开发贡献的技巧（详见 [11-RT56追加式开发参考.md](11-RT56追加式开发参考.md)）：

1. **通用国策树聚合器**：generic.txt 压成 48 行 `shared_focus` 引用列表（82 个共享 focus 定义在独立文件），每个 shared_focus 用 **`offset + trigger` 为不同国家定制树内位置**（`offset = { x = 23 y = 0 trigger = { has_focus_tree = albania_focus } }`）——一套国策多国复用且位置各异；
2. **国策树动态切换**：game_rule（`AFG_focus_tree_selection`，`allow_achievements = yes`）+ on_startup `load_focus_tree = afghanistan_tree` + **双向清理对方专属内容**（remove_ideas/remove_power_balance/retire_character）——与原版 DLC 树共存的标准解法；
3. **吞并即换树**（on_annex）：RAJ 被吞 → `load_focus_tree = r56_india_generic` + 清机制 flag + `create_country_leader` 换领袖 + `drop_cosmetic_tag`；
4. **AI 阵营自动命名**（on_create_faction）：`if/limit/original_tag + has_government` 逐国 `set_faction_name`（"New Order"/"United Nations"/"Treaty of Constantinople"）；
5. **BOP 与国策联动**（KMT 双 BOP）：极端档 `on_activate` 里 `add_power_balance_value` 回推（未完成对应国策时拉回），`decision_category` 挂钩玩家操作；
6. **formable nations 统一模板**：`set_cosmetic_tag` + 遍历州 `add_core_of = ROOT` + 间谍国籍合并（`every_operative = { add_nationality = ROOT }`）+ 统一理念三件套 + `news_event`；
7. **localisation replace 子目录**：`localisation/simp_chinese/replace/*.yml` 用引擎内置机制覆盖原版 key，无需 replace_path。

## 十四、TNO 扩展视角：GUI 四层咬合与科技门控

TNO 补充的最有价值的两种模式（详见 [12-TNO冷战经济与GUI参考.md](12-TNO冷战经济与GUI参考.md) 第三、五节）：

1. **scripted_gui 四层咬合**（133 个 GUI 的通用架构）：
   - 数据层：变量数组（`USA_states_icon_array^idx`、`BOR_SIGType`、`TNO_BoP_Tabs`）；
   - 展示层：properties 的 `frame = 变量^索引`（数组/年份作索引帧动画）、`image = "[GetXXX]"`（scripted_loc 动态贴图）、`x/y = 坐标数组`（50 州坐标）；
   - 逻辑层：effects/triggers 内嵌（按钮点击直接操作数组/变量/调用 scripted_effect）；
   - 文本层：defined_text 查表（`GetSenator_1` 按变量返回党派文本）。
   - 辅助：窗口三层结构（Open→Main→子窗口链式挂载）、`dynamic_lists` 数组→界面条目、`dirty` 变量刷新、`ai_enabled/ai_weights` 让 AI 操作 GUI、法律档位用 token 数组 + `GFX_idea_[?law_v.GetTokenKey]` 动态拼接贴图；
2. **科技分级门控**（1962 开局适配而不重排原版树）：保留原版全部科技，每个科技挂 `allow = { TNO_KD_Can_Research_Modern_Tech = yes }`，门控触发器链基于"研究设施 idea 等级"（makeshift→cutting_edge 六级），**1969.12.30 后自动降级解锁**模拟科技扩散——比整体重排科技树省力且兼容原版。

另注意：TNO 超事件用 **token 变量 + 同步 token 表 + 游戏规则三档 + 禁用时自动执行选项效果**（保证剧情连续性）；世界事件库按区域兴趣旗标过滤（玩家订阅各大洲新闻）；`set_superpower` + `global.TNO_Superpowers` 数组是"多极体系排名"的现成模式。

## 十五、TFR 扩展视角：自建国际组织与巨型分支和平

TFR 补充的三种高价值模式（详见 [13-TFR现代战争与宏观账本参考.md](13-TFR现代战争与宏观账本参考.md) 第三、七节）：

1. **国际组织自建四件套**（不用原版 faction）：成员数组（`USA.USA_nato_members`）+ 联盟级变量广播（`EU_join_effect` 把 ~50 个 `global.eu_*_var` 复制到成员本地 → `EU_member_dynamic` 动态修正读取，`EU_leave_effect` 清除）+ 领导权争夺（三变量比较定 `set_global_flag`）+ 联盟级军力聚合 GUI（every_country 遍历聚合兵力/工业/资源写入 global 变量）——**天下体系/经济圈/军事同盟均可照此自建**；
2. **巨型分支和平系统**：`on_capitulation` 完全接管原版投降（27K 行），每个战争配对 = 一个 if 分支（white_peace + annex/puppet/改组政权/事件）→ `set_global_flag = skip_default_capitulation` 跳过原版；未匹配的战争 `set_global_flag = war_continuing` 继续打——定制和约的标准写法（可精简）；
3. **多实体分裂内战**：预置国家 + `transfer_state`（约 60 州）+ `new_country = yes` + 将领转国籍（`set_nationality`）+ 合法性变量（legit_var）核心资源 + 胜利方 `annex_core_faction`——比 KR 的 cosmetic tag 方案更彻底。

另注意：TFR 的 ai_strategy_plans 用 **0 字节空文件覆盖禁用原版计划**（刻意屏蔽），剧本化 AI 靠 ai_strategy 时间窗 + 游戏规则驱动；`on_nuke_drop` 挂 730 天核沉降修正；战争升级 10 级条（变量 + 决策 + 差异化颜色）。
